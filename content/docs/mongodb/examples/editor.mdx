## VS Code extension — MongoDB

1. Install "MongoDB for VS Code"
2. Add connection
3. Explorer — collections ‌မြင်ယောင်
4. Playground — `.mongodb.js`

## Playground

```js
// new.mongodb.js
use shopdb;

db.products.insertOne({ name: "Pen", price: 1 });

db.products.find().limit(5);
```

Run — ‌လုပ်တ် — Run MongoDB Playground (shift+enter)。
