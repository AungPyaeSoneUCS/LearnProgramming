MongoDB Charts — Atlas data — dashboard ‌ဆွဲ — chart ‌ပြ။

## Setup

1. Atlas → Charts ‌ဖွင့်
2. Data source ‌ရွေး (cluster + db)
3. Dashboard ‌အသစ်
4. Add chart

## Chart types

| Type | ‌သုံး |
|---|---|
| Bar | ‌အကဲ / category |
| Line | Trend — ‌အချိန် |
| Pie | Proportion |
| Table | Data ‌တန်း |
| Scatter | Relationship |

## Example pipeline

```js
db.sales.aggregate([
  { $group: { _id: "$month", total: { $sum: "$amount" } } },
  { $sort: { _id: 1 } }
]);
```

Chart → encodings → X/Y fields ‌ချိတ်။
