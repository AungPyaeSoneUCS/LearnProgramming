Query operators — filters ‌ထိန်း — comparison, logical, element, regex။

## Comparison

```js
db.users.find({ age: { $gt: 20 } });        // > 20
db.users.find({ age: { $gte: 21 } });       // >= 21
db.users.find({ age: { $lt: 30 } });        // < 30
db.users.find({ age: { $lte: 25 } });       // <= 25
db.users.find({ age: { $ne: 22 } });        // != 22
db.users.find({ age: { $in: [20, 22] } });  // ‌ထဲ ‌ရှိ
db.users.find({ age: { $nin: [1, 2] } });   // ‌မရှိ
```

## Logical

```js
db.users.find({ $and: [{ age: { $gt: 18 } }, { city: "Yangon" }] });
db.users.find({ $or: [{ age: 20 }, { age: 30 }] });
db.users.find({ $not: { age: 22 } });
db.users.find({ $nor: [{ age: 20 }, { city: "Mandalay" }] });
```

## Element

```js
db.users.find({ email: { $exists: true } });     // field ‌ရှိ
db.users.find({ age: { $type: "int" } });        // type int
```

## Regex — text ‌ရှာ

```js
db.users.find({ name: { $regex: "^A" } }); // A နဲ့စ
```

## Array

```js
db.users.find({ skills: "node" });              // element ‌ပါ
db.users.find({ skills: { $size: 2 } });        // length 2
db.users.find({ skills: { $all: ["node", "mongo"] } }); // ‌အားလုံး
```

## ‌အဓိက အချက်များ
- Comparison — numbers
- $in/$nin — lists
- $and/$or/$not
- $exists/$type
- $regex — text
