**MongoDB** — NoSQL document database — JSON-like documents — ‌သေ‌ချာ ‌သော schema မလို။

## MongoDB ‌ဆိုတာ

```js
// Document — BSON/JSON ‌ပုံစံ
{
  _id: ObjectId("64b6..."),
  name: "Aung",
  age: 22,
  skills: ["node", "mongo"],
  address: { city: "Yangon" }
}
```

Table ‌သုံးမည့်အစား — collection + document။ Rows → documents, columns → fields။

## Relational vs MongoDB

| Relational | MongoDB |
|---|---|
| Database | Database |
| Table | Collection |
| Row | Document |
| Column | Field |
| Join | Embedded / Reference |

## ‌ဘာကြောင့် MongoDB
- Flexible schema
- Scale out — ‌လွယ်
- JSON — ‌ရှင်း
- Indexing — ‌မြန်
- Aggregation — ‌ရှုပ်ထွေး queries

## ‌သုံးစွဲ ‌ခြင်း
- Atlas (cloud) / ‌ကိုယ်ပိုင် server
- mongosh — shell
- Drivers — Node.js, Python

## ‌အဓိက အချက်များ
- Document database
- NoSQL — schema ‌လို မလို
