Document ‌ဖျက် — delete methods။

## deleteOne

```js

```

## deleteMany

```js
db.users.deleteMany({ city: "Mandalay" });
db.users.deleteMany({}); // ‌အားလုံး
```

## drop — collection ‌ဖျက်

```js
db.users.drop();
```

## ‌ဥပမာ: complete

```js
use shopdb;

db.products.insertMany([
  { name: "A", price: 10 },
  { name: "B", price: 5 },
  { name: "C", price: 100 }
]);

db.products.deleteOne({ name: "B" });
db.products.deleteMany({ price: { $lt: 15 } });
db.products.find(); // C သာ
```
