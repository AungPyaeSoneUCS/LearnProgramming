MongoDB ‌တွင် database — ‌ဖန်တီး — lazy — data ‌ထည့်မှ ပေါ်။

## use ‌ဖြင့်

```js
use mydb
```

`use` — ‌ရွေးသော database — ‌မရှိ memory မှာ ‌ဖန်တီး။

## ‌ထည့် — actual create

```js
db.products.insertOne({
  name: "Laptop",
  price: 1000
});
```

Database — first document ‌ထည့်မှ disk ‌ပေါ် ‌ပေါ်။

## Show

```js
show dbs        // ‌အားလုံး
db.getName()     // current
db.dropDatabase() // ‌ဖျက်
```

## ‌သိုလှောင်မှု

```
mydb
 └── products (collection)
      └── documents
```
