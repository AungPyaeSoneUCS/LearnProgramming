CSS Masking က Element တစ်ခုရဲ့ ဘယ်အပိုင်းကို မြင်ရပြီး ဘယ်အပိုင်းကို ဖျောက်ရမလဲဆိုတာကို ထိန်းချုပ်ပေးတဲ့ နည်းလမ်း ဖြစ်ပါတယ်။ `mask-image` Property ဟာ Mask အဖြစ် အသုံးပြုမယ့် Image ကို သတ်မှတ်ပေးပြီး Image ရဲ့ Alpha Channel (ပွင့်လင်းမှု) ကို ကြည့်ကာ ဘယ်နေရာမှာ ဖျောက်မယ်ဆိုတာ ဆုံးဖြတ်ပါတယ်။

### mask-image နဲ့ Gradient Mask

`mask-image` ကို Gradient နဲ့ အသုံးပြုရင် Element ရဲ့ အနားတစ်ဝိုက်ကို တဖြည်းဖြည်း ဖျောက်ပေးတဲ့ Fade Out ပုံစံကို ဖန်တီးနိုင်ပါတယ်။ Black ကနေ Transparent ကို သွားတဲ့ Gradient က Element ကို အပေါ်ကနေ အောက်အထိ တဖြည်းဖြည်း ဖျောက်ပေးပါတယ်။

**ဥပမာ -**
```css
.fade-bottom {
  mask-image: linear-gradient(to bottom, black, transparent);
}
```

မှတ်ချက် — Gradient ထဲက Black ပိုင်းက ပုံကို အပြည့်မြင်ရပြီး Transparent ပိုင်းက ပုံကို လုံးဝ ဖျောက်ပါတယ်။

### mask-size နဲ့ mask-repeat

`mask-size` က Mask Image ရဲ့ အရွယ်အစားကို သတ်မှတ်ပြီး `mask-repeat` က Mask ကို ထပ်ခါထပ်ခါ ပြန်စီရမယ် မစီရမယ်ကို ထိန်းချုပ်ပါတယ်။ `cover` ၊ `contain` ၊ `no-repeat` တို့ကို အသုံးများပါတယ်။

**ဥပမာ -**
```css
.banner {
  mask-image: linear-gradient(black 30%, transparent);
  mask-size: cover;
  mask-repeat: no-repeat;
}
```

မှတ်ချက် — Browser အဟောင်းတွေမှာ `-webkit-mask-image` လို Vendor Prefix လိုအပ်နိုင်ပါတယ်။

### SVG Mask အသုံးပြုခြင်း

SVG ထဲမှာ Mask Element နဲ့ ပုံသဏ္ဍာန်တစ်ခုကို သတ်မှတ်ပြီး `mask-image: url(#id)` ဖြင့် ရည်ညွှန်းနိုင်ပါတယ်။ White ပုံသဏ္ဍာန်က မြင်ရမယ့် အပိုင်းကို ကိုယ်စားပြုပြီး Black ကတော့ ဖျောက်မယ့် အပိုင်း ဖြစ်ပါတယ်။

**ဥပမာ -**
```css
.profile-pic {
  mask-image: url(#circle-mask);
}
```

မှတ်ချက် — `url()` ထဲမှာ Mask ID ကို ထည့်ပေးမှသာ SVG Mask နဲ့ ချိတ်ဆက်နိုင်ပါတယ်။

သက်ဆိုင်တဲ့ SVG Code ကို အောက်မှာ ကြည့်နိုင်ပါတယ်။

**ဥပမာ -**
```html
<svg width="0" height="0">
  <mask id="circle-mask">
    <circle cx="50" cy="50" r="50" fill="white" />
  </mask>
</svg>
```

မှတ်ချက် — SVG ထဲမှာ Mask ကို Define လုပ်ပြီး CSS ကသာ ရည်ညွှန်းတာမို့ SVG ကို Screen ပေါ်မှာ မပြပါဘူး။

#### မှတ်ထားရမယ့် အချက်များ

- `mask-image` က Mask အဖြစ် သုံးမယ့် Image သို့မဟုတ် Gradient ကို သတ်မှတ်ပါသည်။
- `mask-size` နဲ့ `mask-repeat` က Mask ရဲ့ အရွယ်အစားနဲ့ ပြန်စီပုံကို ထိန်းချုပ်ပါသည်။
- SVG Mask Element ကို `url(#id)` ဖြင့် ရည်ညွှန်းနိုင်ပါသည်။
