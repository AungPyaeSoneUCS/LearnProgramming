CSS Variable (Custom Property) ဆိုတာ အရောင် ၊ အရွယ်အစားလို တန်ဖိုးတွေကို နာမည်တစ်ခုအောက်မှာ သိမ်းထားပြီး တစ်နေရာတည်း ပြောင်းလိုက်ရုံနဲ့ Site တစ်ခုလုံးမှာ သက်ရောက်စေနိုင်တဲ့ နည်းလမ်း ဖြစ်ပါတယ်။ နာမည်ကို `--` နဲ့ စရေးရပါတယ်။

### Variable သတ်မှတ်ခြင်း

Variable တွေကို များသောအားဖြင့် `:root` ထဲမှာ သတ်မှတ်ပြီး Document တစ်ခုလုံးမှာ သုံးနိုင်ပါတယ်။

**ဥပမာ -**
```css
:root {
  --main-color: #3498db;
  --main-padding: 15px;
}
```

မှတ်ချက် — `:root` က Document ရဲ့ အမြင့်ဆုံး Element ကို ကိုယ်စားပြုပြီး အဲဒီမှာ သတ်မှတ်ထားတဲ့ Variable တွေက Page အားလုံးမှာ ရနိုင်ပါတယ်။

### var() Function အသုံးပြုခြင်း

Variable ကို ပြန်သုံးဖို့ `var()` Function ထဲမှာ Variable နာမည်ကို ထည့်ပါတယ်။

**ဥပမာ -**
```css
.button {
  background-color: var(--main-color);
  padding: var(--main-padding);
}

.card {
  border: 2px solid var(--main-color);
}
```

မှတ်ချက် — `var()` ကို Property Value နေရာမှာ သုံးနိုင်ပြီး Variable ရဲ့ တန်ဖိုး ပြောင်းလဲလိုက်တာနဲ့ အသုံးပြုနေတဲ့ နေရာတိုင်းမှာ အလိုအလျောက် ပြောင်းပါတယ်။

### Fallback Value

`var()` အသုံးပြုတဲ့အခါ Variable ရှာမတွေ့ပါက သုံးမယ့် Fallback Value ကို Second Argument အဖြစ် ထည့်နိုင်ပါတယ်။

**ဥပမာ -**
```css
.title {
  color: var(--title-color, #333);
  font-size: var(--title-size, 24px);
}
```

မှတ်ချက် — `--title-color` မရှိတဲ့အခါ Fallback က `#333` ဖြစ်လို့ Style က ကွဲသွားစရာ မလိုဘဲ လုံခြုံပါတယ်။

### Scope နဲ့ Theme ပြောင်းလဲခြင်း

Variable တွေက Nested Scope ရှိပြီး Selector တစ်ခုအတွင်းမှာ ပြန်သတ်မှတ်ရင် အဲဒီနေရာမှာသာ Override ဖြစ်ပါတယ်။ ဒါကြောင့် Theme Switching ကို CSS ပြောင်းစရာမလိုဘဲ ပြုလုပ်နိုင်ပါတယ်။

**ဥပမာ -**
```css
:root {
  --bg: white;
  --text: black;
}

.dark-theme {
  --bg: #222;
  --text: white;
}

body {
  background-color: var(--bg);
  color: var(--text);
}
```

မှတ်ချက် — Body ပေါ်မှာ `dark-theme` Class ရှိနေရင် Variable နှစ်ခုလုံး Override ဖြစ်ပြီး Dark Theme ကို Class ထည့်ခြင်းဖြင့်သာ ရပါတယ်။

#### မှတ်ထားရမယ့် အချက်များ

- Variable နာမည်ကို `--` နဲ့ စတင်ပြီး `var()` ဖြင့် ပြန်အသုံးပြုပါသည်။
- Fallback Value ကြောင့် Variable မရှိလျှင်လည်း Style အလုပ်လုပ်ပါသည်။
- Variable ကို Scope အတွင်း ပြန်သတ်မှတ်၍ Theme ပြောင်းလဲနိုင်ပါသည်။
