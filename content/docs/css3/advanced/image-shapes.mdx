`shape-outside` Property က Float လုပ်ထားတဲ့ Element ရဲ့ ပတ်ဝန်းကျင်ကို Text စီးဆင်းနိုင်တဲ့ ပုံစံ သတ်မှတ်ပေးပါတယ်။ Default အားဖြင့် Text တွေက စတုဂံ Box ပုံစံအတိုင်း စီးဆင်းပြီး `shape-outside` နဲ့ ကွေးဝိုင်းတဲ့ ပုံစံများအထိ ဖန်တီးနိုင်ပါတယ်။

### circle() ပုံစံ

`circle()` Function နဲ့ Image ရဲ့ ပတ်ဝန်းကျင်ကို စက်ဝိုင်းပုံစံ ဖြစ်အောင် ပြုလုပ်ပါတယ်။ Image ကိုလည်း `border-radius: 50%` ပေးမှ Text စီးဆင်းမှုနဲ့ ညီညွတ်ပါတယ်။

**ဥပမာ -**
```css
img.balloon {
  width: 200px;
  height: 200px;
  float: left;
  border-radius: 50%;
  shape-outside: circle(50%);
}
```

မှတ်ချက် — `circle(50%)` က Image Width ရဲ့ 50% ကို Radius အဖြစ် သုံးပြီး Text တွေက စက်ဝိုင်း ပတ်လည်ကို စီးဆင်းပါတယ်။

### ellipse() ပုံစံ

`ellipse()` Function က ဘဲဥပုံသဏ္ဌာန် ဖြစ်အောင် Horizontal Radius နဲ့ Vertical Radius နှစ်ခု သတ်မှတ်ပေးရပါတယ်။

**ဥပမာ -**
```css
img.ellipse-shape {
  width: 250px;
  height: 160px;
  float: right;
  border-radius: 50%;
  shape-outside: ellipse(50% 40%);
}
```

မှတ်ချက် — `ellipse(50% 40%)` မှာ 50% က X-axis Radius ၊ 40% က Y-axis Radius ဖြစ်ပြီး ဘဲဥပုံ ပုံစံ ဖြစ်ပေါ်လာပါတယ်။

### shape-margin ဖြင့် နေရာလွတ်

Text တွေနဲ့ Shape အကြားမှာ နေရာလွတ် ချန်ဖို့ `shape-margin` ကို အသုံးပြုပါတယ်။ Image နဲ့ Text ကပ်နေတာကို ကာကွယ်ပေးပါတယ်။

**ဥပမာ -**
```css
img.avatar {
  width: 180px;
  height: 180px;
  float: left;
  border-radius: 50%;
  shape-outside: circle(50%);
  shape-margin: 20px;
}
```

မှတ်ချက် — `shape-margin: 20px` က Shape နဲ့ Text အကြားမှာ 20 Pixel နေရာလွတ်ချန်ပေးလို့ စာဖတ်ရတာ ပိုသက်တောင့်သက်သာ ဖြစ်ပါတယ်။

### Floating Image နဲ့ Text Wrapping ဥပမာ

Article တစ်ခုထဲမှာ Circle Shape ပုံကို ထည့်ပြီး Text တွေ ပတ်လည်စီးဆင်းစေတဲ့ ဥပမာအပြည့်အစုံ ဖြစ်ပါတယ်။

**ဥပမာ -**
```html
<article>
  <img src="balloon.jpg" alt="မီးပုံးပျံ" class="balloon">
  <p>ဒီစာသားတွေက ပုံရဲ့ ပတ်လည်ကို စက်ဝိုင်းပုံစံအတိုင်း ကွေ့ပြီး စီးဆင်းသွားပါမယ်။ ရလဒ်အနေနဲ့ ပိုလှပပြီး ဖတ်လို့လွယ်တဲ့ Layout တစ်ခု ဖြစ်လာပါတယ်။</p>
</article>
```

မှတ်ချက် — Image ကို Text ထက် ရှေ့မှာ ထားပေးမှ Float ဖြစ်ပြီး Text နောက်ကို ရောက်သွားပါတယ်။

**ဥပမာ -**
```css
.balloon {
  width: 180px;
  height: 180px;
  float: left;
  border-radius: 50%;
  shape-outside: circle(50%);
  shape-margin: 15px;
}
```

မှတ်ချက် — `shape-outside` က Float လုပ်ထားတဲ့ Element မှာသာ အလုပ်လုပ်လို့ `float` ကို မဖြစ်မနေ ထည့်ပေးရပါမယ်။

#### မှတ်ထားရမယ့် အချက်များ

- `shape-outside` က Float Element များမှာသာ သက်ရောက်ပါသည်။
- `circle()` သို့ `ellipse()` ကဲ့သို့ Shape Function များဖြင့် Text စီးဆင်းပုံကို ပြောင်းနိုင်ပါသည်။
- `shape-margin` ဖြင့် Text နှင့် Shape အကြား နေရာလွတ် ချန်နိုင်ပါသည်။
