### Perspective ဆိုတာ ဘာလဲ?

3D Transform ကို မြင်ရဖို့ `perspective` က အဓိက လိုအပ်ပါတယ်။ Parent Element မှာ perspective ထားပြီး Child Element ကို Transform လုပ်ရင် အနီးအဝေး ကြည့်မြင်ရတဲ့ Effect ပေါ်လာပါတယ်။ Perspective Value ငယ်လေ Effect က ပိုစူးရှလေဖြစ်ပြီး ကြီးလေ Effect က ပိုချောလေပါ။

**ဥပမာ -**
```css
.stage {
  perspective: 300px;
}
.stage .card {
  transform: rotateY(45deg);
}
```

မှတ်ချက် — perspective ကို Parent မှာ ထားတာ ပုံမှန်ဖြစ်ပြီး မပါရင်တော့ 3D Effect မပေါ်လာပါဘူး။

### rotateX ၊ rotateY ၊ rotateZ ၊ translateZ

rotateX က X ဝင်ရိုး (အလျားလိုက်) အတိုင်းလှည့်ပြီး rotateY က Y ဝင်ရိုး (ဒေါင်လိုက်) အတိုင်း ရှေ့နောက် လှည့်ကာ rotateZ ကတော့ Z ဝင်ရိုး (မျက်နှာပြင်နဲ့ ထောင့်ဖြတ်) အတိုင်း 2D လှည့်မှုနဲ့ ဆင်တူပါတယ်။ `translateZ()` ကတော့ Element ကို Positive ဆို ကြည့်သူဆီသို့ နီးလာပြီး Negative ဆို ဝေးရာသို့ ရွေ့ပေးပါတယ်။

**ဥပမာ -**
```css
.ax { transform: rotateX(60deg); }
.ay { transform: rotateY(60deg); }
.az { transform: rotateZ(60deg); }
.closer { transform: translateZ(50px); }
```

မှတ်ချက် — rotateZ က 2D rotate နဲ့ ဆင်တူပြီး rotateX နဲ့ rotateY တို့ကသာ အနီးအဝေး 3D Effect ရှိပါတယ်။

### translateZ နဲ့ transform-style

Child Element များစွာကို သုံးဖက်မြင် Space အတွင်းမှာ ကောင်းစွာ ထိန်းသိမ်းချင်ရင် Parent မှာ `transform-style: preserve-3d` ထားရပါတယ်။ မထားရင် Child Transform တွေက ချော့ပြားတဲ့ 2D မျက်နှာပြင်ပေါ်မှာ ပြားပြားဝပ်ဝပ် ကျန်နေပါတယ်။

**ဥပမာ -**
```css
.scene {
  perspective: 400px;
  transform-style: preserve-3d;
}
.layer {
  transform: translateZ(50px);
  background-color: #00bcd4;
}
```

မှတ်ချက် — preserve-3d မပါရင် translateZ လုပ်ထားတဲ့ Child တွေဟာ ၎င်းတို့ရဲ့ 3D အပြောင်အလဲကို မထိန်းသိမ်းနိုင်ပါဘူး။

### 3D Flip Card ဥပမာ

Flip Card ဆိုတာ Mouse Hover လုပ်တဲ့အခါ Card တစ်ခုလုံး 3D အနေနဲ့ ရှေ့မျက်နှာကနေ နောက်မျက်နှာသို့ ပြန်လှည့်ပြတဲ့ UI ပါ။ HTML မှာ `.scene` ထဲထည့်ထားတဲ့ `.card` ထဲမှာ `.front` နဲ့ `.back` ဆိုပြီး မျက်နှာနှစ်ခု ရှိရပါတယ်။ အောက်မှာ CSS ကို ကြည့်ကြရအောင်။

**ဥပမာ -**
```css
.scene { perspective: 1000px; }
.card {
  width: 200px;
  height: 260px;
  position: relative;
  transform-style: preserve-3d;
  transition: transform 0.6s;
}
.scene:hover .card {
  transform: rotateY(180deg);
}
.front, .back {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
}
.back {
  transform: rotateY(180deg);
  background-color: #ffc107;
}
```

မှတ်ချက် — backface-visibility: hidden က နောက်မျက်နှာကို Card လှည့်ပြီးမှသာ ပေါ်စေပြီး front ​​အနေနဲ့ hidden မရှိရင် မျက်နှာ နှစ်ခုလုံး ရောထွေးမြင်နေရပါတယ်။

#### မှတ်ထားရမယ့် အချက်များ

- 3D Effect မြင်ရဖို့ Parent မှာ perspective ရှိရမည်။
- rotateX၊ rotateY က 3D လှည့်မှု ၊ rotateZ က 2D လှည့်မှုနဲ့ ဆင်တူသည်။
- Flip Card အတွက် transform-style: preserve-3d နဲ့ backface-visibility: hidden လိုအပ်သည်။
