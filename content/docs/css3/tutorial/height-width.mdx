### `height` နဲ့ `width` အခြေခံ

`width` က element ရဲ့ အကျယ်၊ `height` က element ရဲ့ အမြင့်ကို သတ်မှတ်ပါတယ်။ Block element တွေက default အနေနဲ့ မိဘရဲ့ full width ကို ယူထားလို့ width ပေးမှပဲ ကျဉ်းသွားပြီး height ကတော့ content အပေါ် မူတည်ပြီး အလိုအလျောက် ကြီးပါတယ်။

**ဥပမာ -**
```css
.div1 {
  width: 300px;
  height: 150px;
  background-color: lightblue;
}

.div2 {
  width: 50%;
  height: 100px;
}
```

မှတ်ချက် — Height ကို fixed ပေးထားရင် content ပိုများလာတဲ့အခါ ပြည့်လျှံသွားနိုင်လို့ `overflow` property နဲ့ တွဲသုံးလေ့ ရှိပါတယ်။

### max-width (အကျယ်ဆုံး ကန့်သတ်ချက်)

`max-width` က element ရဲ့ အကျယ်ကို ဒီတန်ဖိုးထက် မပိုစေဘဲ ထိန်းထားပါတယ်။ Browser ပြောင်းရင် element က ကျဉ်းသွားလို့ responsive design မှာ မရှိမဖြစ် သုံးပါတယ်။

**ဥပမာ -**
```css
p {
  max-width: 600px;
  margin: 0 auto;
}

.responsive-img {
  max-width: 100%;
  height: auto;
}
```

မှတ်ချက် — Image တွေမှာ `max-width: 100%; height: auto;` ပေးရင် container ထက် မကျော်ဘဲ အချိုးကျ ကျုံ့သွားပါတယ်။

### min-width (အနည်းဆုံး အကျယ်)

`min-width` က element ရဲ့ အကျယ်ကို ဒီထက် မကျဉ်းစေဘဲ ထိန်းထားပါတယ်။ Content ဘယ်လောက်ပဲ ကျဉ်းကျဉ်း min-width အောက်ကို မဆင်းပါဘူး။

**ဥပမာ -**
```css
.sidebar {
  min-width: 200px;
  width: 25%;
}

.btn {
  min-width: 120px;
}
```

မှတ်ချက် — min-width က အောက်ကန့်သတ်ချက်ပဲ ဖြစ်လို့ container ကျယ်နေရင် element ကလည်း ပိုကျယ်လို့ ရပါတယ်။

### max-height နဲ့ min-height

`max-height` နဲ့ `min-height` က အမြင့်အတွက် အတူတူ ကန့်သတ်ပေးပါတယ်။ max-height ထက် content များနေရင် overflow ဖြစ်တတ်လို့ scroll နဲ့ တွဲသုံးလေ့ ရှိပါတယ်။

**ဥပမာ -**
```css
.notice {
  min-height: 80px;
  max-height: 300px;
  overflow: hidden;
}

.dropdown-menu {
  max-height: 200px;
  overflow: auto;
}
```

မှတ်ချက် — Menu တွေ၊ notification box တွေမှာ max-height နဲ့ `overflow: auto;` တွဲပြီး scroll လုပ်ပေးတာက အသုံးများပါတယ်။

#### မှတ်ထားရမယ့် အချက်များ

- `width` နဲ့ `height` က element ရဲ့ အကျယ်၊ အမြင့်ကို သတ်မှတ်ပါတယ်။
- `max-width` က responsive layout အတွက် အရေးကြီးပါတယ်။
- `min-width`, `min-height`, `max-height` တွေက ကန့်သတ်ချက် အတိုင်းအတာကို သတ်မှတ်ပေးပါတယ်။
