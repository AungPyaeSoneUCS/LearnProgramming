### Template ဆိုတာ ဘာလဲ

Template ဆိုတာ အင်တာနက်ပေါ်မှာ အသင့်ရေးပြီးသား Website အပြင်အဆင်ကို ပြောတာပါ။ HTML Structure နဲ့ CSS Style တွေကို ကြိုတင်ပြင်ဆင်ထားပြီးသားမို့ ကိုယ့် Content တွေကိုသာ အစားထိုး ထည့်ရုံနဲ့ Website တစ်ခုကို အချိန်တိုအတွင်း တည်ဆောက်လို့ရပါတယ်။

Template သုံးရင် ရတဲ့ အားသာချက်တွေ ရှိပါတယ် —

- Layout ကို ပြန်မဆောက်ရလို့ အချိန် သက်သာပါတယ်။
- Responsive (Screen အရွယ်နဲ့ လိုက်လျောညီထွေဖြစ်မှု) ကို အများအားဖြင့် ထည့်ပြီးသား ပါပါတယ်။
- Beginner တွေအတွက် တကယ့် Website ရဲ့ ဖွဲ့စည်းပုံကို လေ့လာဖို့ အကောင်းဆုံး သင်ခန်းစာ ဖြစ်ပါတယ်။

### Blog Style Template ဥပမာ

Blog တစ်ခုမှာ `<header>` က ခေါင်းစဉ်နဲ့ Menu ၊ `<main>` က ဆောင်းပါးတွေ ၊ `<footer>` က အောက်ခြေ အချက်အလက်တွေကို သယ်ဆောင်ပါတယ်။ ဆောင်းပါးတစ်ပုဒ်ချင်းစီကို `<article>` ထဲမှာ ထည့်ရေးပါတယ်။ ဒီ Template ကို Copy ကူးပြီး Browser မှာ တိုက်ရိုက် ဖွင့်လို့ရပါတယ်။

**ဥပမာ -**
```html
<!DOCTYPE html>
<html lang="my">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Blog</title>
  <style>
    body { font-family: Arial, sans-serif; margin: 0; background: #f4f4f4; }
    header { background: #2c3e50; color: #fff; padding: 20px; }
    header h1 { margin: 0; }
    nav a { color: #fff; margin-right: 15px; text-decoration: none; }
    main { max-width: 800px; margin: 20px auto; padding: 0 20px; }
    article { background: #fff; padding: 20px; margin-bottom: 20px; border-radius: 8px; }
    footer { background: #2c3e50; color: #fff; text-align: center; padding: 15px; }
  </style>
</head>
<body>
  <header>
    <h1>My Blog</h1>
    <nav>
      <a href="#">Home</a>
      <a href="#">About</a>
      <a href="#">Contact</a>
    </nav>
  </header>
  <main>
    <article>
      <h2>ပထမဆုံး ဆောင်းပါး</h2>
      <p>ဒီနေရာမှာ ဆောင်းပါး အကြောင်းအရာ ရေးထည့်ပါ။</p>
    </article>
    <article>
      <h2>ဒုတိယ ဆောင်းပါး</h2>
      <p>ဒီနေရာမှာ နောက်ထပ် ဆောင်းပါး အကြောင်းအရာ ရေးထည့်ပါ။</p>
    </article>
  </main>
  <footer>
    <p>Copyright 2026 My Blog</p>
  </footer>
</body>
</html>
```

မှတ်ချက် — Template ထဲက စာသားနဲ့ Link တွေက ဥပမာသာ ဖြစ်ပြီး ကိုယ့်အကြောင်းအရာနဲ့ လိုအပ်သလို အစားထိုး ပြင်ဆင်ရပါတယ်။

### Business Landing Template (Header နဲ့ Footer)

Business Website အတွက် Logo နေရာ၊ Menu ၊ Hero Section ၊ Footer တို့ ပါတဲ့ Template ကို ကြည့်ကြရအောင်။ Hero Section က Website ဖွင့်လိုက်တာနဲ့ ပထမဆုံး မြင်ရတဲ့ နေရာဖြစ်ပြီး လုပ်ငန်းရဲ့ Message ကို တိုတိုနဲ့ ပြတ်သားစွာ ဖော်ပြပါတယ်။

**ဥပမာ -**
```html
<header class="site-header">
  <span class="brand">Takkatho Business</span>
  <nav>
    <a href="#home">Home</a>
    <a href="#services">Services</a>
    <a href="#about">About</a>
    <a href="#contact">Contact</a>
  </nav>
</header>

<section class="hero">
  <h1>လုပ်ငန်းအတွက် အကောင်းဆုံး ဖြေရှင်းချက်</h1>
  <p>Website နဲ့ Digital Service လုပ်ငန်းများအတွက် အသင့်သုံး Layout။</p>
  <a href="#contact" class="btn">ဆက်သွယ်ရန်</a>
</section>

<footer class="site-footer">
  <p>Takkatho Business — မြန်မာနိုင်ငံ</p>
</footer>
```

မှတ်ချက် — Link တွေထဲက `href="#"` က နေရာကိုင်ထားတဲ့ Placeholder ဖြစ်ပြီး တကယ့် Page ရှိရင် အဲဒီ Link လိပ်စာနဲ့ အစားထိုးရပါတယ်။

အခု အဲဒီ HTML ကို အလှဆင်ဖို့ CSS ကို ထည့်ကြည့်ရအောင်။ Flexbox နဲ့ Gradient တွေကို သုံးထားလို့ `display: flex;` နဲ့ `linear-gradient()` တွေလည်း ပြန်လေ့လာရမှာ ဖြစ်ပါတယ်။

**ဥပမာ -**
```css
.site-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  background: #1a1a2e;
  color: #fff;
  padding: 15px 30px;
}

.brand {
  font-size: 22px;
  font-weight: bold;
}

.site-header nav a {
  color: #fff;
  margin-left: 15px;
  text-decoration: none;
}

.hero {
  background: linear-gradient(135deg, #e94560, #1a1a2e);
  color: #fff;
  text-align: center;
  padding: 80px 20px;
}

.hero .btn {
  display: inline-block;
  background: #fff;
  color: #1a1a2e;
  padding: 12px 24px;
  border-radius: 6px;
  text-decoration: none;
  margin-top: 15px;
}

.site-footer {
  background: #16213e;
  color: #aaa;
  text-align: center;
  padding: 20px;
}
```

မှတ်ချက် — Header မှာ `display: flex;` သုံးထားလို့ Brand နဲ့ Menu တွေ ဘယ်ညာ ညီညီ ခွဲထွက်နေပြီး Hero ရဲ့ Button က Contact Section ကို ညွှန်ပြတဲ့ Link ဖြစ်ပါတယ်။

### အခမဲ့ Template တွေ ဘယ်မှာ ရှာမလဲ

အခမဲ့ Template တွေကို အောက်ပါနေရာတွေမှာ ရှာတွေ့နိုင်ပါတယ်။

- **HTML5 UP** (html5up.net) — Responsive လှတဲ့ HTML5 Template များစွာ ၊ အခမဲ့ ဒေါင်းလုဒ် ရပါတယ်။
- **Start Bootstrap** (startbootstrap.com) — Bootstrap ကိုအခြေခံတဲ့ Landing Page Template တွေ ၊ အခမဲ့ ဖြစ်ပါတယ်။
- **W3Schools Free Templates** (w3schools.com) — HTML စတင်လေ့လာသူတွေအတွက် လွယ်ကူတဲ့ W3.CSS Template တွေ ပါပါတယ်။
- **Colorlib** — WordPress နဲ့ HTML အခမဲ့ Template တွေ အများကြီး စုထားပါတယ်။
- **GitHub** — Open Source Project တွေထဲက အခမဲ့ Template ကုဒ်တွေကို ရှာ လေ့လာနိုင်ပါတယ်။

Template တစ်ခုကို ရွေးပြီးတာနဲ့ ကုဒ်ကို ဖတ်ပြီး ဘယ် Class တွေက ဘာကို လုပ်တယ်ဆိုတာ နားလည်ဖို့ ကြိုးစားကြည့်ပါ — ဒါက ကိုယ်တိုင် CSS ရေးတဲ့အခါ အသုံးဝင်တဲ့ အတွေ့အကြုံ ဖြစ်လာပါလိမ့်မယ်။

#### မှတ်ထားရမယ့် အချက်များ

- Template က အသင့်ရေးပြီးသား HTML နဲ့ CSS ဖြစ်ပြီး Content အစားထိုးရုံနဲ့ ရပါတယ်။
- Blog Template မှာ `header` ၊ `main` ၊ `article` ၊ `footer` တွေ ပါဝင်ပါတယ်။
- HTML5 UP ၊ Start Bootstrap ၊ W3Schools စတဲ့ ဆိုက်တွေက အခမဲ့ Template တွေ ပေးပါတယ်။
