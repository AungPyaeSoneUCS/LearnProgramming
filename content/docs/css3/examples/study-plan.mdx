CSS ကို စနစ်တကျ သင်ယူဖို့ အချိန် သတ်မှတ်ပေးဖို့ လိုပါတယ်။ ဒီ ၆ ပတ် အစီအစဉ်ကို တစ်နေ့ မိနစ် ၃၀ — ၄၅ လောက် ပေးနိုင်ရင် လွယ်ကူစွာ လိုက်လုပ်နိုင်ဖို့ ရေးဆွဲထားတာ ဖြစ်ပါတယ်။ ပိုအချိန်ရတယ်ဆိုရင် ရက်ခြားပြီး နှစ်ကြိမ် လေ့လာရင် ပိုမြန်ပါတယ်။

### တစ်ပတ်ချင်း အစီအစဉ် ဇယား

| Week | အဓိက လေ့လာစရာ | အပတ်တွင်း ရည်မှန်းချက် |
| --- | --- | --- |
| Week 1 | Tutorial — စတင်ခြင်း | Selector ၊ Syntax ၊ Style ထည့်သွင်းနည်း ၃ မျိုး၊ Colors ၊ Backgrounds တို့ကို တတ်မြောက်အောင် |
| Week 2 | Tutorial — Box Model နဲ့ Layout | Box Model ၊ Margin/Padding/Border ၊ Display ၊ Position ၊ Float ၊ z-index ကို ကျွမ်းကျင်အောင် |
| Week 3 | Tutorial — Component နဲ့ Cascade | Table ၊ Form ၊ Nav Bar ၊ Dropdown စသော Component နဲ့ Specificity ၊ `!important` ကို နားလည်အောင် |
| Week 4 | Advanced — Visual Effects | Gradient ၊ Shadow ၊ Rounded Corners ၊ Transition ၊ Transform ၊ Animation တို့ကို လေ့ကျင့်ပြီး |
| Week 5 | Flexbox/Grid နဲ့ Responsive | Flexible Layout နဲ့ Media Query ကို သုံး၍ screen အမျိုးမျိုး အတွက် ပြင်ဆင်ခြင်း |
| Week 6 | References နဲ့ Certificate | Mini Site Project ဆောက်၍ ပြန်လည် သုံးသပ်ပြီး Final Test ဖြေဆို လက်မှတ် ရယူခြင်း |

မှတ်ချက် — ဒီဇယားက ယခုရှိနေတဲ့ Tutorial နဲ့ Advanced Chapter တွေ အပေါ် အခြေခံပြီး Flexbox/Grid နဲ့ Responsive ကို လာမည့် သင်ခန်းစာများဖြင့် ဖြည့်စည်း သွားပါမယ်။

### Week 1 — Tutorial အခြေခံ

ပထမ သီတင်းပတ်မှာ CSS ရဲ့ ဘာသာစကား ဖွဲ့စည်းပုံကို နားလည်ဖို့ အရေးကြီးတဲ့ Selector နဲ့ Syntax ကို လေ့လာပါမယ်။ Element ၊ Class ၊ ID Selector ကစပြီး Style ထည့်သွင်းနည်း ၃ မျိုး ဖြစ်တဲ့ External ၊ Internal ၊ Inline ကို ခွဲခြား နားလည်အောင် ရေးပါမယ်။ ဒီအပတ်ရဲ့ အဆုံးမှာ `<link>` နဲ့ stylesheet ချိတ်ပြီး page တစ်ခုကို အရောင်ခြယ်နိုင်နေရပါပြီ။

Daily အနေနဲ့ —
- Day 1-2: Syntax နဲ့ Selector (element, class, id) — examples ပါ code တွေ ကိုယ်တိုင် ပြန်ရိုက်ပါ
- Day 3-4: How To — External/Internal/Inline Style ၊ Comments
- Day 5-6: Colors ၊ Backgrounds ၊ Text ၊ Fonts
- Day 7: exercises ထဲက Exercise ၁ နဲ့ ၂ ကို ပြန်ဖြေပြီး နားလည်မှု စစ်ဆေးပါ

မှတ်ချက် — Selector ကို မကျွမ်းကျင်ရင် နောက် Lesson အားလုံး ခက်ခဲတာမို့ ဒီအပတ်ကို သေချာ လေ့ကျင့်ပါ။

### Week 2 — Box Model နဲ့ Layout

ဒုတိယ သီတင်းပတ်မှာ CSS ရဲ့ အုတ်မြစ် ဖြစ်တဲ့ Box Model ကို သေချာ နားလည် ရပါမယ်။ Content ၊ Padding ၊ Border ၊ Margin အလွှာ ၄ ခုရဲ့ အလုပ်လုပ်ပုံနဲ့ `box-sizing` ၏ အကျိုးသက်ရောက်မှုကို တွက်ချက် လေ့ကျင့်ပါမယ်။ ပြီးတော့ Element တွေကို နေရာချဖို့ Display ၊ Float ၊ Position (absolute, relative, fixed, sticky) ၊ z-index တို့ကို လေ့လာပါမယ်။

Daily အနေနဲ့ —
- Day 1-2: Box Model နဲ့ စုစုပေါင်း အကျယ် တွက်နည်း
- Day 3-4: Margin ၊ Padding ၊ Border ၊ Height/Width
- Day 5-6: Display ၊ Float ၊ Inline-block
- Day 7: Position ၊ Offsets ၊ z-index ကို ဥပမာများ ဖြင့် စမ်းပြီး Overflow ကို ကြည့်ပါ

မှတ်ချက် — Box Model ကို နားမလည်ဘဲ layout ချရင် မမျှော်လင့်တဲ့ နေရာကွက်များ ဖြစ်လာတာမို့ Developer Tools ထဲက computed tab နဲ့ ပါ စစ်ကြည့်ပါ။

### Week 3 — Component နဲ့ Cascade

တတိယ သီတင်းပတ်မှာ လက်တွေ့ website တွေမှာ သုံးရတဲ့ Component တွေကို Style လုပ်ပါမယ် — Lists ၊ Tables ၊ Forms ၊ Navigation Bars ၊ Dropdowns ၊ Image Gallery တို့ ဖြစ်ပါတယ်။ ဒါတွေရဲ့ အတူတူ Style Rule တွေ အဆင့်ဆင့် ရေးကြည့်ရင်း Cascade စနစ်ကို ခံစားရပါမယ်။ Specificity နဲ့ `!important` ၊ Inheritance ၊ Units (px, em, rem, %) ၊ Math Functions တို့ကိုလည်း ဒီအပတ်မှာ ဖြည့်စွက် လေ့လာပါမယ်။

Daily အနေနဲ့ —
- Day 1-2: Lists ၊ Tables ၊ Forms Style
- Day 3-4: Navigation Bars နဲ့ Dropdowns
- Day 5-6: Pseudo-class ၊ Pseudo-element ၊ Specificity ၊ `!important`
- Day 7: challenges ထဲက Nav Bar Challenge ကို ကိုယ်တိုင် ဆောက်ကြည့်ပါ

မှတ်ချက် — `!important` ကို နည်းနည်းနဲ့ သုံးတာ ကောင်းပေမဲ့ နေ့စဉ်သုံးရင် Style ထိန်းချုပ်ရခက်တာကို သတိချပ်ပါ။

### Week 4 — Advanced Visual Effects

ဒီအပတ်မှာ Website တွေ ပိုလှပစေတဲ့ Visual Effect တွေကို သင်ယူပါမယ်။ Gradient ၊ Box-shadow ၊ Rounded Corners တို့နဲ့ Card နဲ့ Button တွေ ပေါ်လွင်အောင် ၊ Transition နဲ့ `:hover` တွဲ၍ ချောမွေ့တဲ့ Interaction တွေ ပြုလုပ်ပါမယ်။ Transform 2D/3D နဲ့ Animation (keyframes) တို့ဖြင့် Element လှုပ်ရှားစေနည်းတွေကိုလည်း လေ့လာပါတယ်။ Custom Fonts နဲ့ Text Effects ကို ထည့်ပြီး ကိုယ်ပိုင်အနေအထား ဖန်တီးပါမယ်။

Daily အနေနဲ့ —
- Day 1-2: Gradients နဲ့ Shadows
- Day 3-4: Transition နဲ့ Transform 2D/3D
- Day 5-6: Animation နဲ့ Custom Fonts
- Day 7: Rounded Corners ၊ Text Effects ၊ Tooltip တို့ကို ပေါင်းစပ်ပြီး Card တစ်ခု အလှဆင်ပါ

မှတ်ချက် — Transition မသုံးဘဲ hover ပြောင်းတာက ရုတ်တရက် ဖြစ်ပြီး Transition သုံးမှ ကျွမ်းကျင်တဲ့ ခံစားမှု ရပါတယ်။

### Week 5 — Flexbox/Grid နဲ့ Responsive

ဒီအပတ်မှာ ခေတ်မီ Layout ဒီဇိုင်း အတွက် Flexbox နဲ့ Grid ကို လေ့လာပြီး Media Query နဲ့ စက်အမျိုးမျိုး အတွက် ပြင်ဆင်ပါမယ်။ `justify-content` ၊ `align-items` ၊ `gap` စတဲ့ Flexbox key concept များ၊ Grid ရဲ့ `grid-template-columns` ၊ `auto-fit` စတဲ့ နည်းများ၊ Mobile-first စဉ်းစားနည်းနဲ့ `@media` Query ကို လက်တွေ့ သုံးကြည့်ပါမယ်။

Daily အနေနဲ့ —
- Day 1-2: Flexbox — စင်တာချခြင်း ၊ item စီစဉ်ခြင်း ၊ Nav/Footer layout
- Day 3-4: Grid — Card Grid ၊ 2-column layout ၊ auto-fit
- Day 5-6: Media Query — `@media (max-width: ...)` နဲ့ screen လိုက်လျောညီထွေပြောင်းခြင်း
- Day 7: exercises ထဲက Homepage ကို Flexbox/Grid ဖြင့် ပြန်ပြင်ပါ

မှတ်ချက် — Flexbox က တစ်ဖက်တည်း Layout၊ Grid က နှစ်ဖက်စလုံး Layout အတွက် သင့်လျော်ပြီး နှစ်ခုလုံးကို အခြေအနေအလိုက် ရွေးသုံးတတ်ရပါမယ်။

### Week 6 — References နဲ့ Certificate

နောက်ဆုံး သီတင်းပတ်မှာ References (px နဲ့ em ယှဉ်ချက် ၊ Selector နဲ့ Property cheat sheets) ကို ကြည့်ရင်း သင်ခန်းစာ တစ်ခုလုံး ပြန်လည် သုံးသပ်ပါမယ်။ website.mdx မှာ ရေးပြထားတဲ့ marketing site ကို ကိုယ်တိုင် အပြည့်အစုံ ဆောက်ကြည့်ပြီး ကိုယ့်ရဲ့ ကျွမ်းကျင်မှုကို ပေါင်းစည်းကြည့်ပါမယ်။ နောက်ဆုံး Career အတွက် interview-prep.mdx ကိုပါ ဖြေဆို လေ့ကျင့်နိုင်ပါတယ်။

Daily အနေနဲ့ —
- Day 1-2: References နဲ့ Optimization ၊ Accessibility ပြန်ဖတ်ခြင်း
- Day 3-5: Full Website Project — Nav ၊ Hero ၊ Cards ၊ Footer အားလုံး Style လုပ်ပြီး responsive ပြင်ပါ
- Day 6: interview-prep.mdx မေးခွန်းများ ဖြေဆို ပြင်ဆင်ပါ
- Day 7: Final Quiz ဖြေဆိုပြီး Certificate ရယူပါ

မှတ်ချက် — Final Quiz ဖြေတုန်း Code Editor မဖွင့်ဘဲ ဦးနှောက်နဲ့ပဲ ဖြေကြည့်ပါ — မဖြေနိုင်တဲ့ မေးခွန်း ရှိရင် ပြန်လေ့လာဖို့ အချိန် ယူပါ။

### လေ့လာမှု အောင်မြင်ရေး Tip များ

- တစ်နေ့ မိနစ် ၃၀ ပုံမှန် လုပ်တာက ရက် ၂ ရက် ပြင်းပြင်းထန်ထန် လုပ်တာထက် မှတ်မိမှု ပိုကောင်းပါတယ်။
- Code Example တိုင်းကို Copy မလုပ်ဘဲ ကိုယ်တိုင် ပြန်ရိုက်ပါ — Muscle Memory တည်ဆောက်ပါမယ်။
- အပတ်တိုင်းရဲ့ နောက်ဆုံးရက်မှာ လေ့ကျင့်ခန်း ပြန်လုပ်ပြီး မဖြေနိုင်တာတွေကို ချရေးမှတ်ထားပါ။

မှတ်ချက် — ကိုယ့်အရှိန်နဲ့ လေ့လာပြီး ၆ ပတ်ထက် ပိုကြာရင် စိတ်မပူပါနဲ့ — schedule က အကိုးအကားသာ ဖြစ်ပါတယ်။
