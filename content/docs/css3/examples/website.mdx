ဒီသင်ခန်းစာမှာ သင်ယူပြီးတဲ့ CSS အသိပညာအားလုံးကို စုစည်းပြီး လက်တွေ့အလုပ်လုပ်တဲ့ marketing website လေးတစ်ခု ဆောက်ကြည့်ကြမယ်။ Section တစ်ခုချင်းစီကို HTML နဲ့ CSS ခွဲရေးပြီး နောက်ဆုံးမှာ တစ်ခုတည်းသော full page code အဖြစ် ပေါင်းပြပါမယ်။

### အခြေခံ Setup — CSS Variables နဲ့ Reset

Website တစ်ခုလုံးမှာ ပြန်သုံးမယ့် အရောင်၊ အကွာအဝေးတွေကို CSS variable (`--primary`, `--dark` စသဖြင့်) နဲ့ သတ်မှတ်ထားရင် နောက်ပိုင်း တစ်နေရာတည်းပြင်ရုံနဲ့ တစ်ဆိုဒ်လုံး ပြောင်းလဲသွားပါတယ်။ Browser ၏ default margin တွေကို ပယ်ဖို့ reset လည်း လုပ်ထားရပါမယ်။

**ဥပမာ -**

```css
:root {
  --primary: #1d3557;
  --accent: #e63946;
  --light: #f1faee;
  --muted: #6c757d;
  --radius: 10px;
}
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
body {
  font-family: Arial, sans-serif;
  line-height: 1.6;
  color: var(--primary);
}
```

မှတ်ချက် — `:root` ရွေးတဲ့နေရာမှာ variable တွေ သတ်မှတ်ပြီး `var(--primary)` နဲ့ ပြန်သုံးပါတယ်။ `*` selector က element အားလုံးကို ရွေးလို့ reset အတွက် အဆင်ပြေပါတယ်။

### Navigation Bar

ထိပ်မှာ brand နာမည်နဲ့ nav link တွေကို Flexbox သုံးပြီး နှစ်ဖက် ခွဲလိုက်တာက ဒီဇိုင်း ရှင်းပါတယ်။ Mobile မှာလည်း ကောင်းကောင်း အလုပ်လုပ်ဖို့ `flex-wrap` ပါ ထည့်ထားပါမယ်။

**ဥပမာ -**

```html
<header class="navbar">
  <div class="brand">Takkatho</div>
  <nav>
    <a href="#home">ပင်မ</a>
    <a href="#courses">သင်တန်းများ</a>
    <a href="#contact">ဆက်သွယ်ရန်</a>
  </nav>
</header>
```

မှတ်ချက် — `nav` ထဲက link တွေက inline element ဖြစ်လို့ nav container ကို flex လုပ်မှသာ ဘေးချင်းကပ် စီပြီး gap ပေးနိုင်ပါတယ်။

**ဥပမာ -**

```css
.navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  flex-wrap: wrap;
  padding: 16px 24px;
  background: var(--light);
  position: sticky;
  top: 0;
}
.navbar .brand {
  font-weight: bold;
  font-size: 22px;
  color: var(--accent);
}
.navbar nav {
  display: flex;
  gap: 20px;
}
.navbar a {
  text-decoration: none;
  color: var(--primary);
}
.navbar a:hover {
  color: var(--accent);
}
```

မှတ်ချက် — `position: sticky; top: 0;` က စာရွက်ရစဉ် nav ကို အပေါ်မှာ ကပ်နေစေပြီး `space-between` က brand နဲ့ link ကို နှစ်ဖက် ခွဲပေးပါတယ်။

### Hero Section

Hero က ဝင်လာသူနဲ့ ပထမဆုံး ထိတွေ့ရတဲ့ ကြီးမားတဲ့ ကြိုဆိုရေး ဧရိယာ ဖြစ်ပါတယ်။ Gradient နောက်ခံနဲ့ စင်တာချ စာသား သုံးပြီး ထင်ရှားအောင် လုပ်ပါမယ်။

**ဥပမာ -**

```html
<section class="hero" id="home">
  <h1>Programming ကို လွတ်လပ်စွာ သင်ယူပါ</h1>
  <p>မြန်မာလို ရှင်းပြထားတဲ့ သင်ခန်းစာများနဲ့ စတင်လိုက်ပါ။</p>
  <a class="hero-btn" href="#courses">သင်တန်းများ ကြည့်ရန်</a>
</section>
```

မှတ်ချက် — Hero ရဲ့ link က `#courses` ဆီ ညွှန်းထားလို့ နှိပ်လိုက်ရင် အောက်က cards section ဆီ ချောမွေ့စွာ scroll သွားနိုင်ပါတယ်။

**ဥပမာ -**

```css
.hero {
  background: linear-gradient(135deg, #1d3557, #457b9d);
  color: #fff;
  text-align: center;
  padding: 80px 20px;
}
.hero h1 {
  font-size: 42px;
  margin-bottom: 12px;
}
.hero p {
  font-size: 18px;
  margin-bottom: 24px;
}
.hero-btn {
  display: inline-block;
  padding: 12px 28px;
  background: var(--accent);
  color: #fff;
  text-decoration: none;
  border-radius: var(--radius);
  transition: transform 0.2s ease;
}
.hero-btn:hover {
  transform: scale(1.05);
}
```

မှတ်ချက် — `transform: scale(1.05)` က hover မှာ button ကို နည်းနည်း ကြီးစေပြီး `transition` နဲ့ ချောမွေ့အောင် ပြုလုပ်ထားပါတယ်။

### Cards Grid

Course ၃ ခုကို card ၃ ခုဖြင့် ပြပါမယ်။ CSS Grid ရဲ့ `repeat(auto-fit, minmax(...))` က screen အကျယ်အလိုက် column အရေအတွက်ကို အလိုအလျောက် ပြောင်းပေးလို့ responsive ဖြစ်ပါတယ်။

**ဥပမာ -**

```html
<section class="cards" id="courses">
  <div class="card">
    <h3>HTML5</h3>
    <p>Website ၏ အခြေခံ အဆောက်အဦ</p>
  </div>
  <div class="card">
    <h3>CSS3</h3>
    <p>Website ကို လှပအောင် အလှဆင်ခြင်း</p>
  </div>
  <div class="card">
    <h3>JavaScript</h3>
    <p>Website ကို အသက်ဝင်စေခြင်း</p>
  </div>
</section>
```

မှတ်ချက် — Card တစ်ခုစီက အကြောင်းအရာ သီးခြား ဖြစ်လို့ `article` tag နဲ့ ရေးရင်လည်း semantic ပိုကောင်းပါတယ် — ဒီမှာ `div` နဲ့ပဲ ထားပါမယ်။

**ဥပမာ -**

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 20px;
  padding: 40px 24px;
  max-width: 900px;
  margin: 0 auto;
}
.card {
  background: #fff;
  border: 1px solid #ddd;
  border-radius: var(--radius);
  padding: 24px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
}
.card h3 {
  margin-bottom: 8px;
  color: var(--accent);
}
```

မှတ်ချက် — `auto-fit` + `minmax(220px, 1fr)` က screen ကျယ်ချိန် ၃ column၊ ကျဉ်းချိန် ၁ column အထိ ကိုယ်တိုင် ပြောင်းလဲပေးပြီး media query မလိုဘဲ responsive ဖြစ်စေပါတယ်။

### Footer

Footer မှာ copyright စာသားနဲ့ ဆက်သွယ်ရန် link ကို ထားပါမယ်။ Flexbox သုံးပြီး ဘေးချင်းကပ် ခွဲထားနိုင်ပြီး mobile မှာ အောက်ကို ချ စီစဉ်နိုင်ဖို့ wrap ပါ ထည့်ပါမယ်။

**ဥပမာ -**

```html
<footer class="footer" id="contact">
  <p>2026 Takkatho — မြန်မာ Programming School</p>
  <a href="mailto:hello@takkatho.com">hello@takkatho.com</a>
</footer>
```

မှတ်ချက် — `mailto:` link က နှိပ်လိုက်တာနဲ့ email application ကို ဖွင့်ပေးပါတယ်။

**ဥပမာ -**

```css
.footer {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  gap: 12px;
  padding: 24px;
  background: var(--primary);
  color: #fff;
}
.footer a {
  color: #fff;
}
```

မှတ်ချက် — Footer ၏ background က `var(--primary)` မို့ site ၏ အဓိကအရောင်နဲ့ တစ်ထပ်တည်း ကိုက်ညီနေပြီး header hero တို့နဲ့ အရောင် သဟဇာတ ဖြစ်ပါတယ်။

### Responsive — Media Query

Card grid က ကိုယ်တိုင် responsive ဖြစ်ပေမဲ့ သေးငယ်တဲ့ screen အတွက် စာလုံးအရွယ်အစားနဲ့ padding တွေကို `@media` rule ဖြင့် ချိန်ပါမယ်။ Mobile-first စဉ်းစားရင် `min-width` နဲ့ ရေးတာ၊ Desktop အတွက် ချိန်ချင်ရင်တော့ `max-width` နဲ့ ရေးပါတယ်။

**ဥပမာ -**

```css
@media (max-width: 600px) {
  .hero h1 {
    font-size: 28px;
  }
  .navbar {
    justify-content: center;
    text-align: center;
  }
}
```

မှတ်ချက် — `max-width` ရဲ့ rule က screen ကျဉ်းလာမှ အသက်ဝင်ပြီး Hero ခေါင်းစဉ် သေးစေကာ nav ကို စင်တာချပေးပါတယ်။
