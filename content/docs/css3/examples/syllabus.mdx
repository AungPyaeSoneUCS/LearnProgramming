ဒါက Takkatho CSS3 သင်တန်းရဲ့ သင်ရိုးညွှန်းတမ်း အပြည့်အစုံ ဖြစ်ပါတယ်။ သင်ခန်းစာတွေကို chapter ကြီး ၆ ခုဖြင့် ခွဲထားပြီး တစ်ခုစီမှာ လေ့လာမယ့် အကြောင်းအရာနဲ့ သင်ခန်းစာ အရေအတွက် ပါပါတယ်။ အစမှ အဆုံး အစဉ်လိုက် လေ့လာနိုင်သလို စိတ်ဝင်စားတဲ့ chapter ကို ရွေးပြီးလည်း လေ့လာနိုင်ပါတယ်။

### Chapter စာရင်း

အောက်မှာပါတဲ့ ဇယားက chapter တွေ၊ တစ်ခန်းစီရဲ့ အဓိက အကြောင်းအရာနဲ့ သင်ခန်းစာ အရေအတွက်ကို ဖော်ပြထားပါတယ်။ Flexbox/Grid နဲ့ အထက် Chapter တွေက ထပ်မံ ရေးသားမည့် အပိုင်းများ ဖြစ်လို့ အရေအတွက်က ခန့်မှန်းချက် ဖြစ်ပါတယ်။

| Chapter | သင်ကြားမည့် အကြောင်းအရာ | သင်ခန်းစာ အရေအတွက် |
| --- | --- | --- |
| Tutorial | Selector၊ Box Model၊ Layout၊ Text ၊ Component နဲ့ Specificity စသော အခြေခံ အားလုံး | ၄၉ |
| Advanced | Gradient ၊ Shadow ၊ Transform ၊ Transition ၊ Animation ၊ ပုံအဆင့်မြင့် ပြင်ဆင်မှု | ၂၀ |
| Flexbox နှင့် Grid | Flexible box နဲ့ Grid ကို အသုံးပြုသော ခေတ်မီ Layout | ၁၂ (ခန့်မှန်း) |
| Responsive | Media Query နဲ့ မိုဘိုင်းပထမ ဒီဇိုင်းနည်းလမ်းများ | ၈ (ခန့်မှန်း) |
| References | Property နှင့် Selector ကိုးကားစာရင်းများ | ၄ (ခန့်မှန်း) |
| Certificate | သင်တန်းဆုံးခန်း Test နဲ့ လက်မှတ် ရယူမှု | ၁ |

မှတ်ချက် — သင်ခန်းစာ စုစုပေါင်း ခန့်မှန်းချက် ၉၄ ခု ဖြစ်ပြီး တစ်နေ့ တစ်ခုစီ စနစ်တကျ လေ့လာရင် ၆ ပတ်အတွင်း ပြီးစီးနိုင်ပါတယ်။

### Tutorial — CSS အခြေခံ (Chapter 1)

ဒီ Chapter က သင်တန်းရဲ့ အုတ်မြစ် ဖြစ်ပါတယ်။ Syntax နဲ့ Selector ကစပြီး Element တွေကို ရွေးချယ်နည်း (element, class, id, attribute, combinator) ၊ Style ထည့်သွင်းနည်း ၃ မျိုး ၊ Box Model (content, padding, border, margin) ၊ margin ၊ padding ၊ border ၊ height-width စတာတွေကို ကိုင်တွယ် သင်ကြားပေးပါတယ်။ Float ၊ Display ၊ Position (absolute, relative, fixed, sticky) ၊ z-index ၊ overflow စတဲ့ layout နဲ့ ဆိုင်တဲ့ အကြောင်းရာတွေလည်း ပါဝင်ပါတယ်။

ဒါတွေအပြင် Text ၊ Fonts ၊ Links ၊ Lists ၊ Tables ၊ Forms ၊ Navigation Bars ၊ Dropdowns ၊ Image Gallery ၊ Counters ကဲ့သို့သော Component အတွက် Style ရေးနည်း၊ Inline-block ၊ Opacity ၊ Units ၊ Math Functions ၊ Pseudo-class နဲ့ Pseudo-element ၊ Inheritance ၊ Specificity နဲ့ `!important` ၊ CSS Cascading ကို လက်တွေ့ နားလည်စေဖို့ အဆင့်ဆင့် ရှင်းပြထားပါတယ်။ Accessibility နဲ့ Optimization လိုမျိုး လက်တွေ့ website မှာ အရေးပါတဲ့ အကြောင်းအရာတွေလည်း ပါဝင်ပါတယ်။

ယခုအချိန် သင်ခန်းစာ ၄၉ ခု ရှိပြီး သင်တန်း၏ အရေးအကြီးဆုံး Chapter ဖြစ်ပါတယ်။

### Advanced — CSS အဆင့်မြင့် (Chapter 2)

အခြေခံကို ကျွမ်းကျင်ပြီးတဲ့နောက် Visual Effect တွေကို ဒီ Chapter မှာ သင်ယူရပါတယ်။ Color ၊ Gradient ၊ Background ၊ Border-image တို့ဖြင့် နောက်ခံနဲ့ မျက်နှာပြင် အလှဆင်ခြင်း၊ Rounded Corners နဲ့ Box-shadow ဖြင့် Card/Button အသွင်မြှင့်ခြင်း၊ Text Effects နဲ့ Custom Fonts ဖြင့် စာသား ပိုထင်ရှားစေခြင်း၊ Tooltip ပြုလုပ်ခြင်း စတာတွေ ပါဝင်ပါတယ်။

Transform 2D/3D ၊ Transition ၊ Animation (keyframes) တို့ဖြင့် Element ကို ရွေ့လျား ၊ လှုပ်ရှားစေနည်းတွေကိုလည်း လေ့လာရပြီး Image Styling ၊ Filters ၊ Shapes ၊ Object-fit ၊ Object-position ၊ Image Centering နဲ့ Image Modal စတဲ့ ပုံပြင်ဆင်မှု အဆင့်မြင့် နည်းလမ်းများစွာ ပါဝင်ပါတယ်။

ယခု သင်ခန်းစာ ၂၀ ခု ရှိပါတယ်။

### Flexbox နှင့် Grid — Layout အဆင့်မြင့် (Chapter 3)

Past ခေတ် float နဲ့ position ကို အားကိုးတဲ့ layout နေရာမှာ ယနေ့ခေတ်မှာ Flexbox နဲ့ Grid ကို သုံးပါတယ်။ Flexbox က item တွေကို တစ်ဖက်တည်း (row သို့မဟုတ် column) စီစဉ်ရာမှာ အားသန်ပြီး Grid က rows နဲ့ columns နှစ်ခုလုံး တစ်ပြိုင်နက် ထိန်းချုပ်နိုင်ပါတယ်။ Main axis ၊ Cross axis ၊ `justify-content` ၊ `align-items` ၊ `grid-template-columns` ၊ `gap` စတဲ့ key concept တွေအပြင် real layout နမူနာများ ပါဝင်ပါလိမ့်မယ်။

ခန့်မှန်း သင်ခန်းစာ ၁၂ ခု ရှိမယ် လို့ စီစဉ်ထားပါတယ်။

မှတ်ချက် — Flexbox နဲ့ Grid ကို တတ်ကျွမ်းထားခြင်းက modern responsive website တွေ ဆောက်ရာမှာ မရှိမဖြစ် ဖြစ်ပါတယ်။

### Responsive — စက်အမျိုးမျိုး အတွက် ဒီဇိုင်း (Chapter 4)

Phone ၊ tablet ၊ desktop အားလုံးမှာ website ကောင်းကောင်း ပြဖို့ `@media` Query ၊ viewport meta ၊ Relative Unit (rem, em, vw, vh, %) ၊ `max-width: 100%` ရှိသော image ၊ mobile-first စဉ်းစားနည်း စတာတွေကို ဒီ Chapter မှာ သင်ကြားပါမယ်။ Flexbox/Grid ကို responsive ပြောင်းလဲမှုနဲ့ တွဲသုံးနည်းတွေပါ ပါဝင်ပါလိမ့်မယ်။

ခန့်မှန်း သင်ခန်းစာ ၈ ခု ဖြစ်ပါတယ်။

### References — ကိုးကားစာရင်း (Chapter 5)

သင်ယူပြီး မေ့တတ်တဲ့ Property နဲ့ Selector တွေကို လိုအပ်တိုင်း ပြန်ရှာနိုင်ဖို့ အကျဉ်းချုပ် စာရင်းများ ဖြစ်ပါတယ်။ အရွယ်အစား (px နဲ့ em) ယှဉ်ပြချက် ၊ Selector ကိုးကား ၊ Property အမြန်ရှာ cheat-sheet ၂ ခုလောက် ပါဝင်ပြီး ၄ ခု ခန့် ထားရှိပါမယ်။ နောက်ဆုံး Chapter ဖြစ်ပေမဲ့ သင်ကြားစဉ်တစ်လျှောက် လိုအပ်တိုင်း ဖွင့်ကြည့်နိုင်ပါတယ်။

### Certificate — လက်မှတ် (Chapter 6)

နောက်ဆုံး Chapter မှာ သင်တန်းတစ်ခုလုံးကို အကျုံးဝင်တဲ့ Test တစ်ခု ပါဝင်ပြီး အောင်မြင်ရင် Takkatho ရဲ့ CSS Certificate ရရှိမှာ ဖြစ်ပါတယ်။ Test က Tutorial နဲ့ Advanced Chapter ရဲ့ သင်ခန်းစာတွေအပြင် Flexbox/Grid နဲ့ Responsive အကြောင်းရာတွေကိုပါ အကျုံးဝင်ထားပါတယ်။

### CSS3 သင်တန်း ထူးခြားချက်

- သင်ခန်းစာတိုင်းမှာ မြန်မာလို ရှင်းလင်းချက်၊ Code Example နဲ့ Practice ပါဝင်ပါတယ်။
- Examples ၊ Challenges ၊ Website ဆိုတဲ့ လက်တွေ့ လေ့ကျင့်ခန်း folder တစ်ခုစီ ရှိပါတယ်။
- Interview Prep ခေါင်းစဉ်နဲ့ အလုပ်လျှောက်တဲ့အခါ ပြင်ဆင်နိုင်ပါတယ်။

မှတ်ချက် — Syllabus က လမ်းပြမြေပုံသာ ဖြစ်ပြီး ကိုယ့်ရဲ့ ဦးတည်ချက်နဲ့ အချိန်အလိုက် chapter အစဉ်ကို လိုက်လျောညီထွေ ပြောင်းလဲနိုင်ပါတယ်။
