Flexbox (Flexible Box Layout) ဆိုတာ CSS3 မှာ မိတ်ဆက်ခဲ့တဲ့ **one-dimensional** layout model တစ်ခုပါ။ ဆိုလိုတာက container ထဲက item တွေကို **row** (အလျားလိုက်) သို့မဟုတ် **column** (ဒေါင်လိုက်) ဆိုတဲ့ ဦးတည်ချက် တစ်ခုတည်းအတိုင်း စီစဉ်ပေးနိုင်တာပဲ ဖြစ်ပါတယ်။ Old CSS မှာ ဒီလိုစီစဉ်ဖို့ float နဲ့ positioning တွေ သုံးရတာကြောင့် အဆင်မပြေမှုတွေ များစွာ ရှိခဲ့ပါတယ်။

### Flex Container နဲ့ Flex Item

Flexbox မှာ အဓိက အခန်းကဏ္ဍ နှစ်ခု ရှိပါတယ်။

- **Flex Container** — `display: flex` သတ်မှတ်ထားတဲ့ parent element ပါ။ Layout ကို ထိန်းချုပ်တဲ့ နေရာ ဖြစ်ပါတယ်။
- **Flex Item** — Container ရဲ့ အတွင်းတိုက်ရိုက်ရှိတဲ့ child element တွေပါ။ ဒီ item တွေကို container ကနေ စီစဉ်ပေးပါတယ်။

**ဥပမာ -**

```html
<div class="container">
  <div class="box">1</div>
  <div class="box">2</div>
  <div class="box">3</div>
</div>
```

မှတ်ချက် — `.container` က flex container ဖြစ်ပြီး အတွင်းက `.box` သုံးခုစလုံးက flex items တွေ ဖြစ်ပါတယ်။ Container မှာ flex မသတ်မှတ်ခင်က ဒီ box တွေက block element တွေမို့ အပေါ်ကနေ အောက်ကို စီစဉ်နေပါလိမ့်မယ်။

### display: flex — Container အဖြစ် သတ်မှတ်ခြင်း

Flexbox ကို စတင်အသုံးပြုဖို့ container ပေါ်မှာ `display: flex` တစ်ကြောင်းပဲ ရေးလိုက်ရုံပါပဲ။ ဒါက ဒီ CSS3 feature ရဲ့ အလွန်ရိုးရှင်းပြီး အစွမ်းထက်တဲ့ အပိုင်းပဲ ဖြစ်ပါတယ်။

**ဥပမာ -**

```css
.container {
  display: flex;
}
```

မှတ်ချက် — `display: flex` သတ်မှတ်ပြီးတာနဲ့ အတွင်းက `.box` တွေအားလုံးက မူလ default ဖြစ်တဲ့ stacked layout ကနေ လှည့်ပြီး row အနေနဲ့ ဘေးချင်းကပ်ပြီး တစ်တန်းတည်း ဖြစ်သွားပါတယ်။

### Main Axis နဲ့ Cross Axis

Flexbox မှာ axis (ဝင်ရိုး) နှစ်ခုရှိပြီး ဒါတွေက layout တစ်ခုလုံးရဲ့ အုတ်မြစ် ဖြစ်ပါတယ်။

- **Main Axis** — item တွေ စီစဉ်တဲ့ အဓိက ဦးတည်ချက်။ `flex-direction: row` ဖြစ်ရင် အလျားလိုက်၊ column ဖြစ်ရင် ဒေါင်လိုက် ဖြစ်ပါတယ်။
- **Cross Axis** — main axis ကို ထောင့်မှန်ကျတဲ့ ဝင်ရိုး။ row ဆိုရင် ဒေါင်လိုက်၊ column ဆိုရင် အလျားလိုက် ဖြစ်ပါတယ်။

**ဥပမာ -**

```css
.container {
  display: flex;
  flex-direction: row;
  /* Main axis = ဘေး → main axis မှာ စီစဉ်တယ် */
  /* Cross axis = အပေါ် → hmm, ဒီမှာတော့ ထောင့်မှန်ကျတဲ့ ဒေါင်လိုက် */
}
```

မှတ်ချက် — `flex-direction` က main axis ကို သတ်မှတ်ပေးတဲ့ property ဖြစ်ပြီး default တန်ဖိုးက `row` ဖြစ်ပါတယ်။ ဒါကြောင့် `display: flex` တစ်လုံးတည်းနဲ့ကို item တွေ အလျားလိုက် စီစဉ်ပေးတာ ဖြစ်ပါတယ်။

### Basic Row Layout

Item တွေကို row အနေနဲ့ စီပြီး သူတို့ရဲ့ အရွယ်အစား၊ အကွာအဝေးတွေကို သတ်မှတ်ကြည့်ရအောင်။

**ဥပမာ -**

```css
.container {
  display: flex;
}

.box {
  width: 100px;
  height: 100px;
  background-color: tomato;
  margin: 5px;
}
```

မှတ်ချက် — Container က အကျယ်အပြည့် ယူထားပေမယ့် item တွေကတော့ သူတို့ရဲ့ width အတိုင်း ဘေးချင်းကပ် စီထွက်လာပြီး container ရဲ့ ဘယ်ဘက် ကနေ စတင်ပါတယ်။

### Flexbox ဘာကြောင့် အသုံးဝင်လဲ

ဂန္တဝင် method တွေနဲ့ ယှဉ်ကြည့်မယ်ဆိုရင် Flexbox က အောက်ပါ အားသာချက်တွေ ရှိပါတယ်။

- Item တွေကို main axis တဖက်တည်းမှာ အလွယ်တကူ ချိန်ညှိနိုင်ခြင်း
- Item တွေကြား အကွာအဝေး ထိန်းချုပ်ရတာ လွယ်ကူခြင်း
- ဒေါင်လိုက် center လုပ်ခြင်း လို အရင်က အခက်အခဲ ရှိခဲ့တဲ့ ကိစ္စတွေကို ရိုးရှင်းစွာ ဖြေရှင်းနိုင်ခြင်း

#### မှတ်ထားရမယ့် အချက်များ

- Flexbox သည် one-dimensional layout model ဖြစ်သည်။
- Flex layout စတင်ရန် `display: flex` ကို container တွင် သုံးရသည်။
- Main axis က item များ စီစဉ်ရာလမ်းကြောင်း၊ Cross axis က ၎င်းကို ထောင့်မှန်ကျသော လမ်းကြောင်း ဖြစ်သည်။
- `flex-direction: row` သည် item များကို အလျားလိုက် စီစဉ်ပေးသည်။
