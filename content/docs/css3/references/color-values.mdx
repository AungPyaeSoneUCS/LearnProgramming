### Named Color မိသားစုများ

CSS မှာ Color Name 140+ ရှိပြီး အရောင်ခံစားမှု (Warm/Cool/Neutral) အလိုက် အုပ်စုဖွဲ့ မှတ်သားနိုင်ပါတယ်။ အပူရောင်နွမ်းတွေက နွေးထွေးပြီး အားပြင်းသော ခံစားမှု ပေးပြီး အအေးရောင်နွမ်းတွေက အေးဆေးသော ခံစားမှု ပေးပါတယ်။

### Warm Colors — နွေးအုပ်သော အရောင်များ

အနီ ၊ လိမ္မော် ၊ အဝါ နဲ့ ပန်းရောင် စတဲ့ သွေးပူအရောင်တွေ ဖြစ်ပါတယ်။

| အရောင် | Color Name | HEX |
| ---- | ---- | ---- |
| အနီ | `red` | `#ff0000` |
| ခရမ်းနီ | `crimson` | `#dc143c` |
| ငရုတ်သီးရောင် | `tomato` | `#ff6347` |
| လိမ္မော် | `orange` | `#ffa500` |
| ရွှေရောင် | `gold` | `#ffd700` |
| ပန်းရောင် | `pink` | `#ffc0cb` |

### Cool Colors — အေးအုပ်သော အရောင်များ

အပြာ ၊ အစိမ်း ၊ စိမ်းပြာ ၊ ခရမ်း စတဲ့ အရောင်တွေ ဖြစ်ပါတယ်။

| အရောင် | Color Name | HEX |
| ---- | ---- | ---- |
| အပြာ | `blue` | `#0000ff` |
| ကောင်းကင်ပြာ | `skyblue` | `#87ceeb` |
| အစိမ်း | `green` | `#008000` |
| စိမ်းပြာ | `teal` | `#008080` |
| Cyan | `cyan` | `#00ffff` |
| ခရမ်းရောင် | `purple` | `#800080` |

### Neutral Colors — ဘက်မလိုက်သော အရောင်များ

အနက် ၊ အဖြူ ၊ မီးခိုး ၊ အညို စတဲ့ အရောင်တွေ ဖြစ်ပြီး Background နဲ့ စာသား အခြေခိုင်ဖို့ အသုံးများပါတယ်။

| အရောင် | Color Name | HEX |
| ---- | ---- | ---- |
| အမည်း | `black` | `#000000` |
| အဖြူ | `white` | `#ffffff` |
| မီးခိုးရောင် | `gray` | `#808080` |
| ငွေရောင် | `silver` | `#c0c0c0` |
| အညို | `brown` | `#a52a2a` |
| Beige | `beige` | `#f5f5dc` |

### Extended Named Colors

CSS Colors Level 4 မှာ နာမည် အသစ်တွေလည်း ထပ်တိုးလာပါတယ်။ `rebeccapurple` (`#663399`) ၊ `firebrick` (`#b22222`) ၊ `seagreen` (`#2e8b57`) ၊ `steelblue` (`#4682b4`) စတာတွေ ဖြစ်ပါတယ်။

### Opacity (အကြည်-အထူ) သတိပြုချက်

Alpha Channel ကို `rgba()` နဲ့သာ မဟုတ်ဘဲ ခေတ်ပေါ် 8-လုံး HEX `#RRGGBBAA` နဲ့လည်း သုံးလို့ ရပါတယ်။ ဥပမာ `#ff000080` က အနီ 50% အကြည် ဖြစ်ပါတယ်။

### Contrast ဂရုပြုချက်

အရောင်သုံးတိုင်း Background နဲ့ စာသား ခြားနားမှုကို စဉ်းစားပါ။ WCAG စံအရ ပုံမှန် စာသားအတွက် Contrast Ratio **4.5:1** အနည်းဆုံး လိုပါတယ်။ အဖြူ နောက်ခံပေါ်မှာ မီးခိုးဖျော့ စာသားတွေက ဖတ်ရခက်တဲ့အတွက် ရှောင်ပါ။

**ဥပမာ -**
```css
body {
  background-color: #f7f7f7;
  color: #222222;
}

.card {
  background-color: rgba(0, 0, 0, 0.05);
  border-color: #cccccc;
}

.btn {
  background-color: #2563eb;
  color: #ffffff;
}
```

မှတ်ချက် — နောက်ခံ ပေါ့သော အရောင်နဲ့ စာသား နက်သော အရောင် တွဲရင် Contrast ကောင်းပြီး ဖတ်ရ လွယ်ပါတယ်။

#### မှတ်ထားရမယ့် အချက်များ

- Warm — အနီ ၊ လိမ္မော် ၊ အဝါ ၊ ပန်းရောင် ။
- Cool — အပြာ ၊ အစိမ်း ၊ ခရမ်း ၊ စိမ်းပြာ ။
- Neutral — အမည်း ၊ အဖြူ ၊ မီးခိုး ၊ အညို ။
- 8-လုံး HEX နဲ့ Alpha အကြည် ထည့်နိုင်ပါတယ်။
- WCAG Contrast 4.5:1 ရအောင် ဆောင်ရွက်ပါ။
