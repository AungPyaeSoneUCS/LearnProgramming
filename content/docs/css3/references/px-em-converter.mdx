### px ကို em/rem သို့ ပြောင်းနည်း

Browser Default Root Font Size က **16px** ဖြစ်လို့ `1em` နဲ့ `1rem` နှစ်ခုလုံး 16px နဲ့ ညီပါတယ်။ px တန်ဖိုးကို em ပြောင်းဖို့ **Root Size နဲ့ စားရုံပါပဲ** ။ ဥပမာ `32px ÷ 16 = 2em` ဖြစ်ပါတယ်။

စည်းမျဉ်း — `px / root-font-size = em` ။ Root Font Size ကို ကိုယ်တိုင် ပြောင်းထားရင် အဲဒီတန်ဖိုး နဲ့သာ စားပါ။

### em နဲ့ rem ခြားနားချက်

**em** က မိဘ Element (Parent) ရဲ့ Font Size ကို အခြေခံပြီး **rem** က Root Element `<html>` ရဲ့ Font Size ကိုသာ အခြေခံပါတယ်။ Nesting နက်လာရင် `em` က ပုံစံအလိုက် ပွားနိုင်ပြီး `rem` က နေရာတိုင်း တည်ငြိမ်နေပါတယ်။ Default Root 16px မှာတော့ နှစ်ခုလုံး တူညီပါတယ်။

မှတ်ချက် — 16px က 1em ၊ 32px က 2em ဆိုသလို 16 နဲ့ စားရုံဖြင့် အားလုံး ပြောင်းလို့ ရပါတယ် ၊ ကိန်းမြှောက် မရှိရင်လည်း ဒဿမနဲ့ ရေးနိုင်ပါတယ်။

### Manual Conversion ဥပမာ

Root Font Size 16px မှာ လိုချင်တဲ့ px တန်ဖိုးကို 16 နဲ့ စားပြီး em/rem ထဲ ထည့်ရေးပါတယ်။

**ဥပမာ -**
```css
html {
  font-size: 16px;
}

h1 {
  font-size: 2rem;       /* 32px */
  margin-bottom: 1.5rem; /* 24px */
}

p {
  font-size: 0.875rem;   /* 14px */
  line-height: 1.6;
}
```

မှတ်ချက် — Comment တွေမှာ မူရင်း px တန်ဖိုးကို ရေးထားရင် အနာဂတ်မှာ ပြန်ကြည့်ရ လွယ်ပြီး Root Size ပြောင်းရင်လည်း အားလုံး အချိုးကျ ပြောင်းပါတယ်။

#### မှတ်ထားရမယ့် အချက်များ

- Default Root Size က 16px ။
- Manual Conversion — `px / 16 = em` ။
- `em` က Parent ၊ `rem` က Root တို့ကို အခြေခံပါတယ်။
- Root Size ပြောင်းရင် ဇယားပါ တန်ဖိုးတွေ ပြောင်းသွားပါတယ်။
