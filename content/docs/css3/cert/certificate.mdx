### CSS Certificate စာမေးပွဲ

ဒီသင်ခန်းစာက CSS3 သင်တန်း တစ်သင်တန်းလုံးရဲ့ နောက်ဆုံး Certificate စာမေးပွဲ ဖြစ်ပါတယ်။ ဒီ စာမေးပွဲကို ဖြေဆို အောင်မြင်ခဲ့ရင် သင်တန်း တစ်လျှောက်လုံး သင်ယူထားတဲ့ အကြောင်းအရာတွေကို ခြုံငုံ နားလည်ပြီးသား ဖြစ်တယ်လို့ အသိအမှတ်ပြုနိုင်ပါတယ်။

မေးခွန်း (၂၀) လုံးက Tutorial ၊ Advanced ၊ Flexbox ၊ Grid ၊ Responsive ၊ SASS ၊ Examples နဲ့ References အပါအဝင် သင်တန်း အပိုင်း အားလုံးကို ခြုံငုံထားတာ ဖြစ်ပါတယ်။ မေးခွန်း တစ်ခုစီမှာ အဖြေမှန် တစ်ခုသာ ရှိပြီး အဖြေ မသေချာရင် ဂရုတစိုက် စဉ်းစားပါ — အမှား တစ်ခုစီက နောက်ထပ် လေ့လာရမယ့် နေရာကို ပြပေးမှာ ဖြစ်လို့ အမှားတွေကနေလည်း အကျိုးရှိပါတယ်။

### စာမေးပွဲအတွက် လေ့လာသင့်သည့် အကြောင်းအရာများ

- Syntax နဲ့ Selector များ (ID ၊ Class ၊ Attribute ၊ Pseudo-class)
- Box Model — `margin` ၊ `padding` ၊ `border` ၊ content နဲ့ `box-sizing`
- Color ၊ Background နဲ့ Gradient များ
- `position` (`relative` ၊ `absolute` ၊ `fixed`) ၊ `z-index` နဲ့ `overflow`
- Flexbox — `flex-direction` ၊ `justify-content` ၊ `align-items`
- Grid — `grid-template-columns` ၊ `grid-template-areas` ၊ `gap`
- Responsive Design နဲ့ `@media` query
- `transition` ၊ Animation နဲ့ `transform` များ
- CSS Variables (custom properties) ၊ Units (`px` ၊ `em` ၊ `rem`) နဲ့ Specificity
- `display` ၊ `float` ၊ List ၊ Table ၊ Text နဲ့ Font များ
