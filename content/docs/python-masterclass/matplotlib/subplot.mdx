အချို့သော အခြေအနေများတွင် data များကို side-by-side နှိုင်းယှဉ်ရန် chart တစ်ခုတွင် charts အများအပြား ထည့်ချင်ပါသည်။ subplot() function က ဤသို့ လုပ်ဆောင်နိုင်ပါသည်။

## Subplot Function

subplot() သည် arguments သုံးခုကို လက်ခံပါသည်။

```
plt.subplot(rows, columns, index)
```

- **rows**: subplot ၏ row အရေအတွက်
- **columns**: subplot ၏ column အရေအတွက်
- **index**: subplot ၏ နေရာ (1 မှ စတင်)

## Subplot ဖြင့် Single Chart ဖန်တီးခြင်း

```
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [1, 4, 9, 16]

plt.subplot(1, 2, 1)
plt.plot(x, y)
plt.title("First")

plt.subplot(1, 2, 2)
plt.plot(x, y)
plt.title("Second")

plt.show()
```

► chart 2 ခုကို 1 row 2 columns ခွဲ၍ ပြသပါသည်။

## More Subplots များ

2 rows 2 columns ဖြင့် charts 4 ခု ဖန်တီးပါသည်။

```
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [1, 4, 9, 16]

plt.subplot(2, 2, 1)
plt.plot(x, y)
plt.title("Plot 1")

plt.subplot(2, 2, 2)
plt.plot([1, 2, 3], [3, 1, 3])
plt.title("Plot 2")

plt.subplot(2, 2, 3)
plt.plot([1, 2, 3], [2, 4, 6])
plt.title("Plot 3")

plt.subplot(2, 2, 4)
plt.plot([1, 2, 3], [5, 2, 1])
plt.title("Plot 4")

plt.show()
```

► Charts 4 ခုကို 2x2 grid ဖြင့် ပြသပါသည်။

## Title ၏ Overlap

subplots များစွာတွင် titles များ တစ်ခုနှင့်တစ်ခု ထိရောက်နိုင်ပါသည်။ ၎င်းကို plt.tight_layout() ဖြင့် ပြုပြင်နိုင်ပါသည်။

```
import matplotlib.pyplot as plt

plt.subplot(1, 2, 1)
plt.plot([1, 2, 3], [1, 4, 9])
plt.title("Sine")

plt.subplot(1, 2, 2)
plt.plot([1, 2, 3], [2, 3, 5])
plt.title("Random")

plt.tight_layout()
plt.show()
```

Subplots များသည် comparison နှင့် related data များကို ပြသရန် အကောင်းဆုံး နည်းလမ်း ဖြစ်ပါသည်။
