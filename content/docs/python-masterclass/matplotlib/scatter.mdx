Scatter plot သည် data points များကို dots များအဖြစ် plot ပြုလုပ်ပြီး variables နှစ်ခုအကြား ဆက်စပ်မှုကို ပြသရန် အသုံးပြုပါသည်။

## Scatter plot ဆိုသည်မှာ

scatter() function သည် data ၏ random points များအကြား relationship များကို ပြသရန် scatter (random points) plots များကို ဆွဲပါသည်။

```
import matplotlib.pyplot as plt

x = [5, 7, 8, 7, 2]
y = [99, 86, 87, 88, 100]

plt.scatter(x, y)
plt.show()
```

► Points 5 ခုကို scatter plot အဖြစ် ပြသပါသည်။

## Scatter Plot အတွက် Data များ

Random data များဖြင့် scatter plot များစွာ ဖန်တီးနိုင်ပါသည်။

```
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5, 6]
y = [2, 4, 6, 8, 10, 12]

plt.scatter(x, y)
plt.show()
```

## Compare Scatter Plots များ

Scatter plots နှစ်ခုကို တူညီသော chart သီးခြားတွင် နှိုင်းယှဉ်နိုင်ပါသည်။

```
import matplotlib.pyplot as plt

x1 = [5, 7, 8, 2]
y1 = [99, 86, 87, 100]

x2 = [3, 4, 9, 6]
y2 = [100, 90, 80, 85]

plt.scatter(x1, y1, color='r')
plt.scatter(x2, y2, color='g')
plt.show()
```

► Red နှင့် green scatter points များ တစ်ချိန်တည်း ပေါ်လာပါသည်။

## Colors Map

Colors များကို colormap ဖြင့် data အရ တဖြည်းဖြည်း ပြောင်းနိုင်ပါသည်။

```
import numpy as np
import matplotlib.pyplot as plt

x = np.random.randint(100, size=50)
y = np.random.randint(100, size=50)
colors = np.random.randint(100, size=50)

plt.scatter(x, y, c=colors, cmap='viridis')
plt.colorbar()
plt.show()
```

► Color bar ပါသော colormap scatter plot ကို ဆွဲပါသည်.

## Size parameters

s parameter ဖြင့် dots ၏ အရွယ်အစားကို သတ်မှတ်ပါသည်။

```
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]
sizes = [20, 50, 100, 200, 500]

plt.scatter(x, y, s=sizes)
plt.show()
```

► Dots များ၏ အရွယ်အစား ပြောင်းလဲပါသည်။

Scatter plots များသည် correlation ၏ အားနည်းချက်ကို ကြည့်ရှုရန် အကောင်းဆုံး ဖြစ်ပါသည်။
