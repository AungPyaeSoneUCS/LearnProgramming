__init__() method သည် class ၏ constructor ဖြစ်ပြီး object အသစ်တစ်ခုကို ဖန်တီးသည့်အခါ အလိုအလျောက် ခေါ်ဝေါ်ပါသည်။ ၎င်းကို object ၏ initial state ကို သတ်မှတ်ရန် သုံးပါသည်။

## __init__() Method ဆိုသည်မှာ

Object တစ်ခုကို ဖန်တီးသောအခါ attribute များကို initialize လုပ်ရန် __init__() ကို သုံးပါသည်။

```
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

p1 = Person("John", 36)
print(p1.name)
print(p1.age)
```

► Output:
```
John
36
```

## Arguments များကို လက်ခံခြင်း

__init__() သည် arguments များကို လက်ခံနိုင်ပြီး object များကို data နှင့်အတူ ဖန်တီးနိုင်ပါသည်။

```
class Student:
    def __init__(self, name, grade, school):
        self.name = name
        self.grade = grade
        self.school = school

s1 = Student("Aung", "Grade 10", "BBHS")
print(s1.name, s1.grade, s1.school)
```

## Default Values

Parameters များတွင် default values ထားနိုင်ပါသည်။

```
class Person:
    def __init__(self, name, age=18):
        self.name = name
        self.age = age

p1 = Person("John")
print(p1.name, p1.age)
```

► Output: John 18

## Instance များကြား ခွဲခြားခြင်း

__init__() တွင် self သည် object တစ်ခုစီ၏ attributes များကို သီးသန့်ထားပေးပါသည်။

```
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

emp1 = Employee("Alice", 5000)
emp2 = Employee("Bob", 6000)
print(emp1.name, emp1.salary)
print(emp2.name, emp2.salary)
```

► Output:
```
Alice 5000
Bob 6000
```
