Object-Oriented Programming (OOP) သည် program ကို objects များအဖြစ် စုစည်းတည်ဆောက်သော နည်းလမ်း တစ်ခု ဖြစ်ပါသည်။ Object တစ်ခုတွင် data (attributes) နှင့် behavior (methods) နှစ်ခုလုံး ပါဝင်ပါသည်။

## Classes နှင့် Objects

- **Class**: Object များ၏ template/blueprint ဖြစ်ပါသည်။
- **Object**: Class မှ ဖန်တီးထားသော instance ဖြစ်ပါသည်။

## Python Class တစ်ခု ဖန်တီးခြင်း

Python တွင် class တစ်ခုကို class keyword ဖြင့် ဖန်တီးပါသည်။

```
class MyClass:
    x = 5
```

## Object ဖန်တီးခြင်း

```
class MyClass:
    x = 5

p1 = MyClass()
print(p1.x)
```

► Output: 5

## OOP ၏ ဝါဒများ

- **Encapsulation**: Data များကို ရှင်းလင်းစွာ ပြင်ပမှ ခွင့်ပြုထားသော နည်းလမ်းများဖြင့်သာ ရယူနိုင်အောင် ကန့်သတ်ခြင်း
- **Inheritance**: Class တစ်ခုမှ အခြား class သို့ attributes နှင့် methods များ အမွေပေးခြင်း
- **Polymorphism**: Object မှ ၎င်း၏ class ပေါ်မူတည်၍ method များကို ကွဲပြားစွာ အကောင်အထည်ဖော်ခြင်း
- **Abstraction**: အသေးစိတ်ကို ဖုံးကွယ်ပြီး မရှိမဖြစ် အချက်များကိုသာ ပြသခြင်း

## OOP ကဲ့သို့ ရေးသားရန် ဘာကြောင့် အသုံးဝင်သနည်း

- Code ကို ပြန်လည် အသုံးပြုနိုင်ပါသည်။
- Real-world entities များကို model လုပ်ရန် လွယ်ကူပါသည်။
- Complex programs များကို စီမံခန့်ခွဲရန် ပိုမိုလွယ်ကူပါသည်။

အောက်ပါ စာမျက်နှာများတွင် classes/objects, inheritance, polymorphism စသည်တို့ကို အသေးစိတ် လေ့လာရပါမည်။
