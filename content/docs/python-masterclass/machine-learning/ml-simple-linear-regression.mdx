Linear Regression သည် independent variable (x) နှင့် dependent variable (y) အကြားဆက်စပ်မှုကို line equation ဖြင့် ကိုယ်စားပြုသော method ဖြစ်ပါသည်။

## Linear Equation ၏ သဘောတရား

Regression line တစ်ခု၏ equation မှာ-

```
y = a + b * x
```

- **a**: Intercept (y-axis နှင့်ထိသည့် အမှတ်)
- **b**: Slope (slope သို့မဟုတ် x တွင် ပြောင်းလဲမှုအလိုက် y ၏ ပြောင်းလဲမှု)

## 1. Example Data ဖန်တီးခြင်း

မိနစ်ပိုင်းအချိန် vs အိပ်ချိန် ကဲ့သို့ ဥပမာကို ယူပါမည်။

## 2. scikit-learn ဖြင့် Import

```
from scipy import stats

x = [5, 7, 8, 7, 2, 17, 2, 9, 4, 11, 12, 9, 6]
y = [99, 86, 87, 88, 111, 86, 103, 87, 94, 78, 77, 85, 86]

slope, intercept, r, p, std_err = stats.linregress(x, y)
```

## 3. Best-Fit Line ၏ Functions

```
import matplotlib.pyplot as plt
from scipy import stats

x = [5, 7, 8, 7, 2, 17, 2, 9, 4, 11, 12, 9, 6]
y = [99, 86, 87, 88, 111, 86, 103, 87, 94, 78, 77, 85, 86]

slope, intercept, r, p, std_err = stats.linregress(x, y)

def myfunc(x):
    return slope * x + intercept

mymodel = list(map(myfunc, x))

plt.scatter(x, y)
plt.plot(x, mymodel)
plt.show()
```

► Scatter points များမှ အကောင်းဆုံး fit ဖြစ်သော line ကို ဆွဲပါသည်.

## 4. Relationship ၏ အားကို စစ်ဆေးခြင်း

R-Squared (r) သည် x နှင့် y အကြား ဆက်စပ်မှု အားကို ပြပါသည်.

```
print(r)
```

- -1 မှ 1 အထိ
- 0 နီးလျှင် ဆက်စပ်မှု မရှိ
- 1 နီးလျှင် ဆက်စပ်မှု များပါသည်

## 5. Predict ပြုလုပ်ခြင်း

P (pa) ပေါ်မူတည်၍ x ပေးသော y ကို ခန့်မှန်းပါသည်.

```
from scipy import stats

x = [5, 7, 8, 7, 2, 17, 2, 9, 4, 11, 12, 9, 6]
y = [99, 86, 87, 88, 111, 86, 103, 87, 94, 78, 77, 85, 86]

slope, intercept, r, p, std_err = stats.linregress(x, y)

def myfunc(x):
    return slope * x + intercept

speed = myfunc(10)
print(speed)
```

► x = 10 အတွက် predicted y value ကို ပြသပါသည်.

Linear regression သည် predictive modeling ၏ အခြေခံအုတ်မြစ်ဖြစ်ပြီး 2-D data များတွင် ပထမဆုံး အသုံးပြုပါသည်.
