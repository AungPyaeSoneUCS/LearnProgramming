Model တစ်ခုတွင် hyperparameters (model ၏ setting များကို control လုပ်သော parameters) များ ရှိပြီး အသင့်တော်ဆုံး hyperparameters ကို grid search ဖြင့် ရှာဖွေပါသည်.

## Grid Search ဆိုသည်မှာ

GridSearchCV သည် parameters များ၏ grid (combination များ) မျှစေပြီး cross validation ဖြင့် best combination ကို ရွေးချယ်ပါသည်.

## How to Use

ဥပမာ - SVM classifier ၏ kernel, C, gamma parameters များကို ရှာဖွေပါမည်.

```
from sklearn import svm

clf = svm.SVC()
param_grid = {
    "C": [0.1, 1, 10],
    "gamma": [0.1, 1],
    "kernel": ["linear", "rbf"]
}
```

## GridSearchCV ဖန်တီးခြင်း

```
from sklearn.model_selection import GridSearchCV
from sklearn.datasets import load_iris

iris = load_iris()
grid = GridSearchCV(clf, param_grid, cv=3)
grid.fit(iris.data, iris.target)
```

## Best Parameters ရယူခြင်း

```
print(grid.best_params_)
print(grid.best_score_)
print(grid.best_estimator_)
```

►:
- best_params_: အကောင်းဆုံး combination
- best_score_: ၎င်းတို့၏ mean accuracy
- best_estimator_: အကောင်းဆုံး trained model

## New Points Predict ပြုလုပ်ခြင်း

```
print(grid.predict([[5.1, 3.5, 1.4, 0.2]]))
```

► Best model ဖြင့် classify ပြုလုပ်ပါသည်.

## Cross-validation ၏ Role

GridSearchCV တွင် cv parameter ဖြင့် cross-validation fold အရေအတွက် သတ်မှတ်ပါသည်. Model ကို folds များဖြင့် train/evaluate ပြုလုပ်ပြီး mean performance ကို စဉ်းစားပါသည်.

## Overfitting ရှောင်ရန်

- Training set များကို validation နှင့် သီးခြားထားပါသည်
- Grid search တစ်ခုတွင် test data ကို မသုံးပါ

Grid search သည် hyperparameter tuning ၏ simple နှင့် effective နည်းလမ်းဖြစ်ပြီး model ၏ performance ကို optimize ပြုလုပ်ရန် အသုံးပြုပါသည်.
