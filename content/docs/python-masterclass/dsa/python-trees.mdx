Tree သည် hierarchical data structure ဖြစ်ပြီး root, children nodes များဖြင့် ဖွဲ့စည်းပါသည်. Binary tree ဆိုသည်မှာ node တစ်ခုစီတွင် children max နှစ်ခုသာ ရှိသည့် tree ဖြစ်ပါသည်.

## Node Class

```
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
```

## Insert ပြုခြင်း

Binary Search Tree (BST) ၏ insert method:

```
class BST:
    def __init__(self):
        self.root = None

    def insert(self, value):
        new_node = Node(value)
        if not self.root:
            self.root = new_node
            return
        current = self.root
        while True:
            if value < current.value:
                if not current.left:
                    current.left = new_node
                    return
                current = current.left
            else:
                if not current.right:
                    current.right = new_node
                    return
                current = current.right
```

## Search ပြုခြင်း

```
    def search(self, value):
        current = self.root
        while current:
            if value == current.value:
                return True
            elif value < current.value:
                current = current.left
            else:
                current = current.right
        return False
```

## Tree ဖန်တီး၍ စမ်းသပ်ခြင်း

```
tree = BST()
tree.insert(5)
tree.insert(3)
tree.insert(7)
tree.insert(2)

print(tree.search(3))   # True
print(tree.search(6))   # False
```

## In-order Traversal

```
    def inorder(self, node):
        if node:
            self.inorder(node.left)

tree.inorder(tree.root)
```
