Binary search သည် sorted array ထဲတွင် element တစ်ခုကို O(log n) time complexity ဖြင့် ရှာဖွေသည့် algorithm ဖြစ်ပါသည်. Linear search ထက် များစွာ မြန်ဆန်ပါသည်.

## Binary Search ဆိုသည်မှာ

Data ကို ထက်ခြမ်းခွဲ၍ ရှာဖွေပါသည်. တစ်ကြိမ်တစ်ခုတိုင်းတွင် data ကို ထက်ခြမ်းခွဲပါသည်.

- Array ကို sort ပြုထားရမည်
- Target vs middle element ကို နှိုင်းယှဉ်ပါသည်
- Target < middle: left half ကို ကြည့်ပါသည်
- Target > middle: right half ကို ကြည့်ပါသည်

## Python ဖြင့် Implementation

```
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return -1
```

## စမ်းသပ်ခြင်း

```
arr = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
target = 23

result = binary_search(arr, target)
if result != -1:
    print(f"Found at index {result}")
else:
    print("Not found")
```

► Output: Found at index 5

## Recursive Implementation

```
def binary_search_recursive(arr, target, low, high):
    if low > high:
        return -1
    mid = (low + high) // 2
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, high)
    else:
        return binary_search_recursive(arr, target, low, mid - 1)
```

## Step-by-Step Example

```
arr = [1, 3, 5, 7, 9, 11, 13, 15]
target = 11

# Step 1: low=0, high=7, mid=3, arr[3]=7 < 11
# Step 2: low=4, high=7, mid=5, arr[5]=11 = 11!
result = binary_search(arr, target)
print(result)
```

► Output: 5 (index)

## Time Complexity

- Best: O(1)
- Average/Worst: O(log n)
- Space: O(1) (iterative) / O(log n) (recursive)

## Binary vs Linear Search

- Linear: O(n) - sorted မဖြစ်သည့် data တွင် သုံး
- Binary: O(log n) - sorted data တွင်သာ သုံး

Binary search သည် large sorted datasets များတွင် အလွန်ထိရောက်ပါသည်.
