Dictionaries များသည် key-value pairs များကို သိမ်းဆည်းရန် အသုံးပြုပြီး data lookup များအတွက် အလွန်မြန်ဆန်ပါသည်.

## Basic Dictionary Operations

```
person = {
    "name": "John",
    "age": 30,
    "city": "Yangon",
}

print(person["name"])           # John
print(person.get("age", 0))     # 30
person["email"] = "john@example.com"
person.update({"phone": "09-1234567"})

for key in person:
    print(f"{key}: {person[key]}")
```

## Count Words in Text

```
text = "apple banana apple orange apple banana"
words = text.split()

counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1

print(counts)  # {"apple": 3, "banana": 2, "orange": 1}
```

## Dictionary Comprehension

```
numbers = [1, 2, 3, 4, 5]

squares = {n: n**2 for n in numbers}
print(squares)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

even_odd = {n: "even" if n % 2 == 0 else "odd" for n in numbers}
print(even_odd)  # {1: "odd", 2: "even", ...}
```

## Group Items by Key

```
people = [
    {"name": "A", "group": "x"},
    {"name": "B", "group": "y"},
    {"name": "C", "group": "x"},
]

groups = {}
for person in people:
    g = person["group"]
    groups.setdefault(g, []).append(person["name"])

print(groups)  # {"x": ["A", "C"], "y": ["B"]}
```

## Merge Dictionaries

```
dict1 = {"a": 1, "b": 2}
dict2 = {"b": 3, "c": 4}

merged = {**dict1, **dict2}   # Python 3.5+
merged2 = dict1 | dict2       # Python 3.9+
print(merged)   # {"a": 1, "b": 3, "c": 4}
print(merged2)  # {"a": 1, "b": 3, "c": 4}
```

## Find Maximum Value

```
scores = {"John": 85, "Peter": 92, "Amy": 78}

best = max(scores, key=scores.get)
worst = min(scores, key=scores.get)
print(f"Best: {best} ({scores[best]})")     # Peter (92)
print(f"Worst: {worst} ({scores[worst]})")  # Amy (78)
```

## Sort by Value

```
scores = {"John": 85, "Peter": 92, "Amy": 78}

sorted_by_value = dict(sorted(scores.items(), key=lambda x: x[1], reverse=True))
print(sorted_by_value)  # {"Peter": 92, "John": 85, "Amy": 78}
```

## Nested Dictionaries

```
users = {
    "alice": {"age": 25, "email": "alice@example.com"},
    "bob": {"age": 30, "email": "bob@example.com"},
}

for username, info in users.items():
    print(f"{username} ({info['age']}): {info['email']}")
```
