Function ဆိုသည်မှာ မိမိဘာသာ သတ်မှတ်ပြီး ထပ်ခါထပ်ခါ သုံးနိုင်သော code block တစ်ခု ဖြစ်ပါသည်။ Function များသည် code ကို ပြန်လည်သုံးနိုင်ခြင်း (reusability) ကို ပေးပါသည်။

## Function ဖန်တီးခြင်း

Function တစ်ခုကို def keyword ဖြင့် စတင်ပါသည်။

```
def my_function():
    print("Hello from a function")
```

## Function ကို ခေါ်ခြင်း

```
def my_function():
    print("Hello from a function")

my_function()
```

► Output: Hello from a function

## Arguments

Function ကို arguments များ ပို့သွင်းနိုင်ပါသည်။

```
def my_function(fname):
    print(fname + " Refsnes")

my_function("Emil")
my_function("Tobias")
my_function("Linus")
```

## Parameters အများအပြား

```
def my_function(fname, lname):
    print(fname + " " + lname)

my_function("Emil", "Refsnes")
```

## Arguments အရေအတွက် မှားလျှင်

Function arguments အရေအတွက် မှားလျှင် error ဖြစ်ပါသည်။

```
def my_function(fname, lname):
    print(fname + " " + lname)

my_function("Emil")
```

► TypeError ဖြစ်ပါသည်။

## Default Parameter Value

```
def my_function(country="Norway"):
    print("I am from " + country)

my_function("Sweden")
my_function("India")
my_function()
my_function("Brazil")
```

argument မပို့ပါက default "Norway" ကို သုံးပါသည်။

## Return Value

```
def my_function(x):
    return 5 * x

print(my_function(3))
print(my_function(5))
print(my_function(9))
```

## Keyword Arguments

Args များကို key=value အဖြစ် ပို့နိုင်ပါသည်။

```
def my_function(child3, child2, child1):
    print("The youngest child is " + child3)

my_function(child1="Emil", child2="Tobias", child3="Linus")
```

## Arbitrary Arguments (*args)

Arguments အရေအတွက် မသေချာပါက *args ကို သုံးပါသည်။

```
def my_function(*kids):
    print("The youngest child is " + kids[2])

my_function("Emil", "Tobias", "Linus")
```

## **kwargs

Named arguments အများအပြားကို dictionary အဖြစ် လက်ခံရန် **kwargs ကို သုံးပါသည်။

```
def my_function(**kid):
    print("His last name is " + kid["lname"])

my_function(fname="Tobias", lname="Refsnes")
```

Functions များသည် code organization နှင့် reusability ၏ အုတ်မြစ် ဖြစ်ပါသည်။
