Python တွင် output ပြသရန် `print()` function ကို အသုံးပြုပါသည်။ ဤ function သည် မိမိပေးလိုက်သော message အများအပြားကို screen ပေါ်တွင် ပြသပေးပါသည်။

## String များ ပြသခြင်း

```
print("Hello, World!")
```

String များကို single quotes ဖြင့်လည်း ရေးသားနိုင်ပါသည်။

```
print('Hello, World!')
```

## Multiple Values ပြသခြင်း

`print()` အတွင်း တန်ဖိုးများစွာကို comma ဖြင့် ခြားကာ ပြသပါသည်။

```
print("Python", "is", "awesome")
```

► Output: Python is awesome

## ကိန်းဂဏန်းများ ပြသခြင်း

```
print(10 + 5)
```

► Output: 15

Integer များအပြင် string များနှင့် ရောစပ်ပြီး ပြသနိုင်ပါသည်။

```
print("2 + 2 =", 2 + 2)
```

► Output: 2 + 2 = 4

print() ကို line အများအပြားတွင် သုံးပါက တစ်ကြောင်းဆီ ပြသပါသည်။

```
print("Line 1")
print("Line 2")
```

Output:
```
Line 1
Line 2
```

`print()` သည် output ပြသရန် အသုံးအများဆုံး function ဖြစ်ပြီး debugging ပြုလုပ်ရာတွင်လည်း အရေးပါပါသည်။
