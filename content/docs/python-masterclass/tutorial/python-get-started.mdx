Python ကို စတင်အသုံးပြုရန် တရားဝင် website ဖြစ်သော python.org မှ install ပြုလုပ်ရပါမည်။

## Python Install ပြုလုပ်ခြင်း

1. မိမိ၏ browser တွင် `https://www.python.org/downloads/` ကို ဖွင့်ပါ။
2. မိမိ၏ operating system အတွက် သင့်လျော်သော version ကို download လုပ်ပါ။
3. Installer ကိုဖွင့်၍ "Add Python to PATH" ကို အမှန်ခြစ်လုပ်ပါ။
4. Install ပြုလုပ်ပြီးနောက် command prompt ကိုဖွင့်၍ စစ်ဆေးပါ။

```
python --version
```

## Code ရေးရန် နည်းလမ်းများ

### 1. Command Line (interactive)

```
python
```

ရိုက်ထည့်လိုက်သည်နှင့် prompt တစ်ခု ပေါ်လာပြီး code များကို တိုက်ရိုက် ရိုက်ထည့်နိုင်ပါသည်။

### 2. Python File (.py)

File တစ်ခုကို ဖန်တီး၍ code များ ရေးပြီး run နိုင်ပါသည်။

```
print("Hello, World!")
```

File ကို `hello.py` အမည်ဖြင့် သိမ်း၍ run ရန်-

```
python hello.py
```

### 3. IDLE

Python နှင့်အတူ ပါလာသော IDLE editor ကို အသုံးပြု၍ code များ ရေးနိုင်ပါသည်။

## Command Line တွင် စမ်းကြည့်ခြင်း

ပထမဆုံး ရေးရမည့် program မှာ-

```
print("Hello, World!")
```

Python သည် semicolon မလိုအပ်ဘဲ line တစ်ကြောင်းတည်းဖြင့် အလုပ်လုပ်ပါသည်။
