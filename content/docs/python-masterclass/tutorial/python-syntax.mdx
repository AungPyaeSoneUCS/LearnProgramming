Python syntax သည် အခြား programming languages များနှင့် ကွဲပြားသော လက္ခဏာများ ရှိပါသည်။ ထိုထဲမှ အရေးကြီးဆုံးမှာ indentation (စာကြောင်းတွန်းခြင်း) ဖြစ်ပါသည်။

## Indentation

Python သည် code blocks များကို သတ်မှတ်ရန် မလိုအပ်ဘဲ indentation ကို အသုံးပြုပါသည်။

```
if 5 > 2:
    print("Five is greater than two!")
```

Indentation ၏ စည်းမျဉ်းများ-

- Block တစ်ခုစီတွင် indent (space 4 ခု သို့မဟုတ် tab) လိုအပ်ပါသည်။
- Indent နေရာတွင် မိမိကြိုက်နှစ်သက်သည့် space အရေအတွက်ကို သုံးနိုင်ပါသည်။
- တစ်ကြိမ်ရွေးပြီးနောက် file တစ်လျှောက် တသမတ်တည်း ထားရပါမည်။

အောက်ပါ code သည် syntax error ဖြစ်ပါသည်။

```
if 5 > 2:
print("Five is greater than two!")
```

ဤတွင် `print()` line သည် indent မလုပ်ထားသောကြောင့် block ၏ အဖွဲ့ဝင်မဟုတ်ပဲ error ဖြစ်ပါသည်။

## Variables

Variables များကို type declaration မလိုအပ်ဘဲ တန်ဖိုး သတ်မှတ်၍ ဖန်တီးပါသည်။

```
x = 5
y = "Hello, World!"
```

## Comments

Comment များကို # သင်္ကေတဖြင့် ရေးသားပါသည်။

```
# ဤစာသည် comment ဖြစ်ပါသည်
print("Hello, World!")
```

Python syntax ၏ အခြေခံကို နားလည်ပြီးပါက variables များကို ဆက်လက် လေ့လာနိုင်ပါသည်။
