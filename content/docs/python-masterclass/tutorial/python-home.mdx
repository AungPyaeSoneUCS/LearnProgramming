Python သည် 1991 ခုနှစ်တွင် Guido van Rossum မှ ထုတ်ဝေခဲ့သော high-level, interpreted programming language တစ်ခု ဖြစ်ပါသည်။ ၎င်းသည် သင်ယူရလွယ်ကူသော syntax ကြောင့် ကမ္ဘာပေါ်တွင် ရေပန်းအစားဆုံး languages များထဲမှ တစ်ခု ဖြစ်လာပါသည်။

## Python ဖြင့် လုပ်ဆောင်နိုင်သည့် အရာများ

- **Web Development**: Django, Flask စသည့် frameworks များဖြင့် server-side applications ရေးသားခြင်း
- **Data Science**: Pandas, NumPy တို့ဖြင့် data ခွဲခြမ်းစိတ်ဖြာခြင်း နှင့် စီမံခြင်း
- **Machine Learning**: TensorFlow, scikit-learn တို့ဖြင့် model များ တည်ဆောက်ခြင်း
- **Automation**: Scripts များဖြင့် ထပ်ခါတလဲလဲ လုပ်ဆောင်ရသော အလုပ်များကို အလိုအလျောက် လုပ်ခြင်း
- **Desktop Applications**: Tkinter, PyQt တို့ဖြင့် GUI applications ရေးသားခြင်း
- **Game Development**: Pygame ကဲ့သို့သော libraries များဖြင့် games တည်ဆောက်ခြင်း

## Python ၏ အားသာချက်များ

- Syntax သည် ရိုးရှင်းလွယ်ကူပြီး အင်္ဂလိပ်စာသားနှင့် ဆင်တူပါသည်။
- Open source ဖြစ်ပြီး အခမဲ့ အသုံးပြုနိုင်ပါသည်။
- Libraries အမြောက်အမြား ရှိပြီး မည်သည့်အလုပ်အတွက်မဆို module ရှိပါသည်။
- Cross-platform ဖြစ်၍ Windows, macOS, Linux အားလုံးတွင် လုပ်ဆောင်နိုင်ပါသည်။
- Community ကြီးမား၍ documentation နှင့် ဥပမာများ ပေါများပါသည်။

## ပထမဆုံး Program

အောက်ပါ code သည် Python တွင် အကျော်ကြားဆုံး ပထမဆုံး program ဖြစ်ပါသည်။

```
print("Hello, World!")
```

ဤ code သည် `print()` function ကို အသုံးပြု၍ `"Hello, World!"` ဟူသော စာသားကို screen ပေါ်တွင် ပြသပါသည်။ Python ကို စတင်လေ့လာရန် နောက်စာမျက်နှာများကို ဆက်လက် ဖတ်ရှုပါ။
