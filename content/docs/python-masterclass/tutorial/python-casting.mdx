Type casting ဆိုသည်မှာ variable ၏ data type ကို မိမိလိုချင်သော type သို့ ပြောင်းလဲခြင်း ဖြစ်ပါသည်။ Python သည် value ကို assign ပြုလုပ်သောအခါ type ကို အလိုအလျောက် သတ်မှတ်သော်လည်း တစ်ခါတစ်ရံ မိမိကိုယ်တိုင် cast ပြုလုပ်ရန် လိုအပ်ပါသည်။

## Integers သို့ Casting

`int()` ကို အသုံးပြု၍ integer တစ်ခုကို ဖန်တီးပါသည်။

```
x = int(1)      # x သည် 1
y = int(2.8)    # y သည် 2
z = int("3")    # z သည် 3
```

Float instance များတွင် ဒဿမပိုင်းကို ဖျောက်၍ integer တစ်ခုသာ ရပါသည်။

## Floats သို့ Casting

`float()` ကို အသုံးပြု၍ float တစ်ခုကို ဖန်တီးပါသည်။

```
x = float(1)        # x သည် 1.0
y = float(2.8)      # y သည် 2.8
z = float("3")      # z သည် 3.0
w = float("4.2")    # w သည် 4.2
```

## Strings သို့ Casting

`str()` ကို အသုံးပြု၍ string တစ်ခုကို ဖန်တီးပါသည်။

```
x = str("s1")       # x သည် s1
y = str(2)          # y သည် 2
z = str(3.0)        # z သည် 3.0
```

## Example

```
print(int(3.7))    # 3
print(int(-3.7))   # -3
print(float(4))    # 4.0
print(str(100))    # "100"
print(str(2.5))    # "2.5"
```

Casting ကို math operations များတွင် different types များ ရောနှောသည့်အခါ သေချာသော ရလဒ်ရရှိရန် အသုံးပြုပါသည်။
