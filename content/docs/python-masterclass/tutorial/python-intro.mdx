Python သည် သင်ယူရလွယ်ကူပြီး လူကြိုက်များသော programming language တစ်ခု ဖြစ်ပါသည်။ Python ၏ ထင်ရှားသော လက္ခဏာမှာ syntax သည် ရိုးရှင်းပြီး စတင်သူများ အမြန်နားလည်နိုင်ခြင်း ဖြစ်ပါသည်။

## Python ကို အဘယ်ကြောင့် သင်ယူသင့်သနည်း

- Syntax သည် English စကားလုံးများနှင့် ဆင်တူ၍ မျက်လုံးဖြင့် ကြည့်ရုံနှင့် ဖတ်လို့ရပါသည်။
- Code ရေးသည့်အခါ semicolon နှင့် curly braces မလိုအပ်ပါ။
- Python သည် တိုတောင်းပြီး ရှင်းလင်းသော code များဖြင့် အလုပ်လုပ်ပါသည်။
- Industry standard ဖြစ်၍ အလုပ်အကိုင် အခွင့်အလမ်း များပြားပါသည်။

## Python ဥပမာနှင့် အခြား Languages များ

ဥပမာအားဖြင့် "Hello World" ကို ပြသရန် Python ဖြင့်-

```
print("Hello, World!")
```

Java ဖြင့် ရေးလျှင် line များစွာ လိုအပ်ပါသည်။ Python ၏ အားသာချက်မှာ ဤကဲ့သို့ ရိုးရှင်းခြင်း ဖြစ်ပါသည်။

## Python Installation

ကွန်ပျူတာတွင် Python ရှိမရှိ စစ်ဆေးရန် command line တွင် အောက်ပါအတိုင်း ရိုက်ထည့်ပါ။

```
python --version
```

Output အဖြစ် Python version ကို မြင်ရပါက စတင်ရန် အဆင်သင့် ဖြစ်ပါသည်။ မမြင်ရလျှင် နောက်စာမျက်နှာရှိ installation ညွှန်ကြားချက်များကို ဆက်လက် ဖတ်ပါ။
