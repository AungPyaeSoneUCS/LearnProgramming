Data များကို filter ပြုလုပ်ရန် WHERE clause ကို သုံးပြီး specific conditions နှင့် ကိုက်ညီသော rows များကိုသာ ပြန်ပေးပါသည်.

## WHERE Clause

customers မှ address သည် Park Lane ဖြစ်သော rows များကို select ပြုလုပ်ပါသည်.

```
import mysql.connector

mydb = mysql.connector.connect(
    host="localhost",
    user="yourusername",
    password="yourpassword",
    database="mydatabase"
)

mycursor = mydb.cursor()

sql = "SELECT * FROM customers WHERE address = 'Park Lane 38'"
mycursor.execute(sql)

myresult = mycursor.fetchall()
for row in myresult:
    print(row)
```

► 'Park Lane 38' address ပါသော rows များကိုသာ ပြသပါသည်.

## Wildcards (% နှင့် _)

LIKE operator ဖြင့် wildcard characters များကို သုံးနိုင်ပါသည်.

```
# % - မည်သည့် characters မဆို
sql = "SELECT * FROM customers WHERE address LIKE '%way%'"
mycursor.execute(sql)
myresult = mycursor.fetchall()
for row in myresult:
    print(row)
```

► 'way' ပါဝင်သော addresses များကို ပြသပါသည်.

## Prevent SQL Injection

SQL injection ကို ကာကွယ်ရန် %s placeholder များကို သုံးပါသည်.

```
sql = "SELECT * FROM customers WHERE address = %s"
adr = ("Yellow Garden 2", )

mycursor.execute(sql, adr)
myresult = mycursor.fetchall()
for row in myresult:
    print(row)
```

► Placeholder ဖြင့် value ပေးပို့ခြင်းသည် query ကို safe ဖြစ်စေပါသည်.

DERECATED: String concatenation ဖြင့် query ရေးခြင်းကို ရှောင်ကြဉ်ပါသည်. SQL injection risk များသောကြောင့် parameters (%s) များကိုသာ သုံးပါသည်.

WHERE clause ကို placeholder (%) များဖြင့် မှန်ကန်စွာ သုံးပါက safe filtering ပြုလုပ်နိုင်ပါသည်.
