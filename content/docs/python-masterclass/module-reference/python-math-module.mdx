math module သည် mathematical functions များနှင့် constants များကို ပံ့ပိုးပါသည်. အသုံးပြုရန် import math ပြုလုပ်ရပါသည်.

## Import Math Module

```
import math
```

## Math Constants

```
import math

math.pi     # 3.141592653589793
math.e      # 2.718281828459045
math.tau    # 6.283185307179586
math.inf    # infinity
math.nan    # NaN (not a number)
```

## Rounding Functions

```
import math

math.ceil(4.1)    # 5 (round up)
math.floor(4.9)   # 4 (round down)
math.trunc(-9.5)  # -9 (toward zero)
math.fabs(-7.5)   # 7.5 (absolute float)
```

## Power & Log Functions

```
import math

math.pow(2, 10)   # 1024.0
math.sqrt(144)    # 12.0
math.exp(2)       # e^2
math.log(100)     # natural log (base e)
math.log(100, 10) # log base 10
math.log2(8)      # 3.0
```

## Trigonometric Functions

```
import math

math.sin(math.pi / 2)  # 1.0
math.cos(0)            # 1.0
math.tan(math.pi / 4)  # 0.999...
math.degrees(math.pi)  # 180.0
math.radians(180)      # 3.14159...
math.asin(1)           # pi/2
math.atan2(1, 1)       # pi/4
```

## Number Functions

```
import math

math.gcd(12, 18)    # 6
math.factorial(5)   # 120
math.isqrt(100)     # 10 (integer square root)
math.isfinite(5)    # True
math.isnan(math.nan) # True
```

## Fibonacci Example

```
import math

# Phi (golden ratio) ဖြင့် nth fibonacci
def fibonacci(n):
    phi = (1 + math.sqrt(5)) / 2
    return round(phi**n / math.sqrt(5))

print(fibonacci(10))  # 55
```
