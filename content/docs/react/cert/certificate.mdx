## ‌ဘာတွေ ‌သိရမယ်လဲ

```jsx
// ‌အခြေခံ — state + props
function Greeting(props) {
  const [count, setCount] = useState(0);
  return (
    <div>
      <h1>Hello {props.name}</h1>
      <button onClick={() => setCount(count + 1)}>{count}</button>
    </div>
  );
}
```

- Hooks — useState, useEffect, useContext
- Forms, events, lists, conditional rendering
