ဒီ lesson သည် React Tutorial သင်တန်း၏ ပထမဆုံး ခေါင်းစဉ်ပါ။ သင်တန်းတစ်ခုလုံး၏ မြေပုံကို ကြည့်ပြီး React ကို ဘာကြောင့် လေ့လာသင့်လဲ၊ ဘာတွေ သင်ယူရမလဲဆိုတာ ရှင်းပြပါမယ်။

## React ဆိုတာ ဘာလဲ?
React သည် Facebook မှ တီထွင်ထားသည့် JavaScript library တစ်ခုဖြစ်ပြီး **User Interface (UI)** ကို တည်ဆောက်ရန် အသုံးပြုပါတယ်။ Component လို့ခေါ်တဲ့ ပြန်သုံးနိုင်တဲ့ အစိတ်အပိုင်းတွေနဲ့ ဆောက်တာမလို့ ကြီးတဲ့ application တွေမှာတောင် code ကို စနစ်ကျကျ ထိန်းသိမ်းနိုင်ပါတယ်။

| အကြောင်းအရာ | အသေးစိတ် |
| --- | --- |
| UI Library | Component-based, ပြန်သုံးလို့ရပြီး state ကို စီမံပေးတယ် |
| Framework မဟုတ် | သီးချား tool တွေနဲ့ ပေါင်းစပ်သုံးရတယ် |
| Popular | ကမ္ဘာ့အကြီးဆုံး ကုမ္ပဏီတွေ (Facebook, Instagram, Netflix) မှာ သုံးကြတယ် |

## စတင်ရန် လိုအပ်ချက်
- HTML, CSS နဲ့ JavaScript အခြေခံ **သိထားသင့်**ပါတယ်။
- Browser တစ်ခုသာ လုံလောက်ပါတယ်။ Node.js ရှိရင် ကိုယ့် စက်မှာပါ စမ်းနိုင်ပါတယ်။

**ပထမဆုံး React component —**
```jsx
function Welcome() {
  return <h1>Hello React!</h1>;
}
```

React ကို ကျွမ်းကျင်ဖို့ဆို ရေးကြည့်မှ ရပါတယ်။ ဖတ်ရုံနဲ့ မရပါဘူး။
