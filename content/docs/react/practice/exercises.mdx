## ‌လေ့ကျင့်ခန်း 3 — Lists

```jsx
const fruits = ["Apple", "Banana", "Cherry"];

<ul>
  {fruits.map((fruit) => (
    <li key={fruit}>{fruit}</li>
  ))}
</ul>
```

- `map` — array ‌ကို JSX list ‌ပြောင်း
- `key` — ‌စ‌နစ်‌ကျ‌စေရန် unique value
