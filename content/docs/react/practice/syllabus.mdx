‌ဤ React tutorial ‌သည် ‌အခန်းကြီးများစွာ ‌ဖြင့် ‌ဖွဲ့စည်း‌ထားပါသည် — ‌လေ့လာသူများသည် ‌အစီအစဉ်အတိုင်း ‌သင်ယူ ‌နိုင်ပါသ‌ည်။

## ‌သင်ရိုး အခန်းကြီးများ
1. **React Tutorial** — ‌မိတ်ဆက်, setup, first app, render
2. **ES6** — classes, arrow functions, variables (let/const), array methods, destructuring, spread, modules, operators
3. **React JSX** — JSX ‌မိတ်ဆက်, expressions, attributes
4. **React Components** — class components, props, props children
5. **React Events** — event handlers, onClick
6. **React Conditionals** — if statements, ternary, && operator
7. **React Lists** — map, keys
8. **React Forms** — inputs, textarea, select, checkbox, radio
9. **React Portals** — createPortal
10. **React Suspense** — lazy loading
11. **React Styling** — CSS, modules, CSS-in-JS, Sass
12. **React Router** — navigation, transitions
13. **React Advanced** — forwardRef, HOC
14. **React Hooks** — useState → custom hooks
15. **React Certificate** — ‌အောင်လက်မှတ် ‌သင်ရိုး
16. **React Practice** — ‌လေ့ကျင့်ခန်း, quiz, ‌သင်ရိုး, study plan

## ‌ဘာတွေ ‌သိရမလဲ
- JSX ‌နားလည်မှု — `{expression}`, attributes
- Components ‌အကြား data — props, context
- State ‌စီမံမှု — useState, useReducer
- Side effects — useEffect (fetch, timers)
- Forms ‌ကိုင်တွယ်မှု — controlled inputs
- Performance — useMemo, useCallback
