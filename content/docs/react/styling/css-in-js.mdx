CSS-in-JS ‌ဆိုတာ CSS ‌ကို JavaScript ‌ထဲမှာ ‌ရေးတဲ့ ‌နည်းလမ်း ‌ဖြစ်ပါတယ်။ ‌အသုံးများတာက **styled-components** ‌ဖြစ်ပါတယ်။

## Install

```bash
npm install styled-components
```

## styled.button ‌ဖြင့် component

```jsx
import styled from "styled-components";

const Button = styled.button`
  background-color: tomato;
  color: white;
  padding: 10px 20px;
  border-radius: 6px;
`;

function App() {
  return <Button>Click me</Button>;
}
```

`styled.button` — button ‌ကို CSS ‌နဲ့ ‌တွဲ component ‌ဖြစ်‌အောင် လုပ်ပါတယ်။

## Props ‌အလိုက် dynamic style

```jsx
const Button = styled.button`
  background-color: ${(props) => (props.$primary ? "blue" : "gray")};
  color: white;
  padding: 10px 20px;
`;

function App() {
  return (
    <>
      <Button $primary>Primary</Button>
      <Button>Secondary</Button>
    </>
  );
}
```

`$primary` — prop ‌မှန်/မှား အပေါ် ‌မူတည် ‌အရောင် ‌ပြောင်း။

## Global styles

```jsx
import { createGlobalStyle } from "styled-components";

const GlobalStyle = createGlobalStyle`
  body { margin: 0; font-family: sans-serif; }
`;

function App() {
  return (
    <>
      <GlobalStyle />
      <p>Hello</p>
    </>
  );
}
```

## အဓိက အချက်များ
- `styled.tag` component ‌ဖန်တီး
- `${(props) => ...}` — dynamic value
- `createGlobalStyle` — global CSS
- Component-scoped ‌လို့ conflict ‌မဖြစ်
