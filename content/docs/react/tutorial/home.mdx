### ဥပမာ — ရိုးရှင်းတဲ့ React App

```jsx
import React from "react";
import ReactDOM from "react-dom/client";

function Hello() {
  return <h1>Hello React!</h1>;
}

const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(<Hello />);
```

ဒီ code က `Hello` ဆိုတဲ့ component တစ်ခုကို ဖန်တီးပြီး `root` ထဲမှာ render လုပ်ပါတယ်။ component ဆိုတာ UI အစိတ်အပိုင်း တစ်ခုဖြစ်ပြီး ပြန်ပြန် သုံးလို့ရတယ်။
