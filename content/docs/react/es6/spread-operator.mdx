Spread operator `...` က array သို့မဟုတ် object ကို အစိတ်အပိုင်းတွေအဖြစ် ဖြန့်ပေးပါတယ်။ copy လုပ်ဖို့၊ element တွေ ပေါင်းစပ်ဖို့ အသုံးဝင်ပါတယ်။

## Array Spread

```js
const numbersOne = [1, 2, 3];
const numbersTwo = [4, 5, 6];

const numbersCombined = [...numbersOne, ...numbersTwo];
console.log(numbersCombined); // [1, 2, 3, 4, 5, 6]
```

## Array ကို Copy ကူးခြင်း

```js
const arr1 = [1, 2];
const arr2 = [...arr1];     // သီးခြား copy

arr2.push(3);
console.log(arr1); // [1, 2]  (မပြောင်း)
console.log(arr2); // [1, 2, 3]
```

## Object Spread

```js
const vehicle = { brand: "Ford", model: "Mustang" };

const updated = { ...vehicle, model: "Shelby" };
console.log(updated); // { brand: "Ford", model: "Shelby" }
```

## Function Arguments

```js
const numbers = [1, 2, 3];
console.log(Math.max(...numbers)); // 3
```

## React State Update ‌မှာ

```jsx
const [person, setPerson] = useState({ name: "Aung", age: 25 });

// object ကို copy လုပ်ပြီး age ကို ပြောင်း
setPerson({ ...person, age: 26 });
```

Spread နဲ့ copy မလုပ်ဘဲ တိုက်ရိုက် ပြောင်းရင် React ‌အတွက် change ကို သိမှာ မဟုတ်ဘူး။

## အဓိက အချက်များ
- `...` က array/object ကို ဖြန့်သည်
- copy လုပ်ပြီး immutable update လုပ်လို့ရသည်
- React ‌မှာ state update လုပ်တဲ့အခါ object/array copy ‌အတွက် မဖြစ်မနေ လိုအပ်သည်
