`useEffect` ‌က render ‌ပြီးမှ **side effect** — data fetch, timer, event listener, DOM ‌ပြောင်း — ‌တွေကို ‌လုပ်ဖို့ ‌သုံးပါတယ်။

## Syntax

```jsx
useEffect(() => {
  // side effect
}, [dependencies]);
```

- Effect — side effect ‌လုပ်တဲ့ function
- dependency array — ‌ပြောင်းလဲမှ ပြန်လဲ (re-run)

## ‌ပထမ ‌ဥပမာ — document title

```jsx
import { useState, useEffect } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Clicked ${count} times`;
  }, [count]);

  return (
    <button onClick={() => setCount(count + 1)}>
      You clicked {count} times
    </button>
  );
}
```

`[count]` — count ‌ပြောင်းမှသာ effect ‌ပြန်လဲ။

## Data Fetch — ‌ဥပမာ

```jsx
const [data, setData] = useState(null);

useEffect(() => {
  fetch("https://api.example.com/posts")
    .then((res) => res.json())
    .then((json) => setData(json));
}, []);
```

Empty array `[]` — mount ချိန် တစ်ခါသာ ‌ပြေး။

## Cleanup ‌လုပ်ရန် — timer

```jsx
useEffect(() => {
  const timer = setInterval(() => setTime(new Date()), 1000);
  return () => clearInterval(timer); // unmount ‌ချိန် cleanup
}, []);
```

`return` ‌ထဲ cleanup — component ‌ပျောက်တဲ့ ‌အခါ timer ‌ရပ်ပေးပါတယ်။

## ‌အသုံးချ Summary

- `useEffect` — render ‌ပြီးတိုင်း/ dependent ‌ပြောင်းတိုင်း
- Dependence [ ] — ‌တစ်ခါသာ
- Cleanup — unsubscribe / clear timer
