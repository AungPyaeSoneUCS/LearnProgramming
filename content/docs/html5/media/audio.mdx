`### <audio>` Element မိတ်ဆက်

`<audio>` Element က Sound, Music File တွေကို Webpage မှာ ဖွင့်ဖို့ သုံးပါတယ်။ `<video>` Element နဲ့ တည်ဆောက်ပုံ ဆင်တူပြီး `src` Attribute မှာ Audio File ရဲ့ Path ထည့်ပါတယ်။ `controls` Attribute ထည့်မှပဲ Play, Pause, Volume ခလုတ်တွေ မြင်ရမှာဖြစ်ပါတယ်။

**ဥပမာ -**
```html
<audio src="song.mp3" controls></audio>
```

မှတ်ချက် — `controls` မထည့်ထားရင် Audio ဖွင့်နေရင်တောင် ခလုတ်တွေ မမြင်ရတာမို့ User က ထိန်းချုပ်လို့ ရနိုင်မှာ မဟုတ်ပါဘူး။

### Audio Attributes တွေ

`controls` က ထိန်းချုပ်ခလုတ်တွေကို ပြသပေးပြီး `autoplay` က Page ဖွင့်တာနဲ့ Audio ကို အလိုအလျောက် ဖွင့်ပေးပါတယ်။ `loop` က Audio ကုန်သွားရင် ပြန်ပြန်ဖွင့်စေပြီး `muted` က အသံကို ပိတ်ထားပေးပါတယ်။ `preload` က Page ဖွင့်တာနဲ့ Audio ဖိုင်ကို ကြိုတင် ဒေါင်းလုတ်လုပ်မလား ဆိုတာကို သတ်မှတ်ပေးပါတယ်။

**ဥပမာ -**
```html
<audio src="song.mp3" controls autoplay muted loop preload="auto"></audio>
```

မှတ်ချက် — `autoplay` ကို `muted` နဲ့ တွဲမသုံးရင် Browser အများစုက ပိတ်ပေးတတ်ပြီး `preload` မှာ auto, metadata, none ဆိုပြီး Option (၃) မျိုး ရှိပါတယ်။

`### <source>` နဲ့ Fallback

`<source>` Element အမျိုးမျိုး ထည့်ထားရင် Browser က သူ့အတွက် ဖွင့်နိုင်တဲ့ ပထမဆုံး Format ကို ရွေးပါတယ်။ Format တစ်ခုမှ မဖွင့်နိုင်ရင် `<audio>` ရဲ့ အတွင်းထဲမှာ ရေးထားတဲ့ Fallback Text ကို ပြသပါတယ်။ ဒီနည်းနဲ့ Browser အဟောင်းတွေမှာတောင် Audio ကို ကောင်းကောင်း စီစဉ်နိုင်ပါတယ်။

**ဥပမာ -**
```html
<audio controls>
  <source src="song.mp3" type="audio/mpeg">
  <source src="song.ogg" type="audio/ogg">
  Your browser does not support the audio element.
</audio>
```

မှတ်ချက် — Browser က `<source>` တွေထဲက ပထမဆုံး ဖွင့်နိုင်တဲ့ဟာကို သုံးပြီး ဘယ်ဟာမှ မရရင် အတွင်းကစာသားကို Fallback အဖြစ် ပြပါတယ်။

### မှတ်ထားရမယ့် အချက်များ

- Audio Element က Sound File တွေအတွက်သာ ဖြစ်ပြီး Video အတွက် `<video>` ကို သုံးရတယ်။
- `controls` က User အတွက် မဖြစ်မနေ လိုအပ်တယ်။
- `autoplay` ကို `muted` နဲ့ တွဲသုံးရတတ်တယ်။
