### HTML Editor ဆိုတာ ဘာလဲ?
HTML Editor ဆိုတာ HTML code တွေကို ရေးသားဖို့ အသုံးပြုတဲ့ Text Editor (စာသားရေးကိရိယာ) ဖြစ်ပါတယ်။ Word လို Formatting ပါတဲ့ Editor မဟုတ်ဘဲ Plain Text (ရိုးရိုးစာသား) ရေးလို့ရတဲ့ ကိရိယာတိုင်းနဲ့ HTML ရေးလို့ ရပါတယ်။ အရေးကြီးဆုံးကတော့ ဖိုင်ကို `.html` နဲ့ Save လုပ်ဖို့ ဖြစ်ပြီး ဒါဆိုရင် Browser က သူ့ကို Webpage အဖြစ် ဖွင့်ပေးမှာ ဖြစ်ပါတယ်။

#### Notepad နဲ့ စတင်လေ့ကျင့်ခြင်း
Windows မှာ ပါတဲ့ Notepad က အရိုးရှင်းဆုံး Editor ဖြစ်ပါတယ်။ Code ရေးပြီး File → Save As ကနေ "hello.html" ဆိုပြီး Save လုပ်ရပါမယ်။ Save လုပ်တဲ့အခါ `.html` ဆိုတဲ့ Extension (နောက်ဆက်တွဲ) ကို ထည့်ပေးဖို့ အရမ်းအရေးကြီးပြီး Encoding ကို UTF-8 ရွေးရင် မြန်မာစာတွေပါ ရိုက်လို့ ရပါတယ်။

**ဥပမာ -**
```html
<h1>မင်္ဂလာပါ!</h1>
<p>ဒါကတော့ ကျွန်တော့်ရဲ့ ပထမဆုံး HTML page ပါ။</p>
```
မှတ်ချက် — Notepad မှာ ရိုက်ပြီး `.txt` မဟုတ်ဘဲ `.html` နဲ့ သေချာ Save လုပ်ဖို့ မမေ့ပါနဲ့။

#### VS Code နဲ့ ပိုအဆင်ပြေအောင် ရေးသားခြင်း
VS Code (Visual Studio Code) က လူကြိုက်အများဆုံး Editor တစ်ခုဖြစ်ပြီး အခမဲ့ ရယူနိုင်ပါတယ်။ ဒီမှာဆိုရင် Syntax Highlighting (code တွေကို အရောင်ခွဲပြခြင်း) နဲ့ Autocomplete (စာရိုက်တာနဲ့ အလိုအလျောက်ဖြည့်ပေးခြင်း) စတဲ့ အဆင်ပြေမှုတွေ ရရှိမှာ ဖြစ်ပါတယ်။ Project folder (ပရောဂျက် ဖိုင်တွဲ) တစ်ခု ဖွင့်ပြီး အဲဒီထဲမှာ `.html` ဖိုင်အသစ် ဖန်တီးပါ။

**ဥပမာ -**
```html
<!DOCTYPE html>
<html lang="my">
<head>
  <meta charset="UTF-8">
  <title>ကျွန်တော့် Website</title>
</head>
<body>
  <h1>မင်္ဂလာပါ!</h1>
</body>
</html>
```
မှတ်ချက် — VS Code မှာ `!` Shortcut ရိုက်ပြီး Enter နှိပ်ရင် စာမျက်နှာ အခြေခံပုံစံ (skeleton) တစ်ခုလုံး အလိုအလျောက် ဖြစ်လာပါတယ်။

#### Browser မှာ ဖွင့်ကြည့်ခြင်း
`.html` ဖိုင်ကို Save ပြီးတာနဲ့ Double-click လုပ်လိုက်ရင် Browser (Chrome, Edge, Firefox စသဖြင့်) မှာ ရလဒ်ကို မြင်ရမှာ ဖြစ်ပါတယ်။ Code ပြောင်းရင် Save ပြန်လုပ်ပြီး Browser မှာ Refresh (F5) နှိပ်ရုံနဲ့ ပြောင်းလဲမှုတွေကို ကြည့်လို့ ရပါတယ်။ ဒါကြောင့် အလုပ်လုပ်နေစဉ်မှာ Browser ကို ဘေးမှာ ဖွင့်ထားဖို့ အကြံပြုပါတယ်။

**ဥပမာ -**
```html
<h1>Hello World</h1>
```
မှတ်ချက် — HTML file က Server မလိုဘဲ တိုက်ရိုက် ဖွင့်လို့ရတာမို့ စတင်လေ့လာဖို့ အရမ်း လွယ်ကူပါတယ်။

#### မှတ်ထားရမယ့် အချက်များ
* Editor က Plain Text ရေးလို့ရတဲ့ ကိရိယာ ဖြစ်ရပါမယ်။
* ဖိုင်ကို `.html` extension နဲ့ Save လုပ်ရပါမယ်။
* VS Code က Beginner တွေအတွက် အဆင်ပြေဆုံး Free Editor တစ်ခုပါ။
* Code ပြောင်းပြီးတိုင်း Browser မှာ Refresh လုပ်ဖို့ မမေ့ပါနဲ့။
