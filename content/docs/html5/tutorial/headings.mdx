### Heading Tag များ — h1 ကနေ h6 အထိ
Heading တွေက Webpage ရဲ့ ခေါင်းစဉ်တွေကို သတ်မှတ်ပေးပြီး `<h1>` (အကြီးဆုံး) ကနေ `<h6>` (အငယ်ဆုံး) အထိ အဆင့် ၆ ဆင့် ရှိပါတယ်။ Browser က Heading အဆင့်အလိုက် အရွယ်အစား ကွဲပြားအောင် သူ့အလိုလို ပြသပေးပါတယ်။ Page တစ်ခုမှာ `<h1>` ကို အဓိက ခေါင်းစဉ်အနေနဲ့ သုံးပြီး ကျန်အပိုင်းတွေကို အောက်အဆင့် Heading တွေနဲ့ ခွဲပါတယ်။

**ဥပမာ -**
```html
<h1>အကြီးဆုံး ခေါင်းစဉ်</h1>
<h2>ပိုသေးတဲ့ ခေါင်းစဉ်</h2>
<h3>အသေးစား ခေါင်းစဉ်</h3>
```
မှတ်ချက် — Browser မှာ ခေါင်းစဉ်တွေ အရွယ်အစား အဆင့်ဆင့် မြင်ရပါလိမ့်မယ်။

#### Heading တွေ ဘာကြောင့် အရေးကြီးသလဲ
Heading တွေက စာဖတ်သူ အတွက်သာ မဟုတ်ဘဲ Search Engine (Google စသည်) နဲ့ Screen Reader တွေအတွက်ပါ အရေးကြီးပါတယ်။ Search Engine တွေက Heading တွေကို ဖတ်ပြီး Page ရဲ့ အကြောင်းအရာတွေကို နားလည်ကာ SEO (Search Engine Optimization) မှာ အကျိုးပြုပါတယ်။ Screen Reader တွေကလည်း Heading တွေကနေ User တွေကို Page အတွင်း လမ်းညွှန်ပေးပါတယ်။

**ဥပမာ -**
```html
<h1>လေ့ကျင့်ရေး Website</h1>
<h2>HTML သင်ခန်းစာ</h2>
```
မှတ်ချက် — ခေါင်းစဉ်တွေကို အဓိပ္ပါယ်ရှိရှိ ရွေးပြီး Page ရဲ့ ဖွဲ့စည်းပုံနဲ့ လိုက်လျောညီထွေ သုံးပါ။

#### Heading အဆင့်တွေ မကျော်ဘဲ သုံးခြင်း
h1 ကနေပြီး h2 ကို ကျော်ပြီး တိုက်ရိုက် h3 ကို မသုံးတာက ပိုကောင်းပါတယ်။ အဆင့်တွေကို ဆက်တိုက် (sequential) သုံးမှ Screen Reader နဲ့ Search Engine တွေ အတွက် ဖွဲ့စည်းပုံ ရှင်းပါတယ်။ အမှန်တော့ ဒါက Style ကိစ္စမဟုတ်ဘဲ Structure/Semantics (အဓိပ္ပါယ်ရှိတဲ့ ဖွဲ့စည်းပုံ) ကိစ္စ ဖြစ်ပါတယ်။

**ဥပမာ -**
```html
<h1>အပိုင်း ၁</h1>
<h2>အပိုင်းခွဲ ၁.၁</h2>
<h3>အပိုင်းခွဲ ၁.၁.၁</h3>
```
မှတ်ချက် — အဆင့်တွေ မကျော်ဘဲ တစ်ဆင့်ချင်း သုံးတာက ပိုစနစ်ကျပါတယ်။

#### Heading တွေကို Style လုပ်ခြင်း
Heading တွေရဲ့ မူလပုံစံကို `style` attribute နဲ့ အရောင်၊ အရွယ်အစား စသဖြင့် ပြောင်းလို့ ရပါတယ်။ ရှုပ်ထွေးတဲ့ Styling တွေကိုတော့ CSS (Cascading Style Sheets) နဲ့ သုံးတာက ပိုသင့်လျော်ပါတယ်။ ဒါကြောင့် Heading ကို Style လုပ်လို့ရတယ် ဆိုပေမယ့် အဓိကရည်ရွယ်ချက်က Structure ဖန်တီးဖို့ ဖြစ်ပါတယ်။

**ဥပမာ -**
```html
<h1 style="color: blue; font-size: 40px;">အပြာရောင် ခေါင်းစဉ်</h1>
```
မှတ်ချက် — style attribute က မြန်မြန်ဆန်ဆန် စမ်းကြည့်ဖို့ ကောင်းပြီး အခြေအနေကြီးတွေမှာတော့ CSS ကို သုံးပါတယ်။

#### မှတ်ထားရမယ့် အချက်များ
* Heading က h1 ကနေ h6 အထိ အဆင့် ၆ ခု ရှိပါတယ်။
* Page တစ်ခုမှာ h1 ကို တစ်ကြိမ်သာ အသုံးပြုသင့်ပါတယ်။
* Heading level တွေကို မကျော်ဘဲ ဆက်တိုက် သုံးပါ။
* Heading တွေက SEO နဲ့ Screen Reader အတွက် အရေးပါပါတယ်။
