### HTML Document ရဲ့ ဖွဲ့စည်းပုံ
HTML page တိုင်းမှာ Document ရဲ့ အခြေခံ ဖွဲ့စည်းပုံ ရှိပါတယ်။ `<head>` အတွင်းမှာ Page အကြောင်း အသေးစိတ် (title စသည်) ထည့်ပြီး `<body>` အတွင်းမှာ ကြည့်သူတွေ မြင်ရမယ့် Content တွေ ထည့်ပါတယ်။ Tag ဆိုတာ `<အမည်>` ပုံစံနဲ့ ရေးတဲ့ HTML ရဲ့ အခြေခံ Block တွေ ဖြစ်ပါတယ်။

**ဥပမာ -**
```html
<!DOCTYPE html>
<html>
<head>
  <title>ကျွန်တော့် Page</title>
</head>
<body>
  <h1>မင်္ဂလာပါ</h1>
  <p>ဒါကတော့ ရိုးရှင်းတဲ့ Paragraph တစ်ခုပါ။</p>
</body>
</html>
```
မှတ်ချက် — `<html>` အတွင်းမှာ `<head>` နဲ့ `<body>` ဆိုပြီး အပိုင်း နှစ်ပိုင်း ပါဝင်ပါတယ်။

#### h1 Heading နဲ့ p Paragraph
`<h1>` က အကြီးဆုံး Heading (ခေါင်းစဉ်) ဖြစ်ပြီး `<p>` က Paragraph (စာပိုဒ်) ဖြစ်ပါတယ်။ Browser က Tag တွေရဲ့ သဘောသဘာဝကို ကြည့်ပြီး အကြီးအငယ်၊ အကွာအဝေးတွေကို သူ့အလိုလို နေရာချပေးပါတယ်။ ဆိုလိုတာက Styling မလိုပဲ အသွင်အပြင်တွေ လှပစွာ ပြနေတာ ဖြစ်ပါတယ်။

**ဥပမာ -**
```html
<h1>ခေါင်းစဉ် အကြီးဆုံး</h1>
<p>ဒါက စာပိုဒ် တစ်ပိုဒ်ပါ။</p>
```
မှတ်ချက် — Browser မှာ Heading က အကြီးနဲ့ ထင်ထင်ရှားရှား မြင်ရပြီး Paragraph က အနည်းငယ် ဖတ်ရ လွယ်ကူအောင် ပြပေးပါတယ်။

#### Link ထည့်ခြင်း (a Tag)
အခြား Website ဒါမှမဟုတ် Page ကို သွားနိုင်ဖို့ `<a>` (anchor) Tag ကို သုံးပါတယ်။ `href` attribute ထဲမှာ သွားရမယ့် URL (လိပ်စာ) ကို ထည့်ပေးရပါတယ်။ ဒီအချက်ကို Link လို့ ခေါ်ပြီး ကလစ်နှိပ်ရင် အဲဒီနေရာကို သွားလို့ ရပါတယ်။

**ဥပမာ -**
```html
<a href="https://www.google.com">Google ကို သွားမယ်</a>
```
မှတ်ချက် — `<a>` Tag ရဲ့ အတွင်းမှာ ရေးထားတဲ့ စာသားကိုပဲ User တွေ မြင်ရပါတယ်။

#### Image ထည့်ခြင်း (img Tag)
ပုံတစ်ပုံ ထည့်ဖို့ `<img>` Tag ကို သုံးပြီး `src` မှာ ပုံရဲ့ လိပ်စာ (path) နဲ့ `alt` မှာ ပုံပျက်သွားရင် ပြရမယ့် စာသား ထည့်ပါတယ်။ `<img>` မှာ Content မရှိတာမို့ Closing Tag မလိုပဲ ကိုယ့်ဘာသာ ပိတ်သွားပါတယ်။

**ဥပမာ -**
```html
<img src="dog.jpg" alt="ခွေးလေး တစ်ကောင်">
```
မှတ်ချက် — `<img>` က Empty Tag ဖြစ်လို့ `<img></img>` လို့ ရေးစရာ မလိုပါဘူး။

#### br Tag နဲ့ Line Break
`<br>` Tag က Line Break (စာကြောင်း ချိုးခြင်း) ကို ပြုလုပ်ပေးပါတယ်။ Paragraph အတွင်းမှာ နောက်လိုင်း ဆင်းချင်တဲ့အခါ `<br>` ထည့်ရုံပါပဲ။ HTML မှာ Enter နှိပ်ထားရုံနဲ့ Line မကျတာမို့ `<br>` ကို သိသိသာသာ သုံးရပါတယ်။

**ဥပမာ -**
```html
<p>ပထမလိုင်း<br>ဒုတိယလိုင်း</p>
```
မှတ်ချက် — Browser မှာ မြင်ရမယ့် ရလဒ်က နှစ်ကြောင်း ခွဲပြီး ပြသပေးပါလိမ့်မယ်။

#### မှတ်ထားရမယ့် အချက်များ
* မြင်ရမယ့် အကြောင်းအရာတွေ အားလုံးက `<body>` အတွင်း ရှိရပါတယ်။
* `<a href>` နဲ့ Link တွေ၊ `<img src>` နဲ့ ပုံတွေ ထည့်ပါတယ်။
* `<br>` က Line Break အတွက် ဖြစ်ပြီး Empty Tag ပါ။
* Code တိုင်းကို Browser မှာ ဖွင့်ကြည့်ပြီး ရလဒ် လေ့လာပါ။
