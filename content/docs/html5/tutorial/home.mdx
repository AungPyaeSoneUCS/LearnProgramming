HTML ဆိုတာ Web ရဲ့ အခြေခံအုတ်မြစ် ဖြစ်ပြီး၊ ဒီ HTML5 သင်တန်းမှာ ခင်ဗျားအနေနဲ့ HTML ကို **အခြေခံမှ အဆင့်မြင့်အထိ** အဆင့်ဆင့် လေ့လာသွားရမှာ ဖြစ်ပါတယ်။

### ဒီသင်တန်းမှာ ဘာတွေ သင်ရမလဲ?

- **HTML Tutorial** — Tags, Elements, Attributes, Links, Images, Tables, Lists စတဲ့ အခြေခံအားလုံး။
- **HTML Forms** — ဒေတာထည့်သွင်းမှုအတွက် Form နဲ့ Input အမျိုးမျိုး။
- **HTML Graphics** — Canvas နဲ့ SVG ဖြင့် ပုံဆွဲနည်း။
- **HTML Media** — Video, Audio, YouTube ထည့်သွင်းနည်း။
- **HTML APIs** — Geolocation, Web Storage, Web Workers စတဲ့ Browser APIs များ။
- **HTML References** — Tag, Attribute, Event စတဲ့ အသေးစိတ်စာရင်းများ။
- **လေ့ကျင့်ခန်းနှင့် စာမေးပွဲ** — နားလည်မှု စစ်ဆေးရန် သင်ခန်းစာတိုင်း၏ Quiz များနှင့် နောက်ဆုံး Certificate စာမေးပွဲ။

### စတင်ရန် ဘာတွေ လိုအပ်လဲ?

- **Browser** တစ်ခုသာ လုံလောက်ပါတယ် (Chrome, Edge, Firefox စသဖြင့်)။
- **Editor** — Notepad, VS Code စတာတွေ သုံးနိုင်ပါတယ် (နောက်သင်ခန်းစာမှာ အသေးစိတ် လေ့လာရမှာပါ)။

**သင့်ရဲ့ ပထမဆုံး HTML ဖိုင် -**
```html
<!DOCTYPE html>
<html lang="my">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <p>ဟယ်လို ကမ္ဘာ!</p>
</body>
</html>
```

မှတ်ချက် — အပေါ်က Code ကို copy လုပ်ပြီး `index.html` အမည်နဲ့ သိမ်း၍ browser ထဲ ဖွင့်ကြည့်နိုင်ပါတယ်။
