### HTML Certificate သင်ခန်းစာ

ဒီသင်ခန်းစာက HTML အကြောင်းအရာ တွေအားလုံးကို ခြုံငုံပြီး မေးခွန်း (၂၀) နဲ့ စစ်ဆေးပေးမှာ ဖြစ်ပါတယ်။ သင်ခန်းစာ အစဉ်လိုက် လေ့လာပြီးသားဆိုရင် ဒီ Quiz က ကိုယ့်ကိုယ်ကိုယ် အဖိုးတန်တဲ့ ပြန်လည်သုံးသပ်မှု တစ်ခု ဖြစ်ပါလိမ့်မယ်။

ထုံးစံအတိုင်း တစ်ခုချင်း မှတ်မိလို့ မရဘူးဆိုရင် ပြန်ဖတ်လို့ ရပါတယ် — ဗဟုသုတ အသစ်တွေ ယူဖို့ အမှားတွေက နောက်ဆုံးအဆင့် အထောက်အကူ ဖြစ်ပါတယ်။

#### လွှမ်းခြုံထားတဲ့ ခေါင်းစဉ်များ

- Basic Tag နဲ့ Attribute
- Links ၊ Images နဲ့ Comment
- Tables နဲ့ Forms များရဲ့ Input များ
- Semantic HTML
- Media (Video ၊ Audio)
- Web API (localStorage ၊ Geolocation)
- HTML Entity များ

#### ဖြေရန် နည်းလမ်း

မေးခွန်း တစ်ခုစီမှာ အဖြေမှန် တစ်ခုသာ ရှိပြီး အခက်အခဲ အဆင့် ကတော့ အစပိုင်းမှာ လွယ်၍ နောက်လေလေ ခက်လေ ဖြစ်ပါတယ်။ အဖြေ မသေချာတဲ့ မေးခွန်းကို ကျော်ပြီး နောက်ကို ဆက်သွားလို့ ရပါတယ်။ မေးခွန်း (၂၀) စလုံး ကြိုးစားဖြေပြီးမှ အမှတ်ကြည့်ပါ။
