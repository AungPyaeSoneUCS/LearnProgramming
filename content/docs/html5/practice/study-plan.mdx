စာသင်ဖို့ အချိန်ပေးဖို့တော့ လိုပါတယ် — အဲဒီအတွက် ဒီနေရာမှာ ၄ ပတ်တာ လေ့လာမှု အစီအစဉ်ကို ရေးဆွဲပေးထားပါတယ်။ တစ်နေ့ကို မိနစ် ၃၀ လောက် အချိန်ပေးနိုင်ရင် လွယ်ကူစွာ လိုက်လုပ်နိုင်တဲ့ schedule ဖြစ်ပါတယ်။ ပိုကြိုးစားနိုင်ရင် ရက်တစ်ရက်ခြား နှစ်ကြိမ် လေ့လာရင် ပိုမြန်ပါတယ်။

### Week 1 — အခြေခံ (Basic Tags)

ပထမ သီတင်းပတ်မှာ HTML တစ်ခုလုံးရဲ့ အုတ်မြစ်ဖြစ်တဲ့ အခြေခံ tag တွေကို လေ့လာပါမယ်။ Heading၊ paragraph ကစပြီး attribute ဆိုတာ ဘာလဲဆိုတာ နားလည်အောင် လုပ်ပါ။ Practice လုပ်ဖို့မမေ့ပါနဲ့ — ကိုယ်တိုင် စမ်းရေးမှသာ မှတ်မိပါတယ်။

Daily အနေနဲ့ —
- Day 1-2: Introduction နဲ့ ပထမဆုံး page; element နဲ့ attribute
- Day 3-4: Heading နဲ့ paragraph; text formatting
- Day 5-6: List နဲ့ link; practice file လေးတွေသုံးပြီး ပြန်လေ့လာပါ
- Day 7: Exercises အပေါ်က ပြန်စမ်းပြီး ကိုယ့်ရဲ့ နားလည်မှု စစ်ဆေးပါ

မှတ်ချက် — မှတ်မိအောင် တစ်နေ့ကို မိနစ် ၃၀ လောက် ပေးပြီး နေ့လယ်စာ ချက်စားလောက် အလျဉ်းမှာလည်း screenshot ကြည့်တာမျိုး မလုပ်ဘဲ keyboard ပေါ်မှာ စမ်းရေးတာ ပိုထိရောက်ပါတယ်။

### Week 2 — Link နှင့် Media

ဒုတိယ သီတင်းပတ်မှာ link ကို ပိုကျွမ်းကျင်အောင် လုပ်ပြီး ပုံ၊ ဗီဒီယို၊ အသံ စတဲ့ media တွေ ထည့်သွင်းတတ်အောင် လေ့လာပါမယ်။ Image ရဲ့ `alt` attribute ကလို accessibility နဲ့ ဆိုင်တဲ့ အသေးစိတ်တွေကိုလည်း ဒီအပတ်မှာ တွေ့လာပါလိမ့်မယ်။

Daily အနေနဲ့ —
- Day 1-2: Link အမျိုးမျိုး (absolute/relative, mailto)
- Day 3-4: Image ထည့်ခြင်း၊ `width`/`height` နဲ့ `alt`
- Day 5-6: Video နဲ့ audio ထည့်ခြင်း
- Day 7: challenges ဖိုင်မှာရှိတဲ့ product card စမ်းဆောက်ကြည့်ပါ

မှတ်ချက် — media file တွေက ဥပမာဖိုင်တွေ အတွက်ပဲ ဆိုတာ သတိရပြီး ကိုယ်ပိုင်ဖိုင် ရှိရင် အဲဒါတွေ အစားထိုး သုံးပါ။

### Week 3 — Forms နှင့် Tables

တတိယ သီတင်းပတ်မှာ သုံးစွဲသူဆီက အချက်အလက် ယူတဲ့ form တွေနဲ့ ဇယားတွေကို သင်ယူပါမယ်။ Form က website ရဲ့ အရေးပါတဲ့ အပိုင်းဖြစ်လို့ `label` နဲ့ `input` ချိတ်ပုံကို သေချာ လေ့လာပါ။

Daily အနေနဲ့ —
- Day 1-2: Form ရဲ့ ဖွဲ့စည်းပုံနဲ့ input type တွေ
- Day 3-4: Label ချိတ်ဆက်ပုံ၊ button တွေ
- Day 5-6: Table ရဲ့ tr/th/td နဲ့ ဇယားတွေ ရေးလေ့ကျင့်
- Day 7: exercises ရဲ့ exercise ၅ နဲ့ ၆ ကို ဖြေကြည့်ပါ

မှတ်ချက် — Form ၂ ခုလောက် ကိုယ်တိုင် စိတ်ကြိုက်ဆောက်ကြည့်မှ ရလဒ်ကောင်း ရပါတယ်။

### Week 4 — Advanced နှင့် APIs

နောက်ဆုံး သီတင်းပတ်မှာ Semantic HTML tag တွေ၊ အဆင့်မြင့် topic နဲ့ Web API အကြောင်း မိတ်ဆက် လေ့လာပြီး ၁ ရက်မှာ စာမေးပွဲကြီး အတွက် ပြင်ဆင်ပါမယ်။ ဒီအတောအတွင်း website.mdx ပါ စာမျက်နှာ ၄ ပိုင်း website ကို ဆောက်ကြည့်တာက အကြံကောင်းပါတယ်။

Daily အနေနဲ့ —
- Day 1-2: Semantic HTML (header, nav, main, footer) နဲ့ accessibility
- Day 3: Web API မှာ Geolocation စမ်းကြည့်ခြင်း
- Day 4-5: website.mdx က tutorial အတိုင်း website တစ်ခုလုံး ဆောက်ပါ
- Day 6: သင်ရိုးတစ်လျှောက် ပြန်ကြည့်ပြီး မေးခွန်းတွေ ဖြေပါ
- Day 7: Final quiz (quiz.mdx) ဖြေဆိုပြီး Certificate ရယူပါ

မှတ်ချက် — Final quiz ကို ဖြေတုန်း internet မဖွင့်ဘဲ ဖြေကြည့်ပါ။ မဖြေနိုင်တဲ့မေးခွန်း ရှိနေရင် ပြန်လေ့လာဖို့ အခွင့်အရေး ရှိပါသေးတယ်။

### လေ့လာမှု အောင်မြင်ရေး Tip များ

- တစ်နေ့ ၃၀ မိနစ် ပုံမှန်လုပ်တာက တစ်ပတ်လုံး ငြီးငွေ့အောင် လုပ်တာထက် ပိုထိရောက်ပါတယ်။
- အပတ်တိုင်းရဲ့ နောက်ဆုံးရက်မှာ practice ပြန်လုပ်ခြင်းဖြင့် မှတ်မိစေပါ။
- နားမလည်တဲ့ topic ကို နောက်နေ့မထားဘဲ အဲဒီနေ့မှာတင် ပြန်ဖတ်ပါ။

မှတ်ချက် — ကိုယ်က ပိုနှေးလို့ အပတ်ပိုကြာတယ်ဆိုရင် စိတ်မပူပါနဲ့ — schedule က အကိုးအကားပဲ ဖြစ်ပြီး ကိုယ့်အရှိန်အဟုန်နဲ့ လေ့လာပါ။
