ဒီစာမျက်နှာမှာ HTML ရဲ့ အသုံးအများဆုံး element တွေအတွက် အသင့်ကူးယူ သုံးလို့ရတဲ့ ဥပမာလေးတွေ စုထားပါတယ်။ တစ်ခုချင်းစီမှာ ဘာတွေ ပါဝင်လဲ၊ ဘယ်လို အလုပ်လုပ်လဲ ဆိုတာကို မြန်မာလို ရှင်းပြပေးထားလို့ ကိုယ့်အလုပ်ထဲမှာ လိုအပ်သလို ပြင်ပြီး သုံးနိုင်ပါတယ်။ Copy-paste လုပ်ပြီး browser မှာ စမ်းကြည့်ရုံနဲ့ ရပါတယ်။

### ခေါင်းစဉ်နှင့် စာပိုဒ် (Headings & Paragraphs)

`<h1>` မှ `<h6>` အထိ ခေါင်းစဉ် ၆ မျိုးရှိပြီး `h1` က အကြီးဆုံး၊ `h6` က အသေးဆုံး ဖြစ်ပါတယ်။ စာပိုဒ်တွေကတော့ `<p>` tag နဲ့ ရေးပါတယ်။ စာမျက်နှာရဲ့ အခြေခံ အဆောက်အဦတွေ ဖြစ်တဲ့အတွက် ပထမဆုံး မှတ်ထားသင့်ပါတယ်။

**ဥပမာ -**

```html
<h1>မင်္ဂလာပါ ကမ္ဘာ</h1>
<h2>နိဒါန်း</h2>
<p>ဒါက ပထမဆုံး စာပိုဒ်ပါ။ ဒီနေရာမှာ အကြောင်းအရာ အများကြီး ရေးနိုင်ပါတယ်။</p>
<p>နောက်ထပ် စာပိုဒ်တစ်ခုလည်း ထပ်ထည့်လို့ရပါတယ်။</p>
```

မှတ်ချက် — heading တစ်မျိုးတည်းကို စာမျက်နှာတစ်ခုမှာ တစ်ခါပဲ သုံးသင့်တာ `h1` ဖြစ်ပြီး ကျန်တာတွေက အကြောင်းအရာကို ခွဲထားဖို့ပဲ ဖြစ်ပါတယ်။

### Link (လင့်များ)

`<a>` tag က စာမျက်နှာတစ်ခုကနေ နောက်တစ်ခုကို သွားဖို့ သုံးပါတယ်။ `href` attribute ထဲမှာ သွားချင်တဲ့ လိပ်စာကို ထည့်ပေးရပါတယ်။ `target="_blank"` ထည့်ရင် သီးခြား tab အသစ်မှာ ပွင့်ပါတယ်။

**ဥပမာ -**

```html
<p>အသေးစိတ်ကို <a href="https://example.com">ဒီမှာ ကြည့်ပါ</a>။</p>
<p>Official site <a href="https://developer.mozilla.org" target="_blank">MDN</a> ကိုလည်း ဖတ်နိုင်ပါတယ်။</p>
```

မှတ်ချက် — link ရဲ့ အပြာရောင် text အစား ကိုယ်ပိုင်စာသားနဲ့ link ကို ဖော်ပြခြင်းက screen reader သုံးသူတွေအတွက် ပိုအဆင်ပြေပါတယ်။

### ပုံ (Image)

`<img>` tag က ပုံတွေ ထည့်သွင်းဖို့ ဖြစ်ပြီး closing tag မလိုပါဘူး။ `src` မှာ ပုံဖိုင် လိပ်စာ၊ `alt` မှာ ပုံပျက်ရင် ပြမယ့် စာသားကို ထည့်ရပါတယ်။ `width` နဲ့ `height` နဲ့ အရွယ်အစား ညှိနိုင်ပါတယ်။

**ဥပမာ -**

```html
<img src="https://example.com/photo.jpg" alt="ရေကန်ရဲ့ နေဝင်ချိန် မြင်ကွင်း" width="400" height="250">
```

မှတ်ချက် — `alt` က screen reader ဖတ်ပေးရုံမက အကြောင်းတစ်ခုခုကြောင့် ပုံမပေါ်ရင်လည်း နားလည်စေမယ့် စာသား ဖြစ်ပါတယ်။

### စာရင်း (Lists)

List က အမျိုးအစား နှစ်မျိုးရှိပါတယ် — နံပါတ်တပ်ထားတဲ့ `<ol>` (ordered list) နဲ့ နံပါတ်မပါတဲ့ `<ul>` (unordered list)။ List item တစ်ခုချင်းစီကို `<li>` နဲ့ ရေးပါတယ်။

**ဥပမာ -**

```html
<h3>အကြိုက်ဆုံး အစားအစာများ</h3>
<ul>
  <li>မုန့်ဟင်းခါး</li>
  <li>ကြေးအိုး</li>
  <li>မန်းကျည်းသီး သုပ်သုပ်</li>
</ul>

<h3>အဆင့်ဆင့် လုပ်ရန်</h3>
<ol>
  <li>ပထမအဆင့် လုပ်ပါ</li>
  <li>ဒုတိယအဆင့် လုပ်ပါ</li>
</ol>
```

မှတ်ချက် — အစီအစဉ်လိုက် လုပ်ရမယ့်အရာတွေဆို `ol` သုံးပြီး ဒီလိုမဟုတ်တဲ့ စာရင်းတွေအတွက် `ul` သုံးပါတယ်။

### Table (ဇယား)

`<table>` ထဲမှာ `<tr>` က အတန်း (row) တစ်ခုစီ ဖြစ်ပြီး `<th>` က column ခေါင်းစဉ်၊ `<td>` က အချက်အလက် အကွက်တွေ ဖြစ်ပါတယ်။ ဇယားက နှိုင်းယှဉ်ဖော်ပြမှုတွေအတွက် အသုံးဝင်ပါတယ်။

**ဥပမာ -**

```html
<table border="1">
  <tr>
    <th>မြို့</th>
    <th>လူဦးရေ</th>
  </tr>
  <tr>
    <td>ရန်ကုန်</td>
    <td>၅ သန်း</td>
  </tr>
  <tr>
    <td>မန္တလေး</td>
    <td>၁.၂ သန်း</td>
  </tr>
</table>
```

မှတ်ချက် — ခေတ်သစ် website တွေမှာ table ကို layout အတွက် မသုံးတော့ဘဲ အချက်အလက် ဇယားအဖြစ်သာ သုံးပါတယ်။

### Form (ပုံစံ)

`<form>` က သုံးစွဲသူတွေဆီက အချက်အလက် ယူဖို့ ဖြစ်ပါတယ်။ `<input>` က စာရိုက်စရာနေရာ၊ `<label>` က ထိုနေရာရဲ့ အမည်ပြ၊ `<button>` က ပေးပို့လုပ်ဆောင်ချက် ဖြစ်ပါတယ်။

**ဥပမာ -**

```html
<form>
  <label for="name">နာမည်</label><br>
  <input type="text" id="name" name="name"><br>
  <label for="email">အီးမေးလ်</label><br>
  <input type="email" id="email" name="email"><br><br>
  <button type="submit">ပေးပို့မည်</button>
</form>
```

မှတ်ချက် — `<label>` ရဲ့ `for` နဲ့ `<input>` ရဲ့ `id` ကို တူညီအောင် ပေးထားမှ label ကိုနှိပ်ရင်လည်း input ထဲ ဝင်ရောက်နိုင်ပါတယ်။

### Video Placeholder (ဗီဒီယိုနေရာ)

`<video>` tag နဲ့ ဗီဒီယိုထည့်နိုင်ပြီး `<source>` က ဖိုင်လိပ်စာကို ချိတ်ပေးပါတယ်။ `controls` က play/pause ခလုတ်တွေ ပြပေးပြီး browser မှာ မဖွင့်နိုင်ရင် fallback message ပြဖို့လည်း ထည့်နိုင်ပါတယ်။

**ဥပမာ -**

```html
<video width="480" height="270" controls>
  <source src="movie.mp4" type="video/mp4">
  သင့် browser မှာ video ကို မဖွင့်နိုင်ပါ။
</video>
```

မှတ်ချက် — `video.mp4` နဲ့ `movie.mp4` ကဲ့သို့သော ဖိုင်တွေက ဥပမာသာ ဖြစ်ပြီး ကိုယ့်မှာ ရှိတဲ့ ဗီဒီယိုဖိုင် လိပ်စာနဲ့ အစားထိုးပြီး သုံးပါတယ်။
