ဒါက Takkatho HTML သင်တန်းရဲ့ သင်ရိုးညွှန်းတမ်း အပြည့်အစုံ ဖြစ်ပါတယ်။ သင်ခန်းစာတွေကို ဘာသာရပ် အကြီး ၇ ခုဖြင့် ခွဲထားပြီး တစ်ခုစီမှာ သင်ခန်းစာ အရေအတွက် ရှိပါတယ်။ ကိုယ့် တိုးတက်မှုကို ခြေရာခံနိုင်ဖို့ ဒီစာရင်းကို သိမ်းထားနိုင်ပြီး တစ်ခုပြီးတစ်ခု အမှတ်အသားလိုက် ရှုပ်ထွေးအောင် နေပါ။

### Chapter စာရင်း

အောက်မှာပါတဲ့ ဇယားက သင်တန်းရဲ့ အခန်း (chapter) တွေ၊ တစ်ခန်းစီရဲ့ အကြောင်းသဘောတရားနဲ့ သင်ခန်းစာ အရေအတွက်ကို ဖော်ပြထားပါတယ်။ ဒီဇယားကို သင်တန်းလမ်းညွှန် အနေနဲ့ သုံးနိုင်ဖို့ ဒီဇိုင်းထားတာ ဖြစ်ပါတယ်။

| Chapter | အကြောင်းအရာ | သင်ခန်းစာ အရေအတွက် |
| --- | --- | --- |
| Tutorial | HTML အခြေခံ၊ element၊ attribute၊ heading၊ text ဖော်ပြခြင်း | ၈ |
| Forms | Form ဆောက်ခြင်း၊ input အမျိုးအစားများ၊ validation | ၅ |
| Graphics | SVG နှင့် Canvas အကြောင်း မိတ်ဆက် | ၂ |
| Media | Audio၊ Video၊ ပုံဖော်မပြခြင်း အမျိုးမျိုး | ၃ |
| APIs | Geolocation စသော built-in Web API မိတ်ဆက် | ၂ |
| References | Tag နှင့် attribute အားလုံး၏ ကိုးကားစာရင်း | ၃ |
| Certificate | သင်တန်းဆုံးခန်း Test နှင့် လက်မှတ် ရယူခြင်း | ၁ |

မှတ်ချက် — သင်ခန်းစာ စုစုပေါင်း ၂၄ ခုရှိပြီး ပုံမှန် လေ့လာရင် ၄ ပတ် အတွင်း အပြီး သင်ယူနိုင်ပါတယ်။

### Tutorial — HTML အခြေခံ

ဒီ Chapter မှာ HTML ရဲ့ အခြေခံအုတ်မြစ်အားလုံး ပါဝင်ပါတယ်။ Element ကဘာလဲ၊ tag ချိတ်ပုံကဘယ်လိုလဲဆိုတာကစပြီး စာသား၊ လင့်၊ ပုံ၊ စာရင်း၊ ဇယား အထိ အဆင့်ဆင့် သင်ယူရပါတယ်။ ဒါတွေက နောက် Chapter တွေအားလုံးရဲ့ အခြေခံ ဖြစ်တာကြောင့် အရေးကြီးဆုံး part လို့ ဆိုနိုင်ပါတယ်။

- HTML မှာရှိ သင်ခန်းစာ ၈ ခု
- သင်ခန်းစာတိုင်းမှာ examples နဲ့ practice file တွေ ပါဝင်သည်

### Forms — ပုံစံများ

Form က website ကနေ သုံးစွဲသူ အချက်အလက်တွေ စုဆောင်းတဲ့ နည်းလမ်း ဖြစ်ပါတယ်။ Text box၊ button၊ dropdown တို့အပြင် input validation အကြောင်းအထိ ပါဝင်ပါတယ်။ အီးမေးလ်၊ မိုဘိုင်းဖုန်း အမျိုးအစား input တွေပါ ပါဝင်တာကြောင့် လက်တွေ့ project တွေမှာ တန်ဖိုးရှိပါတယ်။

### Graphics — ဂရပ်ဖစ်

Graphics Chapter မှာ SVG နဲ့ Canvas အကြောင်း မိတ်ဆက်ပေးပါတယ်။ SVG က vector ပုံဆွဲခြင်း ဖြစ်ပြီး Canvas က JavaScript နဲ့ pixel အလိုက် ဆွဲခြင်း ဖြစ်ပါတယ်။ နှစ်ခုလုံးက advanced topic ဖြစ်ပေမယ့် အခြေခံ လေ့လာထားရုံနဲ့ အသုံးဝင်ပါတယ်။

### Media — မီဒီယာ

Media Chapter မှာ ရုပ်ပုံနဲ့ ဆိုင်တဲ့ အဆင့်မြင့် နည်းလမ်းတွေနဲ့ ဗီဒီယို၊ အသံချထည့်ခြင်းကို သင်ယူရပါတယ်။ Responsive image တွေ၊ `<video>` နဲ့ `<audio>` tag အသုံးပြုပုံတွေ ပါဝင်ပါတယ်။ ဒီပြီးရင် ကိုယ့် site မှာ multimedia ထည့်လို့ အဆင်ပြေပါပြီ။

### APIs — Web API

Web APIs က browser ကိုယ်တိုင် ပေးထားတဲ့ built-in လုပ်ဆောင်ချက်တွေ ဖြစ်ပါတယ်။ ဥပမာ — Geolocation က သုံးစွဲသူရဲ့ တည်နေရာကို ရယူပေးတာ ဖြစ်ပါတယ်။ ဒီ Chapter က JavaScript နဲ့ တွဲဖက်လေ့လာရမဲ့ topic တွေ ဆိုပေမယ့် HTML ရဲ့ နောက်ကွယ်က ဖွဲ့စည်းပုံကို နားလည်ထားဖို့ အထောက်အကူ ဖြစ်ပါတယ်။

### References — ကိုးကားစာရင်း

References Chapter က HTML tag နဲ့ attribute အားလုံးရဲ့ အကျဉ်းချုပ်စာရင်း ဖြစ်ပါတယ်။ သင်ပြီးတဲ့အခါ မေ့သွားတဲ့ tag တစ်ခုကို ပြန်ရှာဖို့ ဒီစာရင်း ကိုးကားလို့ရပါတယ်။ ဒီတော့ ဒီ chapter က သင်တန်းရဲ့ နောက်ဆုံးမှာပဲ ရှိပေမဲ့ လိုအပ်တိုင်း ပြန်ဖတ်တာ ကောင်းပါတယ်။

### Certificate — လက်မှတ်

နောက်ဆုံး Chapter မှာ သင်တန်းဆုံးခန်း Test တစ်ခု ပါဝင်ပြီး အောင်မြင်ရင် Takkatho ရဲ့ Certificate ရရှိမှာ ဖြစ်ပါတယ်။ Test က Tutorial၊ Forms နဲ့ Media Chapter တွေက အကြောင်းအရာတွေကို အကျုံးဝင်ထားပါတယ်။ ဒါကြောင့် chapter တိုင်းကို စနစ်တကျ လေ့လာပြီးမှ test ဖြေပါ။
