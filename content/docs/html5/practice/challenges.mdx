စိန်ခေါ်မှုတွေက သင်ယူပြီးသား အသိပညာကို စုစည်းပြီး လက်တွေ့ သုံးကြည့်ဖို့ ပြုလုပ်ထားတာ ဖြစ်ပါတယ်။ Answer key မရှိပါ — ဘယ်လို ရေးရေးလဲ ကိုယ်ရေးတဲ့ ကုဒ်ကို ရှင်းပြနိုင်ပြီး browser မှာ ရလဒ်ကောင်း မြင်ရရင် အောင်မြင်ပါပြီ။ သင်ခန်းစာတစ်ခုစီမှာ စဉ်းစားစရာ အချက်တွေကို hint အနေနဲ့ ပေးထားပါတယ်။

### စိန်ခေါ်မှု ၁ — Product Card

သစ်သီးတစ်လုံးရဲ့ Product Card တစ်ခု ရေးပါ။ Card ထဲမှာ အမည်၊ ပုံ၊ ဖော်ပြချက်၊ ဈေးနဲ့ ဝယ်မည် button ပါရမယ်။ တကယ့် e-commerce site တွေမှာ ဒီပုံစံ card တွေ တွေ့နေရတာ မို့ အသုံးဝင်တဲ့ လေ့ကျင့်ခန်း ဖြစ်ပါတယ်။

Workspace hints:
- အမည်ကို `h3` နဲ့ ရေးပါ။
- ပုံကို `img` နဲ့ ထည့်ပြီး `alt` ထည့်ဖို့ မမေ့ပါနဲ့။
- ဖော်ပြချက်ကို `p`၊ ဈေးကို `strong` ဖြင့် အလေးပေးနိုင်ပါတယ်။
- Button အတွက် `button` tag သုံးပြီး အထဲမှာ ဝယ်မည် ဟူသော စာသား ထည့်ပါ။

**စတင်ရန် template -**

```html
<h3>ထောပတ်သီး</h3>
<img src="https://example.com/avocado.png" alt="ထောပတ်သီးတစ်လုံး">
<p>လတ်ဆတ်တဲ့ ထောပတ်သီး၊ နံနက်စာ အတွက် ကောင်းပါတယ်။</p>
<strong>၂၀၀၀ ကျပ်</strong>
<button>ဝယ်မည်</button>
```

မှတ်ချက် — hint တွေကို လိုက်လုပ်ပြီး ကိုယ့်စိတ်ကြိုက် အရောင်အဆင်း၊ ဈေးနှုန်းနဲ့ ပြင်ပြီး ရေးပါ။

### စိန်ခေါ်မှု ၂ — ကိုယ်ရေး Page

ကိုယ့်အကြောင်း Page တစ်ခု ရေးပါ — ခေါင်းစဉ်၊ မိတ်ဆက် စာပိုဒ်၊ အကြိုက်ဆုံးတွေ စာရင်း၊ ဓာတ်ပုံနဲ့ နောက်ကွယ်သို့ ချိတ်တဲ့ link ပါဝင်ရမယ်။ ဒါက ဒီသင်တန်းရဲ့ အခြေခံအားလုံးကို ပေါင်းစပ်ပြီး လေ့ကျင့်ရတဲ့ အကောင်းဆုံး နည်းလမ်း ဖြစ်ပါတယ်။

Workspace hints:
- `h1` နဲ့ နာမည်ကို ဖော်ပြပါ။
- `p` ၂ ပိုဒ် ရေးပြီး ကိုယ့်အကြောင်း ပြောပြပါ။
- `ul` စာရင်းနဲ့ အကြိုက်ဆုံးတွေကို ဖော်ပြပါ။
- Footer မှာ email link `a` တစ်ခု ထည့်ပါ။

**စတင်ရန် template -**

```html
<h1>မင်းခန့်</h1>
<p>ကျွန်မက web design လေ့လာနေတဲ့ ကျောင်းသားတစ်ဦးပါ။</p>
<ul>
  <li>ဓာတ်ပုံရိုက်ခြင်း</li>
  <li>ခရီးသွားခြင်း</li>
</ul>
<a href="mailto:minkhan@example.com">အီးမေးလ် ပို့ရန်</a>
```

မှတ်ချက် — `mailto:` က အီးမေးလ်အပလီကေးရှင်းကို new message နဲ့ ဖွင့်ပေးတဲ့ link အမျိုးအစား ဖြစ်ပါတယ်။

### စိန်ခေါ်မှု ၃ — Mini စားသောက်ဆိုင် Menu

မြန်မာ စားသောက်ဆိုင် လေးတစ်ဆိုင်ရဲ့ Menu ကို ရေးပါ။ Menu ထဲမှာ အစားအစာ အမည်နဲ့ ဈေးနှုန်း ပါရမယ်။ Group ခွဲဖို့ `h2` နဲ့ ခေါင်းစဉ်တွေထည့်ပြီး `ul` ဒါမှမဟုတ် `table` နဲ့ ဖော်ပြနိုင်ပါတယ်။

Workspace hints:
- မုန့်၊ အသုပ်၊ ဟင်းချို စသည်ဖြင့် group နှစ်ခုလောက် ခွဲပါ။
- တစ်ခုချင်းစီကို `li` ထဲမှာ အမည်နဲ့ ဈေးနဲ့တကွ ရေးပါ။
- `table` သုံးရင် `th` မှာ အမည်နဲ့ ဈေး column နှစ်ခု ထားပါ။
- Menu ပြီးရင် ဝယ်ယူလိုသူတွေ ဆက်သွယ်ဖို့ link တစ်ခု ထည့်ပါ။

**စတင်ရန် template -**

```html
<h2>မုန့်များ</h2>
<ul>
  <li>မုန့်ဟင်းခါး — ၁၀၀၀ ကျပ်</li>
  <li>မုန့်အေး — ၅၀၀ ကျပ်</li>
</ul>
<h2>အသုပ်များ</h2>
<ul>
  <li>လက်ဖက်သုပ် — ၁၅၀၀ ကျပ်</li>
</ul>
```

မှတ်ချက် — ပိုကျွမ်းကျင်ချင်ရင် အစားအစာတစ်ခုချင်းစီကို `table` နဲ့ ဖော်ပြပြီး column သုံးခု အထိ စမ်းကြည့်ပါ။

### စိန်ခေါ်မှု အဆင့်မြင့် — စိတ်ကြိုက် Project

အထက်က စိန်ခေါ်မှု ၃ ခုထဲက တစ်ခုကို ကိုယ့်စိတ်ကြိုက် ပြင်ဆင်ပြီး ပိုကောင်းအောင် တိုးချဲ့ပါ။ ဥပမာ — Product card ကို image ၂ လုံး၊ link ၂ ခုပါအောင် ပြောင်းတာ၊ ဒါမှမဟုတ် menu ကို form တစ်ခုနဲ့တွဲပြီး order မှာလို့ရအောင် လုပ်တာမျိုး ဖြစ်ပါတယ်။

Workspace hints:
- ရည်မှန်းချက်ကို စာရွက်ပေါ်မှာ အရင်ရေးပါ။
- နောက်မှ browser မှာ အဆင့်ဆင့် စမ်းသပ်ပါ။
- Semantic tag (`header`, `footer`) အသစ်တွေ ထည့်ဖို့ စမ်းကြည့်ပါ။

မှတ်ချက် — coding မှာ အကောင်းဆုံး သင်ယူနည်းက ကိုယ်တိုင် စမ်းရေးတာ ဖြစ်တာကြောင့် ဒီစိန်ခေါ်မှုကို လွတ်လပ်စွာ ဖန်တီးကြည့်ပါ။
