ဒီလေ့ကျင့်ခန်းတွေက HTML ရဲ့ အခြေခံကို လက်တွေ့ကျင့်ဖို့ ဖြစ်ပါတယ်။ တစ်ခုချင်းစီမှာ လုပ်စရာ ရည်မှန်းချက်နဲ့ မျှော်လင့်ထားတဲ့ ရလဒ်ကို အရင်ဖတ်ပြီး ကိုယ်တိုင် စမ်းရေးကြည့်ပါ။ နောက်ဆုံးမှာ အဖြေကုဒ်နဲ့ ယှဉ်ကြည့်ပြီး ဘာတွေ ကွာခြားလဲ ဆိုတာ သုံးသပ်ပါ။ ကွာတယ်ဆိုလည်း မစိုးရိမ်ပါနဲ့ — ကိုယ်ရေးတဲ့နည်း မှန်နေသမျှ ရလဒ် တူရင် အောင်မြင်ပါတယ်။

### လေ့ကျင့်ခန်း ၁ — ပထမဆုံး ခေါင်းစဉ်

`<h1>` နဲ့ ကိုယ့်နာမည်ကို ဖော်ပြတဲ့ ခေါင်းစဉ်တစ်ခု ဖန်တီးပါ။ အဲ့ဒီအောက်မှာ ကိုယ်ရဲ့ အကြိုက်ဆုံး တစ်ခုခုအကြောင်း `<p>` နဲ့ စာပိုဒ်တစ်ခု ရေးပါ။

မျှော်လင့်ထားသော ရလဒ် — စာမျက်နှာထိပ်မှာ နာမည် ကြီးကြီး ပေါ်ပြီး အောက်မှာ စာပိုဒ်တစ်ပိုဒ် ပါနေမှာ ဖြစ်သည်။

**အဖြေ -**

```html
<h1>ကျွန်တော်နာမည် အောင်မိုး</h1>
<p>ကျွန်တော် ကုဒ်ရေးရတာကို ကြိုက်ပြီး website တွေ ဆောက်ဖို့ လေ့လာနေပါတယ်။</p>
```

မှတ်ချက် — browser မှာ ဖွင့်ကြည့်ရင် `h1` က စာလုံးကြီးနဲ့ ထင်ရှားပြီး `p` က သာမာန် စာပိုဒ်အဖြစ် မြင်ရမှာ ဖြစ်ပါတယ်။

### လေ့ကျင့်ခန်း ၂ — Link နှင့် ပုံ

မျက်နှာပေါ်မှာ link တစ်ခုနဲ့ ပုံတစ်ပုံ ရှိရမယ်။ Link က `https://example.com` ဆီ သွားရပြီး ပုံမှာ `alt` text ပါ ထည့်ရပါတယ်။

မျှော်လင့်ထားသော ရလဒ် — link ကို နှိပ်ရင် site ပြောင်းသွားပြီး ပုံပေါ်မှာ mouse ရွှေ့ရင် alt text ကို tooltip အနေနဲ့ မြင်ရနိုင်သည်။

**အဖြေ -**

```html
<a href="https://example.com">ဥပမာဆိုက်သို့ သွားမည်</a><br>
<img src="https://example.com/cat.png" alt="ကြောင်လေး တစ်ကောင်">
```

မှတ်ချက် — `src` ထဲက လိပ်စာကို တကယ့်ပုံတစ်ပုံနဲ့ အစားထိုးရင် ပုံကို မြင်ရမှာ ဖြစ်ပြီး `alt` က screen reader နဲ့ မသန်စွမ်းသူတွေအတွက် အရေးကြီးပါတယ်။

### လေ့ကျင့်ခန်း ၃ — စာရင်းတစ်ခု

ကိုယ့် နေ့စဉ်အလုပ်တွေကို နံပါတ်စဉ်တပ်ပြီး စာရင်း ရေးပါ။ ပြီးတော့ အကြိုက်ဆုံး သရေစာ ၃ မျိုးကို နံပါတ်မပါတဲ့ စာရင်းနဲ့ ရေးပါ။

မျှော်လင့်ထားသော ရလဒ် — ဂဏန်းတွဲ စာရင်းတစ်ခုနဲ့ တစ်ချက်မှတ်တွေ ပါတဲ့ စာရင်း တစ်ခု မြင်ရမည်ဖြစ်သည်။

**အဖြေ -**

```html
<h3>နေ့စဉ် အလုပ်များ</h3>
<ol>
  <li>ဆန်းကြယ်ထခြင်း</li>
  <li>လေ့ကျင့်ခန်း လုပ်ခြင်း</li>
  <li>HTML လေ့လာခြင်း</li>
</ol>

<h3>အကြိုက်ဆုံး သရေစာ</h3>
<ul>
  <li>ဆီကြော်</li>
  <li>ငှက်ပျောသီးခြောက်</li>
  <li>ပူတင်း</li>
</ul>
```

မှတ်ချက် — `ol` က နံပါတ် အလိုအလျောက် တပ်ပေးပြီး `ul` က တစ်ချက်မှတ်သာ ပြပေးခြင်း ဖြစ်ပါတယ်။

### လေ့ကျင့်ခန်း ၄ — Column ၃ ခု ဇယား

ကိုယ့်မြို့ရဲ့ နေ့စဉ် ရာသီဥတု (အပူချိန်၊ မိုးရေချိန်) ကို column ၃ ခု ပါတဲ့ ဇယားနဲ့ ဖော်ပြပါ။ ထိပ်ဆုံးမှာ ဇယားခေါင်းစဉ် တန်းတစ်ခု ထည့်ပါ။

မျှော်လင့်ထားသော ရလဒ် — အတန်း ၃ တန်း ပါသော ဇယားတစ်ခုကို မြင်ရမည်ဖြစ်ပြီး ပထမဆုံးတန်းက အမည်ခေါင်းစဉ်များ ဖြစ်သည်။

**အဖြေ -**

```html
<table border="1">
  <tr>
    <th>နေ့</th>
    <th>အပူချိန်</th>
    <th>အခြေအနေ</th>
  </tr>
  <tr>
    <td>တနင်္လာ</td>
    <td>၃၀ ဒီဂရီ</td>
    <td>နေသာ</td>
  </tr>
  <tr>
    <td>အင်္ဂါ</td>
    <td>၂၇ ဒီဂရီ</td>
    <td>မိုးတိမ်ကျ</td>
  </tr>
  <tr>
    <td>ဗုဒ္ဓဟူး</td>
    <td>၂၅ ဒီဂရီ</td>
    <td>မိုးရွာ</td>
  </tr>
</table>
```

မှတ်ချက် — `border="1"` က ဇယားဝန်းရံမျဉ်းတွေကို ပြပေးပြီး `th` က bold နဲ့ ခေါင်းစဉ် ဖြစ်အောင် လုပ်ပေးပါတယ်။

### လေ့ကျင့်ခန်း ၅ — အလိုအလျောက် လုပ်ဆောင်မှု

Form တစ်ခု ဖန်တီးပြီး နာမည်အတွက် text input၊ အီးမေးလ်အတွက် email input တစ်ခုစီ ထည့်ပါ။ Input တစ်ခုချင်းစီမှာ `<label>` နဲ့ `<br>` ကို သုံးပါ။

မျှော်လင့်ထားသော ရလဒ် — နာမည်နဲ့ အီးမေးလ် စာရိုက်စရာ နေရာနှစ်ခုနဲ့ ပေးပို့မည် button တစ်ခု မြင်ရမည်ဖြစ်သည်။

**အဖြေ -**

```html
<form>
  <label for="username">နာမည်</label><br>
  <input type="text" id="username" name="username"><br>
  <label for="useremail">အီးမေးလ်</label><br>
  <input type="email" id="useremail" name="useremail"><br><br>
  <button type="submit">ပေးပို့မည်</button>
</form>
```

မှတ်ချက် — `type="email"` က browser ကို အီးမေးလ်ပုံစံ မှန်မမှန် စစ်ပေးစေပြီး `label` ရဲ့ `for` နဲ့ `input` ရဲ့ `id` က တွဲထားပါတယ်။

### လေ့ကျင့်ခန်း ၆ — တစ်မျက်နှာအပြည့်

အထက်မှာရေးခဲ့တဲ့ ခေါင်းစဉ်၊ စာပိုဒ်၊ link၊ ပုံ၊ စာရင်း၊ ဇယားနဲ့ form အားလုံးကို တစ်စာမျက်နှာတည်းမှာ စုစည်းပြီး ရေးပါ။ Title ကို `h1` နဲ့ စပြီး section တစ်ခုစီကို `h2` နဲ့ ခွဲပါ။

မျှော်လင့်ထားသော ရလဒ် — ကိုယ်ရေးကိုယ်တာ မိတ်ဆက် စာမျက်နှာတစ်မျက်နှာ အပြည့်အစုံ ရရှိမည်ဖြစ်သည်။

**အဖြေ -**

```html
<h1>ကိုယ်တိုင် မိတ်ဆက်</h1>
<p>ဟယ်လို! ဒါက ကျွန်တော့် စာမျက်နှာပါ။</p>
<a href="https://example.com">ကျွန်တော့် blog</a><br>
<img src="https://example.com/me.jpg" alt="ကိုယ်တိုင်ပုံ">
<h2>အကြိုက်ဆုံးအရာများ</h2>
<ul>
  <li>စာအုပ်ဖတ်ခြင်း</li>
  <li>ဘာသာစကားသင်ယူခြင်း</li>
</ul>
<h2>အဆက်အသွယ်</h2>
<form>
  <label for="mail">အီးမေးလ်</label><br>
  <input type="email" id="mail" name="mail"><br><br>
  <button type="submit">ပို့မည်</button>
</form>
```

မှတ်ချက် — section တွေကို `h2` နဲ့ ခွဲထားတာက ဖတ်ရှုသူနဲ့ search engine နှစ်ဖက်လုံးအတွက် ဖွဲ့စည်းပုံ ရှင်းလင်းစေပါတယ်။
