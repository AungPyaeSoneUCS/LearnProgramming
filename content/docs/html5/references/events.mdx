### Event ဆိုတာ ဘာလဲ?

**Event** ဆိုတာ အသုံးပြုသူ ဒါမှမဟုတ် Browser က ပြုလုပ်တဲ့ လုပ်ဆောင်ချက် တစ်ခုခု ဖြစ်ပါတယ်။ ဥပမာ Button ကို နှိပ်တာ ၊ Input ထဲ စာရိုက်တာ ၊ Mouse ကို Element ပေါ် ရွှေ့တာတွေ အားလုံး Event တွေ ဖြစ်ပါတယ်။ HTML မှာ `on` နဲ့ စတင်တဲ့ Event Attribute တွေကို Element ပေါ် တိုက်ရိုက် ရေးနိုင်ပါပြီး JavaScript နဲ့ ချိတ်ဆက်ပြီး တုံ့ပြန်လုပ်ဆောင်ချက် ဖြစ်စေပါတယ်။

Event Attribute ကို `onclick="functionName()"` ပုံစံနဲ့ ရေးပြီး JavaScript Function ကို ခေါ်ယူပါတယ်။ ဒါပေမယ့် ခေတ်ပေါ် နည်းလမ်းကတော့ JavaScript ထဲမှာ `addEventListener` သုံးပြီး Element နဲ့ Event ကို ချိတ်ဆက်တာ ဖြစ်ပါတယ်။

### အသုံးများတဲ့ Event များ

| Event | ဖြစ်တဲ့အခါ |
| ---- | ---- |
| `onclick` | Element ကို Click (နှိပ်) လိုက်တဲ့အခါ |
| `onchange` | Input တစ်ခုရဲ့ တန်ဖိုး ပြောင်းပြီး အာရုံ ပြောင်းသွားတဲ့အခါ |
| `onmouseover` | Mouse Pointer က Element ပေါ် ရောက်လာတဲ့အခါ |
| `onmouseout` | Mouse Pointer က Element ပေါ်ကနေ ထွက်သွားတဲ့အခါ |
| `onkeydown` | Keyboard ရဲ့ Key တစ်ခုကို နှိပ်လိုက်တဲ့အခါ |
| `onload` | Page (သို့) Element အကုန် Load ဖြစ်ပြီးတဲ့အခါ |
| `onfocus` | Input စတဲ့ Element ကို အာရုံပြု (Focus) လိုက်တဲ့အခါ |
| `onblur` | Element ကနေ အာရုံပြောင်း (Blur) သွားတဲ့အခါ |

### Event ကို ချိတ်ဆက်သုံးပုံ

အလွယ်ကူဆုံး နည်းကတော့ HTML Attribute အနေနဲ့ `onclick` ထည့်ပြီး JavaScript Function ကို ခေါ်တာ ဖြစ်ပါတယ်။ နောက်ထပ် နည်းကတော့ JavaScript မှာ `getElementById` နဲ့ Element ကို ရှာပြီး Listener တွဲတာ ဖြစ်ပါတယ်။ Listener နည်းက HTML နဲ့ JavaScript ကို ခွဲထားလို့ ပိုပြီး သပ်ရပ်ပါတယ်။

**ဥပမာ -**
```html
<button onclick="greet()">Click Me</button>
<p>Button ကို နှိပ်လိုက်ရင် Greeting ပေါ်လာပါလိမ့်မယ်။</p>

<script>
  function greet() {
    alert("မင်္ဂလာပါ ၊ Takkatho မှ ကြိုဆိုပါတယ်");
  }
</script>
```

မှတ်ချက် — HTML Attribute နည်းက စတင်လေ့လာသူအတွက် လွယ်ကူပြီး ပရော်ဖက်ရှင်နယ် ပရောဂျက်တွေမှာ Listener နည်းကို ပိုသုံးပါတယ်။

#### JavaScript Listener နည်း

JavaScript ထဲမှာ Listener ချိတ်ဆက်ရတာက HTML ကို သန့်ရှင်းစေပြီး Space ခွာပြီး Element များစွာကိုလည်း ထိန်းချုပ်ရ လွယ်ပါတယ်။ `addEventListener` ရဲ့ ပထမဆုံး Argument က Event နာမည် ၊ ဒုတိယ Argument က Function ပဲ ဖြစ်ပါတယ်။

```javascript
var btn = document.getElementById("myBtn");
btn.addEventListener("click", function () {
  alert("Event Listener ကနေ ခေါ်လိုက်ပါပြီ");
});
```

မှတ်ချက် — `onclick` Attribute ထဲမှာလည်း Listener ထည့်သုံးလို့ ရပြီး HTML ထဲက Value ကို Function နာမည် ထည့်ပြီး ခေါ်ရပါတယ်။

#### မှတ်ထားရမယ့် အချက်များ

- Event တွေက User Action ကို JavaScript နဲ့ ချိတ်ဆက်ပေးပါတယ်။
- Attribute နည်း (`onclick`) နဲ့ Listener နည်း (`addEventListener`) နှစ်မျိုး ရှိပါတယ်။
- `onchange` က Form Input တန်ဖိုး ပြောင်းတာကို ခံနိုင်ဖို့ အသုံးဝင်ပါတယ်။
- `onload` က Page တစ်ခုလုံး Load ပြီးမှ Code လုပ်စေလိုတဲ့အခါ သုံးပါတယ်။
