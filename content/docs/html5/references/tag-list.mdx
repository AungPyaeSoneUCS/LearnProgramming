### HTML Tag ဆိုတာ ဘာလဲ?

HTML Tag ဆိုတာ Element တစ်ခုကို `<tag>` ပုံစံနဲ့ သတ်မှတ်ပေးတဲ့ အမှတ်အသား ဖြစ်ပါတယ်။ Tag တစ်ခုစီမှာ ကိုယ့်အလုပ်နဲ့ ကိုယ့်အဓိပ္ပာယ် ရှိပြီး Browser က အဲဒီ Tag ကို ကြည့်ပြီး Page ကို ဖော်ပြပါတယ်။ အောက်မှာ Website တစ်ခု တည်ဆောက်ရာမှာ မဖြစ်မနေ သုံးရတဲ့ အရေးအကြီးဆုံး Tag တွေကို Category အလိုက် စုစည်းပေးထားပါတယ်။

ဒီစာရင်းကို အလွတ်ကျက်မှတ်စရာ မလိုဘဲ သင်ခန်းစာ တွေ ဖတ်နေစဉ်မှာ ကိုးကားပြီး သုံးလို့ ရအောင် ရည်ရွယ်ထားပါတယ်။ Tag အသစ်ရှေ့မှာ `<` နဲ့ `>` ကျန်ခဲ့ရင် Browser က အဲဒါကို HTML လို့ မမြင်ဘဲ စာသားအတိုင်း ပြသသွားမှာ ဖြစ်လို့ သတိထားပါ။

### Tag များ ပေါင်းစပ်အသုံးပြုပုံ

Tag တွေက တစ်ခုနဲ့ တစ်ခု ပေါင်းစပ် သုံးရတာ များပါတယ်။ `div` ထဲမှာ `p` ထည့်လို့ ရသလို Form ထဲမှာ `input` နဲ့ `button` တွေ တွဲသုံးပါတယ်။ Semantic Tag တွေကိုလည်း Block Level Container တွေနဲ့ အတူ Layout တစ်ခုလုံး ဖွဲ့စည်းရန် သုံးပါတယ်။

**ဥပမာ -**
```html
<!DOCTYPE html>
<html lang="my">
  <head>
    <title>Takkatho</title>
    <meta charset="UTF-8">
  </head>
  <body>
    <header>
      <h1>မင်္ဂလာပါ</h1>
      <nav>
        <a href="lessons.html">သင်ခန်းစာများ</a>
      </nav>
    </header>
    <main>
      <article>
        <p>HTML ကို အတူတူ လေ့လာကြရအောင်။</p>
        <img src="logo.png" alt="Takkatho logo">
      </article>
    </main>
    <footer>
      <small>Copyright 2026 Takkatho</small>
    </footer>
  </body>
</html>
```

မှတ်ချက် — Opening Tag နဲ့ Closing Tag ကို အမြဲ တွဲဖို့ ၊ Content တွေကို အတွင်းထဲးမှာ မှန်ကန်စွာ ထည့်သွင်းဖို့ ဂရုပြုပါ။

#### မှတ်ထားရမယ့် အချက်များ

- Tag တစ်ခုစီမှာ ကိုယ့်အသုံးပြုပုံနဲ့ ကိုယ့်အဓိပ္ပာယ် ရှိပါတယ်။
- Block Level (`div` ၊ `p`) နဲ့ Inline (`span` ၊ `a`) ကို ခွဲခြား နားလည်ထားပါ။
- Semantic Tag တွေက Page ဖတ်သူရော Search Engine ရော နားလည်လွယ်စေပါတယ်။
- Table နဲ့ Form တွေမှာ Header ၊ Body ၊ Row ဆိုတဲ့ အဖွဲ့အစည်း ရှိပါတယ်။

ဒီစာရင်းကို အလွတ်ကျက်ဖို့ တွန်းအားမထုတ်ပါနဲ့ — Tag တွေကို သုံးလေ ရင်းနှီးလေ ဖြစ်လာမှာပါ။ ဒီ Page ကို Bookmark လုပ်ထားပြီး သင်ခန်းစာ တစ်ခုစီမှာ ပြန်ကြည့်ရင်း လေ့ကျင့်သွားပါ။ နောက်တစ်ဆင့်မှာ Attribute တွေ ၊ Event တွေနဲ့ HTTP အကြောင်း Reference များကို ဆက်လေ့လာနိုင်ပါတယ်။
