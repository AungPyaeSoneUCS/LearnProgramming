## JavaScript ဆိုတာ ဘာလဲ

JavaScript ဆိုတာ **Webpage တွေကို အသက်ဝင်လှုပ်ရှားစေတဲ့ Programming Language** ဖြစ်ပါတယ်။

- **HTML** → စာသား၊ ခလုတ်၊ ပုံ စတဲ့ Structure
- **CSS** → အရောင်၊ ဒီဇိုင်း စတဲ့ Styling
- **JavaScript** → Button နှိပ်လို့ ပုံပြောင်းတာ၊ Form စစ်ဆေးတာ စတဲ့ Functionality

JavaScript ကို Browser တွေမှာသာမက **Node.js** နဲ့ Server/Desktop/Mobile App အနေနဲ့ပါ အသုံးပြုနိုင်ပါတယ်။

## ES6 ဆိုတာ ဘာလဲ

**ES6 (ECMAScript 2015)** ဆိုတာ JavaScript ရဲ့ ကြီးမားတဲ့ အဆင့်မြှင့်တင်မှု တစ်ခုပါ။ အဲ့ဒီနောက်ပိုင်းမှာ JavaScript မှာ ခေတ်မီနည်းစနစ်တွေ ဖြည့်စွက်လာခဲ့ပါတယ်။

ES6+ မှာ ပါလာတဲ့ အဓိက အင်္ဂါရပ်အချို့:

```javascript
// let / const — ခေတ်မီ variable ကြေညာနည်း
let count = 0;
const name = "Mg Mg";

// Arrow function
const add = (a, b) => a + b;

// Template literal
console.log(`Hello, ${name}!`);
```

<Aside type="note" title="မှတ်ချက်">
ဒီသင်တန်းတစ်လျှောက်လုံး **`var` အစား `let`/`const`** ကို သုံးပါမယ်။ ဒါက ခေတ်မီ JavaScript ရေးနည်း ဖြစ်ပါတယ်။
</Aside>

## ဘာကြောင့် JavaScript ကို သင်သင့်လဲ

- Web Development ရဲ့ မရှိမဖြစ် အစိတ်အပိုင်း
- Frontend လည်း ရ၊ Backend (Node.js) လည်း ရ
- အလုပ်အကိုင် အခွင့်အလမ်း အမြောက်အမြားရှိတဲ့ ဘာသာစကား
