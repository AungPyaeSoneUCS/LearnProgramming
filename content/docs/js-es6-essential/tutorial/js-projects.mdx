## Project လုပ်ခြင်းက ဘာကြောင့် အရေးကြီးလဲ

စာဖတ်ရုံနဲ့ JavaScript တတ်မြောက်မလာပါဘူး။ **Project ကိုယ်တိုင် ဆောက်ကြည့်ခြင်း** ကသာ Code ရေးနည်းကို တကယ် ဖမ်းစားနိုင်ပါတယ်။

## Beginner Project Ideas

```javascript
// 1. Counter App
let count = 0;
const update = () => {
  document.getElementById("count").textContent = count;
};
// button click → count++; update();
```

```javascript
// 2. Random Quote Generator
const quotes = ["မနက်ဖြန် ပိုကောင်းမယ်", "ကြိုးစားသူ နိုင်တယ်"];
const randomIndex = Math.floor(Math.random() * quotes.length);
console.log(quotes[randomIndex]);
```

```javascript
// 3. Todo List (Core Logic)
const todos = [];
const addTodo = (text) => todos.push({ id: Date.now(), text, done: false });
const toggleTodo = (id) => {
  const t = todos.find((t) => t.id === id);
  if (t) t.done = !t.done;
};
```

## Challenge ပြုလုပ်နည်း

2. **နေ့စဉ် တိုးတက်ပါ** — ရက်တိုအတွင်း ပြီးအောင် ကြိုးစားပါ

4. **ပြီးရင် တင်ပြ** — Code ကို GitHub မှာ share ပါ
</Aside>
