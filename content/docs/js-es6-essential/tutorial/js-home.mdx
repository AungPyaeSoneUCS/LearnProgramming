## သင်တန်း အကြောင်း

**JavaScript ES6+ Essential** သင်တန်း မှ ကြိုဆိုပါတယ်။ 🎉
ဒီသင်တန်းမှာ **Modern JavaScript (ES6+)** နည်းစနစ်တွေကို အခြေခံကနေ အဆင့်မြင့်အထိ မြန်မာလို ရှင်းလင်းစွာ သင်ယူသွားမှာ ဖြစ်ပါတယ်။

JavaScript ကို စစချင်း စတင်သူတွေမှစပြီး ES6 ရဲ့ Arrow Functions, Classes, Modules, Async/Await, Fetch API စတာတွေကို ကျွမ်းကျင်ချင်သူတွေအထိ အားလုံးအတွက် အကျိုးရှိမယ့် သင်တန်းပါ။

## သင်တန်းမှာ ပါဝင်မယ့် အကြောင်းအရာများ

- **JS Tutorial** — Basics များ (Syntax, Operators, Functions, Arrays ...)
- **JS HTML DOM** — Webpage တွေကို JavaScript နဲ့ ပြုပြင်ခြင်း
- **JS Web API** — Window, Fetch, JSON စတဲ့ Browser API များ
- **JS Advanced** — Classes, Async, Modules, Typed Arrays ...
- **Old Technologies** — AJAX, jQuery, JSONP များကို သိထားသင့်သလောက်
- **JS Examples** — လက်တွေ့ ဥပမာ များ

<Aside type="tip" title="အကြံပြုချက်">
သင်ခန်းစာတစ်ခုချင်းကို Code နဲ့ အတူ **ကိုယ်တိုင် စမ်းသပ်ကြည့်**ပါ။ ဖတ်ရုံသက်သက်ထက် ရေးကြည့်တာက ပိုမှတ်မိပါတယ်။
</Aside>
