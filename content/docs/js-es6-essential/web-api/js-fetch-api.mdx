## Fetch API ဆိုတာ ဘာလဲ

**Fetch API** ဆိုတာ Server ထံ HTTP Request ပို့ပြီး **Response လက်ခံ** တဲ့ ခေတ်မီနည်းလမ်းပါ (ES6 မှာ မိတ်ဆက်)။ `XMLHttpRequest` ရဲ့ အစားထိုး နည်းလမ်း လည်း ဖြစ်ပါတယ်။

## GET — Data ရယူခြင်း

```javascript
fetch("https://jsonplaceholder.typicode.com/todos/1")
  .then((res) => res.json())
  .then((data) => console.log(data))
  .catch((error) => console.error("Error:", error));
```

## async/await နည်း (ပိုရှင်းလင်း)

```javascript
async function getTodo() {
  try {
    const res = await fetch("https://jsonplaceholder.typicode.com/todos/1");
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const data = await res.json();
    console.log(data);
  } catch (error) {
    console.error("Error:", error.message);
  }
}

getTodo();
```

<Aside type="note" title="res.ok ကို စစ်ပါ">
`fetch` က **HTTP 404 မှာတောင်မှ** reject မလုပ်ပါဘူး။ `res.ok` (200-299) ကို ကိုယ်တိုင် စစ်ရပါတယ်။ Network-level Error မှသာ reject ဖြစ်ပါတယ်။
</Aside>

## POST — Data ပို့ခြင်း

```javascript
const postData = {
  title: "သင်ခန်းစာ",
  body: "ဒါက Fetch POST ပါ",
  userId: 1
};

fetch("https://jsonplaceholder.typicode.com/posts", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(postData)
})
  .then((res) => res.json())
  .then((data) => console.log("Created:", data));
```

## Response Methods

```javascript
const res = await fetch(url);

res.json();       // JSON → Object
res.text();       // စာသား
res.status;       // 200, 404 ...
res.ok;           // boolean
res.headers;      // Headers
```

## Practical — User List ပြ

```javascript
async function loadUsers() {
  const res = await fetch("https://jsonplaceholder.typicode.com/users");
  const users = await res.json();

  users.forEach((user) => {
    console.log(`${user.id}. ${user.name} — ${user.email}`);
  });
}

loadUsers();
```
