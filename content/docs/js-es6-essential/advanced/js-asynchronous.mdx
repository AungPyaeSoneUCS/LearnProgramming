## Synchronous vs Asynchronous

- **Synchronous** — အတန်းလိုက် လုပ်တယ်။ ရှေ့တစ်ခု ပြီးမှ နောက်တစ်ခု
- **Asynchronous** — မစောင့်ရ နောက်တစ်ခု ဆက်လုပ်တယ်။ ပြီးတာနဲ့ ပြန်လှမ်းယူတယ်

```javascript
console.log("One");

setTimeout(() => console.log("Two (Async)"), 0);

console.log("Three");

// Output: One → Three → Two (Async)
```

## Promise — Function ဖြစ်ရင်

```javascript
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

wait(1000).then(() => console.log("၁ စက္ကန့် ကြာပါပြီ"));
```

## Promise States

1. **Pending** — စောင့်ဆိုင်းနေ
2. **Fulfilled** — အောင်မြင်ပြီး (resolve)
3. **Rejected** — မအောင်မြင် (reject)

```javascript
const fetchUser = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve({ id: 1, name: "Aung" });
    // reject(new Error("မရှိဘူး"));
  }, 1000);
});

fetchUser
  .then((user) => console.log("User:", user.name))
  .catch((error) => console.log("Error:", error.message))
  .finally(() => console.log("ပြီးပါပြီ"));
```

## async / await — Promise ဖတ်ရလွယ်အောင် (ES2017)

```javascript
async function loadUser() {
  try {
    const res = await fetch(
      "https://jsonplaceholder.typicode.com/users/1"
    );
    if (!res.ok) throw new Error("Request failed");
    const user = await res.json();
    console.log(user.name);
  } catch (error) {
    console.log("Error:", error.message);
  }
}

loadUser();
```

<Aside type="caution" title="await အသုံးများ">
`await` က **async function ထဲမှာသာ** သုံးလို့ရပါတယ်။ Top-level မှာဆို `await` (ES2022) အတွက် Module ​​အသုံးပြုပါ။
</Aside>

## Promise.all — အားလုံး ပြီးမှထုတ်

```javascript
const p1 = Promise.resolve(1);
const p2 = Promise.resolve(2);
const p3 = new Promise((r) => setTimeout(() => r(3), 1000));

const all = await Promise.all([p1, p2, p3]);
console.log(all); // [1, 2, 3]
```

## Promise.race — ပထမဆုံး ပြီးတာယူ

```javascript
const slow = new Promise((r) => setTimeout(() => r("slow"), 2000));
const fast = Promise.resolve("fast");

const winner = await Promise.race([slow, fast]);
console.log(winner); // "fast"
```

<Aside type="tip" title="Callback Hell ကို ရှောင်ရန်">
Task မှာ Callback တစ်ခုနဲ့ တစ်ခု သိပ်ထားတဲ့ "Callback Hell" ကို ရှောင်ပြီး **async/await** ကို သုံးပါ။
</Aside>
