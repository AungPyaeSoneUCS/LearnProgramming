Declaration merging — ‌တူ ‌သော ‌ကြေညာ — ‌ပေါင်း။

## Interface merge

```ts
interface User {
  name: string;
}

interface User {
  age: number;
}

const u: User = { name: "Aung", age: 22 }; // ✓
```

## ‌သုံးစွဲ — augment

```ts
interface Window {
  appName?: string;
}

window.appName = "takkatho"; // ✓ ‌ထည့်
```

## Namespace + function

```ts
function parse(input: string): number[] {
  return input.split(",").map(Number);
}

namespace parse {
  export const version = "1.0";
}

parse.version; // ✓
```
