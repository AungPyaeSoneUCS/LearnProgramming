**TypeScript (TS)** — JavaScript ‌ပေါ် type system ‌ပေါင်းထည့် — compile ‌ချိန် error ‌ဖမ်း။

## TypeScript ‌ဆိုတာ

```ts
let name: string = "Aung";
name = 42; // ❌ error — string မဟုတ်
```

JavaScript ‌အ‌ပြည့်အ‌ပေါ် ‌အခြေ‌ခံ ‌ထည့် — ‌သူ့ syntax ‌က JS ‌နှင့် ‌တူ — types ‌သာ ‌ပိုများ။

## Why TS
- ‌အ‌မှား ‌ရှာ — compile ‌ချိန်
- IDE ‌အကူအညီ — autocomplete
- ‌ရှင်းလင်း self-documenting code
- Scale ‌ကြီး projects ‌လုံး‌ခြုံ

## Run ‌နည်း

```bash
npm install -g typescript
tsc app.ts
node app.js
```

TypeScript compiler (tsc) → JS → run။

## ‌အဓိက အချက်များ
- JS + types
- tsc ‌ဖြင့် compile
- ‌အ‌မှား ‌စောစော ‌ဖမ်း
