Simple types — JavaScript data types ကို ‌သုံး။

## string

```ts
let name: string = "Aung";
let msg: string = "Hello";
```

## number

```ts
let age: number = 22;
let price: number = 99.5;
let neg: number = -10;
```

## boolean

```ts
let done: boolean = true;
let active: boolean = false;
```

## bigint & symbol

```ts
let big: bigint = 10n;          // ‌ကြီးမား ‌သော number
let sym: symbol = Symbol("id"); // ‌တစ်မူထူး unique
```

## ‌အဓိက အချက်များ
- string, number, boolean
- bigint — ‌ကြီးမား
- symbol — unique
