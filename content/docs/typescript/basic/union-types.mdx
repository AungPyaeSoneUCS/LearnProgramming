Union — ‌တစ်မျိုး‌ထက် type ‌ခံ — `|`။

```ts
let value: string | number = 10;
value = "hello"; // ‌ရ
```

## ‌အခြေ‌ခံ

```ts
function printId(id: number | string): void {
  console.log(id);
}

printId(101);
printId("A101");
```

## Narrowing (type guard)

```ts
function size(input: string | string[]): number {
  if (typeof input === "string") {
    return input.length;    // string
  }
  return input.length;      // array
}
```

## Union with objects

```ts
type Success = { ok: true; data: string };
type Fail = { ok: false; error: string };

function run(): Success | Fail {
  return { ok: true, data: "OK" };
}
```
