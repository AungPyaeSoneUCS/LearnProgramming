Java Enterprise Edition (Java EE) သည် standalone program များရေးသားခြင်း (Java SE) မှ ထောင်ပေါင်းများစွာသော request များကို ကိုင်တွယ်နိုင်သည့် robust, multi-tier web application များ တည်ဆောက်ခြင်းသို့ ကူးပြောင်းရာတွင် အသုံးပြုသည့် enterprise platform တစ်ခု ဖြစ်ပါသည်။ Java EE application များသည် application server (သို့) web container အတွင်းတွင် အလုပ်လုပ်ပြီး web tier, business tier ၊ database tier များကို သီးခြားစီ ခွဲထားခြင်းဖြင့် maintainability ကို မြှင့်တင်ပါသည်။

ဤသင်တန်းတွင် server setup မှအစပြု၍ Servlet, JSP, EJB, JPA, REST API များအထိ စနစ်တကျ သင်ယူရပါမည်။ အဆုံးတွင် MVC pattern ကို အသုံးပြုထားသော e-commerce web application တစ်ခုကို လက်တွေ့ တည်ဆောက်ရပါမည်။
