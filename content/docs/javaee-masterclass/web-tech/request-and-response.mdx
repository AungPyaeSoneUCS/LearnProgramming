HttpServletRequest object သည် client ၏ request အကြောင်း အချက်အလက်အားလုံး (parameters, headers, cookies) ကို ချုပ်ကိုင်ထားပြီး HttpServletResponse က server မှ ပြန်ပို့မည့် data ကို ချုပ်ကိုင်ထားပါသည်။

## Form Parameters ဖတ်ခြင်း

HTML form မှ submit လုပ်လိုက်သော field များကို getParameter() ဖြင့် ရယူပါသည်။ Multiple values (checkbox) များအတွက် getParameterValues() ကို သုံးပါသည်။

```
@WebServlet("/register")
public class RegisterServlet extends HttpServlet {

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        String name = req.getParameter("name");
        String email = req.getParameter("email");
        String[] hobbies = req.getParameterValues("hobby");

        resp.setContentType("text/html");
        resp.getWriter().println("<h2>Registered: " + name + "</h2>");
        resp.getWriter().println("<p>Email: " + email + "</p>");
        resp.getWriter().println("<p>Hobbies: " +
            (hobbies == null ? "none" : String.join(", ", hobbies)) + "</p>");
    }
}
```

► Name ၊ email နှင့် hobbies ကို form မှ fill လုပ်ပြီး submit လုပ်ပါက server သည် အချက်အလက်များကို ပြန်လည် display ပြုလုပ်ပေးပါသည်။

## Response Headers ပို့ခြင်း

setHeader() ၊ setContentType() များကို သုံး၍ browser နားလည်နိုင်သည့် header များ ပို့နိုင်ပါသည်။ Redirect သို့မဟုတ် caching ထိန်းချုပ်ရန် header များကို သတ်မှတ်ပါသည်။

```
@WebServlet("/download")
public class DownloadServlet extends HttpServlet {

    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        resp.setContentType("application/pdf");
        resp.setHeader("Content-Disposition", "attachment; filename=report.pdf");
        resp.getWriter().println("PDF content goes here");
    }
}
```

► Browser သည် response ကို file download အဖြစ် လက်ခံမည် ဖြစ်ပြီး အမည်မှာ report.pdf ဖြစ်ပါသည်။

## JSON Response ထုတ်ခြင်း

JSON ကို ပြန်ပို့ရန် content type ကို application/json ဟု သတ်မှတ်၍ response writer ဖြင့် JSON string ရေးပါသည်။ ရိုးရှင်းစွာ ပြသရန်အတွက် JSON ကို လက်ဖြင့် ရေးပြပြီး အသေးစိတ်ကို Module 30 တွင် လေ့လာပါမည်။

```
@WebServlet("/api/time")
public class TimeServlet extends HttpServlet {

    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        resp.setContentType("application/json");
        resp.setCharacterEncoding("UTF-8");
        resp.getWriter().println("{"time": "2026-01-01T10:30:00Z", "app": "TimeService"}");
    }
}
```

► Output (JSON):
```
{"time": "2026-01-01T10:30:00Z", "app": "TimeService"}
```

Request နှင့် Response ကို ကိုင်တွယ်နည်း သိပြီးပါက နောက် module တွင် Servlet များကို URL နှင့် ချိတ်ဆက်နည်းကို လေ့လာပါမည်။
