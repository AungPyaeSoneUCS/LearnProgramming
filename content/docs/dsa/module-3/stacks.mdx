## Stacks (LIFO)

Stack ဆိုတာ ပန်းကန်ပြား ဆေးဖို့ ပုံထားတာကို မြင်ယောင်ကြည့်ပါ -
- ဆေးမယ့် ပန်းကန်ကို အပေါ်ဆုံးမှာ တင်မယ် (**Push**).
- ဆေးဖို့အတွက် အပေါ်ဆုံးက ဟာကိုပဲ အရင်ယူမယ် (**Pop**).
- အောက်ဆုံးက ပန်းကန်ကို ယူချင်ရင် အပေါ်က ပန်းကန်တွေ အကုန်ဖယ်မှ ရမယ်။

ဒါကို **Last-In, First-Out (LIFO)** ၊ "နောက်ဆုံးဝင်၊ အရင်ထွက်" လို့ ခေါ်ပါတယ်။

### Real World Use: The "Undo" Button

Microsoft Word သို့မဟုတ် Code Editor တွေမှာ စာရိုက်နေရင်း `Ctrl + Z` (Undo) နှိပ်လိုက်ရင် ဘာဖြစ်သွားသလဲ?
1. လုပ်လိုက်တဲ့ Action တိုင်းကို Stack ထဲ ထည့်ထားတယ်။ (Push)
2. Undo နှိပ်လိုက်တဲ့အခါ နောက်ဆုံးလုပ်ခဲ့တဲ့ Action ကို Stack ပေါ်ကနေ ယူထုတ်ပြီး ပြန်ဖျက်လိုက်တယ်။ (Pop)

![Undo Timeline Diagram](../../..//media/dsa/undo-timeline-diagram.svg)

### Browser History

Browser မှာ Back Button နှိပ်တာဟာလည်း Stack သဘောတရားပါပဲ။ လက်ရှိ Page ကနေ နောက်တစ်မျက်နှာ နှိပ်လိုက်ရင်၊ လက်ရှိ Page ကို Stack ထဲ ထည့်ခဲ့ပြီး ရှေ့ဆက်သွားတာပါ။

### လက်တွေ့ Code: Valid Parentheses

Bracket တွေ မှန်မမှန် စစ်တဲ့ နည်းလမ်း —

```javascript
function isValid(s) {
  const stack = [];
  const map = { ")": "(", "]": "[", "}": "{" };

  for (const char of s) {
    if (char === "(" || char === "[" || char === "{") {
      stack.push(char);  // ဖွင့်လိုက်ရင် ထည့်
    } else {
      if (stack.pop() !== map[char]) return false; // မတူရင် မှား
    }
  }
  return stack.length === 0; // Stack ဗလာမဖြစ်ရင် မှား
}

console.log(isValid("{[()]}")); // true
console.log(isValid("{[(])}")); // false — ရောနှောနေ
```
