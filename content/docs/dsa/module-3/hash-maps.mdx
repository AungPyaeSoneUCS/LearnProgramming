## Hash Maps (Objects / Dictionaries)

Data Structure လောကမှာ "အမြန်ဆုံး" ဆုကို ပေးရမယ်ဆိုရင် **Hash Map** က ဗိုလ်စွဲမှာ သေချာပါတယ်။
Array တွေလို Index `0`, `1`, `2` နဲ့ မဟုတ်ဘဲ၊ ကိုယ်ပိုင်နာမည် (Key) နဲ့ သိမ်းလို့ ရပါတယ် -

- `phone_book["Mg Mg"]` = "0912345678"
- `menu["Burger"]` = "$5"

### Constant Time $O(1)$ Lookup

Array တွေမှာ "Mg Mg" ကို ရှာချင်ရင် ခေါင်းကနေ အဆုံးထိ လိုက်မွှေရနိုင်တယ်။ ($O(n)$)
Hash Map မှာတော့ "Mg Mg" ဆိုတာ ဘယ်နေရာမှာ ရှိလဲဆိုတာကို **Hash Function** က တန်းတွက်ပေးလိုက်တဲ့အတွက် ချက်ချင်း ရှာတွေ့ပါတယ်။ ($O(1)$)

### Handling Collisions

မတူညီတဲ့ Keys နှစ်ခု (ဥပမာ "Apple" နဲ့ "Ava") ကို Hash လုပ်လိုက်တဲ့အခါ တိုက်ဆိုင်စွာနဲ့ နေရာတစ်ခုတည်း (Index တူတူ) သွားကျနေတာမျိုး ဖြစ်တတ်ပါတယ်။ ဒါကို **Collision** လို့ ခေါ်တယ်။
ဒါကို ဖြေရှင်းဖို့ နည်းလမ်းတွေ (ဥပမာ - ကြပ်နေတဲ့ အခန်းမှာ Linked List လေး ထပ်ချိတ်လိုက်တာမျိုး) ရှိပါတယ်။ ဒါပေမဲ့ Programming Languages တော်တော်များများက နောက်ကွယ်မှာ အလိုအလျောက် ဖြေရှင်းပေးထားပြီးသားပါ။

### Project: Spell Checker

Dictionary တစ်ခု တည်ဆောက်မယ်။ စာလုံးပေါင်း မှန်/မမှန် စစ်ချင်တယ်။
English Dictionary ထဲမှာ စာလုံးပေါင်း သိန်းချီ ရှိနိုင်တယ်။ Array နဲ့ ရှာရင် အရမ်းကြာမယ်။ Hash Map (Set) ထဲမှာ ထည့်ထားရင် `if word in dictionary:` ဆိုပြီး စစ်လိုက်တာနဲ့ ချက်ချင်း အဖြေထွက်ပါတယ်။

### Classic Problem: Two Sum

Array ထဲက နံပါတ် နှစ်ခု ပေါင်းရင် `target` ရတဲ့ Index တွေကို ရှာပါ။

```javascript
function twoSum(nums, target) {
  const seen = {}; // value → index

  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i]; // ပြည့်ဖို့ လိုတဲ့ လက်တွဲဖော်
    if (need in seen) return [seen[need], i]; // ရှာတွေ့ပြီ!
    seen[nums[i]] = i; // ဒီ value ကို မှတ်ထား
  }
  return [];
}

console.log(twoSum([2, 7, 11, 15], 9)); // [0, 1] — 2 + 7 = 9
console.log(twoSum([3, 2, 4], 6));      // [1, 2] — 2 + 4 = 6
```

Nested Loop သုံးရင် $O(n^2)$ ဖြစ်ပြီး၊ Hash Map သုံးလိုက်တဲ့အတွက် $O(n)$ နဲ့ ပြီးသွားပါတယ်။ "ရှာဖို့" ဆို Hash Map က အပေါင်းအဖော် အကောင်းဆုံးပါပဲ။
