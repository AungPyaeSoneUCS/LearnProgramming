Course ပြီးရင် certification စာမေးပွဲ ဖြေဖို့ အဆင်သင့် ဖြစ်ပါပြီ။

## စာမေးပွဲ အကြောင်း
- Topic: SELECT / JOIN / GROUP BY / DDL / Security
- Format: Multiple choice
- Passing score: 70% (ဥပမာ)
- Time: 60 minutes (ဥပမာ)

## နမူနာ မေးခွန်းများ
```text
1) Result မှာ duplicate rows ဖယ်ဖို့:
   a. SELECT DISTINCT   b. SELECT UNIQUE
   c. SELECT REMOVE     d. SELECT DUPLICATE
 
2) Orders ရဲ့ total ကို ပေါင်းဖို့:
   a. COUNT(Total)   b. SUM(Total)
   c. ADD(Total)     d. TOTAL(Total)
 
3) ဒီဟာ ဘယ်အခါ true:
   WHERE Price > ALL (SELECT ...)
   a. subquery ရဲ့ တစ်ခုခုထက်  b. subquery ရဲ့အားလုံးထက်
   c. subquery ရဲ့ ဘယ်တစ်ခုထက်မှ  d. subquery  အတိုင်း
```
