Instructor-led training session တွေမှာဖြစ်ဖြစ် self-study မှာပဲဖြစ်ဖြစ် ဒီ guide ကို အသုံးပြုလို့ရပါတယ်။

## Course Structure
| Duration | Topic |
| --- | --- |
| 1 hour | SELECT / WHERE / ORDER BY |
| 1 hour | Joins (INNER/LEFT/RIGHT) |
| 1 hour | Aggregate + GROUP BY + HAVING |
| 1 hour | Database Management (DDL) |
| 30 min | Security (injection / parameters) |
| 30 min | Practice + Q&A |

## Materials
- ဒီ SQL Tutorial ရဲ့ lessons
- SQL editor (W3Schools Tryit)
- Local SQLite file (shop.db)
- Terminal access for setup

## Session Example — 2 hours
```
[10 min]  introductions + goals
[30 min]  SELECT / WHERE / ORDER BY demo + practice
[15 min]  JOIN demo (diagram → code)
[30 min]  Aggregate + GROUP BY
[15 min]  Q&A + review
```

## Self-study Guide
1. SQL lesson တစ်ခုဖတ်
2. Example ကို run ပြီး ပြောင်းကြည့်
3. Quiz ဖြေ
4. Exercise ကို editor မှာ ရေး
5. နောက် lesson ရှေ့ဆက်

## Instructor Tips
- Diagram ကို အရင်ပြ — concept visualization
- "တွေးဆစဉ်" ကို အသံထွက်ပြောပြ (think-aloud)
- မေးခွန်းတွေ မေး — "ဒီ code က ဘာလုပ်လဲ?"
- Real-world use case ထည့်ပြ
- Break ပေး

## အဓိက အချက်များ
- 1 hour per topic
- Interactive — run, discuss, practice
- Think-aloud for complex queries
- Diagram + real-world examples
