ဒီ course ကို module ၅ ခုခွဲထားပါတယ် — အခေါင်းအရင်းအမြစ်ကစလို့ နည်းပညာအဆင့်အထိ။

## Module 1 — SQL Basics (Lesson 1-7)
- SELECT, WHERE, ORDER BY, AND/OR/NOT
- INSERT / UPDATE / DELETE
- NULL handling
- Aggregates (COUNT, SUM, AVG, MIN, MAX)

## Module 1+ — Joins & Grouping (Lesson 8-14)
- INNER / LEFT / RIGHT / FULL / SELF joins
- UNION / UNION ALL
- GROUP BY / HAVING
- EXISTS / ANY / ALL subqueries

## Module 2 — Database Management (Lesson 15-21)
- CREATE / DROP / ALTER DATABASE/TABLE
- Constraints — NOT NULL, UNIQUE, PK, FK, CHECK, DEFAULT
- Indexes, Views, Backup
- Security — injection, parameters, prepared statements

## Module 3 — References
- Data types
- Keywords / Operators
- Engine functions (MySQL / SQL Server / Access)

## Module 4 — Practice
- Examples, Editor, Quiz, Exercises
- Setup real DB

## Module 5 — Certification
- Quiz-style review → Certificate

## သင်ယူမှု အကြံပြုချက်
- တစ်ရက် ၁-၂ lessons
- Query တိုင်း run ပြီး ကြည့်ပါ
- Exercise ၄၈ ခု
- တစ်ပတ်လုံး module ၃ ရင် review
