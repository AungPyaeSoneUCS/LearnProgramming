## အကောင်းဆုံးအဖြေတချို့
```sql
-- Exercise 2-3
SELECT c.Name, COUNT(o.OrderID) AS Orders
FROM Customers c
LEFT JOIN Orders o ON c.CustomerID = o.CustomerID
GROUP BY c.Name
HAVING COUNT(o.OrderID) = 0;
```
```sql
-- Exercise 3-4
SELECT Country, COUNT(*) FROM Customers GROUP BY Country;
```
