SQL (Structured Query Language) သည် Database (အချက်အလက် သိုလှောင်ရုံ) နဲ့ စကားပြောဆိုဖို့ သုံးတဲ့ စံသတ်မှတ်ထားတဲ့ ဘာသာစကား တစ်ခုပါ။ MySQL, PostgreSQL, SQL Server, Oracle စတဲ့ နာမည်ကြီး Database တွေအားလုံးနီးပါးက SQL ကို အခြေခံထားလို့ ဒီသင်တန်းကို ပြီးရင် ဘယ် Database နဲ့မဆို အလွယ်တကူ ပြောင်းသုံးနိုင်ပါတယ်။

## ဒီသင်တန်းမှာ ဘာတွေ သင်ရမလဲ?

## သင်တန်းကို ဘယ်လို လိုက်လေ့လာမလဲ?
1. Lesson တစ်ခုချင်းစီကို အစဉ်လိုက် ဖတ်ပါ။ ခေါင်းစဉ် တစ်ခုက နောက်တစ်ခုရဲ့ အခြေခံ ဖြစ်ပါတယ်။
2. Code block တိုင်းမှာ Copy ခလုတ် ပါပါတယ်။ ကူးယူပြီး ကိုယ့် စက်/Editor ပေါ်မှာ လက်တွေ့ Run ကြည့်တာ အကောင်းဆုံးပါ။
3. ဥပမာ ဥပမာတွေကို နားလည်ရုံနဲ့ မရပါဘူး။ ကိုယ်တိုင် ပြန်ရေးပြီး ပြင်ကြည့်ပါ။
4. Module 1 ရဲ့ sql-home မှာ ဥပမာတွေအတွက် အသုံးပြုမယ့် sample table တွေ ထည့်ပေးထားပါတယ်။
5. သင်တန်းဆုံးရင် Module 4 ရဲ့ Quiz နဲ့ Exercises ကို ဖြေပြီး Module 5 ရဲ့ Certificate ကို ရယူပါ။

ဒီနေ့ကစပြီး SQL ကျွမ်းကျင်သူ ဖြစ်ဖို့ ခရီးကို စတင်လိုက်ကြရအောင်။ ပထမဆုံး lesson ကို သွားကြည့်ကြပါ။
