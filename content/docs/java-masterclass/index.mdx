Java Masterclass သင်တန်း တစ်ခုလုံးသို့ ကြိုဆိုပါသည်။ ဤသင်တန်းသည် Java အကြောင်းကို မသိသေးသူများ မှ စတင်ပြီး Java SE ၏ အဆင့်မြင့် features များကို ကျွမ်းကျင်သည်အထိ တစ်ဆင့်ချင်း သင်ယူနိုင်ရန် စီစဉ်ထားသော ပြည့်စုံသည့် သင်ရိုးဖြစ်ပါသည်။ သင်ခန်းစာတိုင်းတွင် full-sentence ဖြင့် ရေးထားသော မြန်မာရှင်းလင်းချက်များနှင့် တွဲဖက်၍ compile လုပ်ပြီး run နိုင်သော complete Java code များကို လေ့လာရမည် ဖြစ်ပါသည်။

## သင်တန်း၏ ရည်ရွယ်ချက်

ဤသင်တန်း၏ အဓိက ရည်ရွယ်ချက်မှာ Java developer တစ်ယောက် ဖြစ်လာရန် လိုအပ်သော အသိပညာနှင့် ကျွမ်းကျင်မှု အားလုံးကို ဖွဲစည်းပေးရန် ဖြစ်ပါသည်။ ပထမဦးစွာ သင့် workstation တွင် JDK ကို တပ်ဆင်ခြင်း၊ environment variables များကို ပြင်ဆင်ခြင်း၊ Hello World program ကို run ခြင်းတို့ဖြင့် စတင်ပါမည်။ ထို့နောက် Object-Oriented Programming ၏ မဏ္ဍိုင်ကြီးလေးခုဖြစ်သော encapsulation, inheritance, polymorphism နှင့် abstraction တို့ကို နက်နက်နဲနဲ သင်ယူပါမည်။ နောက်ဆုံးတွင် Lambda, Stream API, Optional, Records ကဲ့သို့သော Java 8 မှ 21 အထိ modern features များနှင့် ပြီးပြည့်စုံသော module 19 ခုပါသည့် syllabus တစ်ခုလုံးကို ဖြတ်သန်း သွားပါမည်။

## သင်တန်း ဖွဲ့စည်းပုံ

သင်တန်းကို အပိုင်းလေးပိုင်း ခွဲထားပါသည်။ Part 1 တွင် course prerequisites နှင့် environment setup ပါဝင်ပြီး Part 2 တွင် core OOP concepts များ ပါဝင်ပါသည်။ Part 3 တွင် modern Java features များ ပါဝင်ပြီး Part 4 တွင် phase လေးခု ခွဲထားသော complete syllabus နှင့် ဥပမာ လေ့ကျင့်ခန်းများ ပါဝင်ပါသည်။ သင်ခန်းစာများကို ဘယ်ဘက်မီနူးမှ အစဉ်လိုက် သွားနိုင်ပြီး သင်ခန်းစာ တစ်ခုစီ၏ အဆုံးတွင် သင်ခန်းစာ ပြီးမြောက်ကြောင်း အမှတ်အသား ပြုလုပ်ရန် toggle တစ်ခု ပါရှိပါသည်။

## ပထမဦးဆုံး Program

သင်တန်းတွင် ပေးထားသော code များသည် အားလုံး complete runnable ဖြစ်ပြီး အောက်တွင် ပြထားသော အတိုင်း ရိုက်ထည့်ရန် မလိုဘဲ နားလည်စေရန် ဖတ်ရှုလေ့လာရန် ရည်ရွယ်ပါသည်။

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Welcome to the Java Masterclass!");
    }
}
```

အထက်ပါ program ကို `Main.java` ဟု နာမည်ပေး၍ သိမ်းပြီး compile လုပ်ရန် `javac Main.java` ကို သုံးပါသည်။ ထို့နောက် `java Main` ဖြင့် run သောအခါ အောက်ပါ output ကို ရမည် ဖြစ်ပါသည်။

```
Welcome to the Java Masterclass!
```

## သင်တန်းကို မည်သို့ လေ့လာမည်နည်း

သင်ခန်းစာတိုင်းကို အစဉ်လိုက် ဖတ်ရှုရန် အကြံပြုပါသည်။ Code များကို ဖတ်ရုံသာမက သင့် IDE တွင် ပြန်ရိုက်၍ run ကြည့်သင့်ပါသည်။ ပြဿနာ တစ်ခုခု ကြုံသောအခါ output ကို သေချာဖတ်ပြီး စဉ်းစားတတ်ရန် လေ့ကျင့်ပါ။ ဤနည်းဖြင့် လေ့လာပါက Java ကို မြန်မြန် ကျွမ်းကျင်လာမည် ဖြစ်ပါသည်။
