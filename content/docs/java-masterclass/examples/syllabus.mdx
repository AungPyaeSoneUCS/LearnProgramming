ဤစာမျက်နှာတွင် Java Masterclass သင်တန်း၏ syllabus အပြည့်အစုံကို ဖော်ပြပါသည်။ သင်ရိုးကို အပိုင်းလေးပိုင်း ခွဲထားပြီး module ၁၉ ခုဖြင့် ဖွဲ့စည်းထားပါသည်။

## Part 1 — Course Prerequisites & Environment Setup

ပထမအပိုင်းတွင် Java developer များ code မရေးမီ ပြင်ဆင်ရမည့် အချက်များကို သင်ယူရမည် ဖြစ်ပါသည်။ Part 1 တွင် Download and Install the JDK, Set Environment Variables (JAVA_HOME), Install an IDE နှင့် Write and Execute Hello World ဟူ၍ သင်ခန်းစာ ၄ ခု ပါဝင်ပါသည်။

## Part 2 — Core OOP Concepts

ဒုတိယအပိုင်းတွင် Object-Oriented Programming ၏ မဏ္ဍိုင်ကြီး လေးခုကို သင်ယူရမည် ဖြစ်ပါသည်။ Part 2 တွင် Classes & Objects, Encapsulation, Inheritance, Polymorphism, Abstraction နှင့် OOP Summary ဟူ၍ သင်ခန်းစာ ၆ ခု ပါဝင်ပါသည်။

## Part 3 — Modern Java Features (Java 8 to 21)

တတိယအပိုင်းတွင် boilerplate code ကို လျှော့ချပေးသော modern features များကို သင်ယူရမည် ဖြစ်ပါသည်။ Part 3 တွင် Lambda Expressions & Functional Interfaces, The Stream API, The Optional Class နှင့် Records တို့ ပါဝင်ပါသည်။

## Part 4 — The Complete Java SE Masterclass Syllabus

စတုတ္ထအပိုင်းကို phase လေးခု ခွဲထားပြီး module ၁၉ ခု ပါဝင်ပါသည်။ Phase 1 (Java Mechanics & Syntax) တွင် Modules 1-4, Phase 2 (Object-Oriented Mastery) တွင် Modules 5-9, Phase 3 (Core Libraries & Memory) တွင် Modules 10-13, Phase 4 (Advanced Java & Modern Features) တွင် Modules 14-19 ဖြစ်ပါသည်။

## Module အသေးစိတ်

`Module 1: The JVM & Execution Lifecycle` သည် bytecode နှင့် JVM အလုပ်လုပ်ပုံဖြစ်ပြီး Module 2 သည် environment setup ဖြစ်ပါသည်။ Module 3 တွင် primitives, reference types, casting များဖြစ်ပြီး Module 4 တွင် operators နှင့် control flow များ ဖြစ်ပါသည်။ ဤ Module 1-4 များသည် Phase 1 ဖြစ်ပါသည်။

Phase 2 တွင် Modules 5-9 များဖြစ်သည့် Classes & Objects, Encapsulation, Inheritance, Polymorphism နှင့် Abstraction တို့ ပါဝင်ပါသည်။ Phase 3 တွင် Modules 10-13 များဖြစ်သည့် Arrays & Strings, Exception Handling, Generics နှင့် Collections Framework တို့ ဖြစ်ပါသည်။ Phase 4 တွင် Modules 14-19 များဖြစ်သည့် Multithreading, Functional Java, Stream API Deep, File I/O & Networking, Modern Data Structures နှင့် JDBC တို့ ဖြစ်ပါသည်။

## သင်ယူမှု အစီအစဉ်

စာမျက်နှာများကို အစဉ်လိုက် ဖတ်ရန် အကြံပြုပြီး မီနူးရှိ အစဉ်အတိုင်း သွားပါက Phase 1 မှ Phase 4 အထိ ပြည့်စုံစွာ သင်ယူပြီးဖြစ်ပါမည်။ Syllabus ၏ နောက်ဆက်တွဲအဖြစ် examples များဖြစ်သော exercises, quiz နှင့် practice problems တို့ကို လေ့ကျင့်ရပါမည်။
