## Problem 5 — Student Class with OOP

Encapsulation ကို သုံး၍ Student class ရေးပြီး name နှင့် score ကို private fields များဖြင့် သိမ်းပြီး getter/setter ပြုလုပ်ပါ။ အောက်ပါ complete solution ကို ကြည့်ပါ။

```java
public class Main {
    public static void main(String[] args) {
        Student s1 = new Student("Mya", 85);
        Student s2 = new Student("Aung", 45);

        s1.display();
        s2.display();
        System.out.println("Student with higher score: "
                + ((s1.getScore() > s2.getScore()) ? s1.getName() : s2.getName()));
    }
}

class Student {
    private String name;
    private int score;

    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    public String getName() {
        return name;
    }

    public int getScore() {
        return score;
    }

    public void display() {
        System.out.println(name + " scored " + score);
    }
}
```
