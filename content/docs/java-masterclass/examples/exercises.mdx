## Exercise 1 — Even or Odd

User မှ နံပါတ်တစ်ခု ထည့်သွင်းပြီး ၎င်းသည် စုံလား မက်လား ပြပါ။

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Enter a number: ");
        int number = scanner.nextInt();

        if (number % 2 == 0) {
            System.out.println(number + " is even.");
        } else {
            System.out.println(number + " is odd.");
        }
        scanner.close();
    }
}
```

## Exercise 2 — Factorial

နံပါတ်တစ်ခု၏ factorial ကို loop ဖြင့် တွက်ပါ။ ဥပမာ 5! = 120 ဖြစ်ပါသည်။

```java
public class Main {
    public static void main(String[] args) {
        int n = 5;
        long fact = 1;

        for (int i = 1; i <= n; i++) {
            fact *= i;
        }

        System.out.println(n + "! = " + fact);
    }
}
```

Run လုပ်သောအခါ ```5! = 120``` ကို မြင်ရမည် ဖြစ်ပါသည်။

## Exercise 3 — Fibonacci Series

ပထမဆုံး Fib1=0, Fib2=1 ဖြင့်စ၍ စီရင်ချက် ၁၀ ခုကို ထုတ်ပါ။

```java
public class Main {
    public static void main(String[] args) {
        int a = 0;
        int b = 1;

        System.out.print(a + " " + b + " ");

        for (int i = 2; i < 10; i++) {
            int next = a + b;
            System.out.print(next + " ");
            a = b;
            b = next;
        }
        System.out.println();
    }
}
```
