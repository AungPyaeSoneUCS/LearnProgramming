## ရှင်းလင်းချက်

Next.js ကို သင်ယူဖို့မှာ video တွေကလည်း အရေးကြီးတဲ့ ကိရိယာတစ်ခု ဖြစ်ပါတယ် — official docs က fundamentals နဲ့ deep dives တွေအတွက် စိစစ်ရွေးချယ်ထားတဲ့ YouTube video series တွေကို link လုပ်ထားပါတယ် (YouTube မှာ "Next.js Learn" ဒါမှမဟုတ် official channel ကို ရှာပါ)။ စစ်ဆေးပြီးသား official series တွေကတော့ **App Router Explained**, **Data Fetching with RSC**, **Cache Components**, **Security**, **Deployment** တွေ ဖြစ်ပါတယ်။ ကြည့်တဲ့ အဆင့်ပေါ် မူတည်ပြီး ရွေးသင့်ပါတယ် — Foundations အဆင့်မှာ full-stack အကြောင်း၊ App Router basics တွေ၊ Data & caching အဆင့်မှာ Server Components, use cache, ISR တွေ၊ Advanced အဆင့်မှာ streaming, auth, edge, security တွေ ဖြစ်ပါတယ်။ Video ကြည့်နေစဉ်မှာ create-next-app နဲ့အတူ code along လုပ်ပြီး reveal မလုပ်ခင်ကြိုတင်ပြီး build result ကို ခန့်မှန်းကြည့်ဖို့ အကြံပြုပါတယ်။ သင်ယူမှု loop ကတော့ video ကြည့် + demo build → ဒီ course ရဲ့ matching docs တွေ ဖတ် → lesson အဆုံးမှာ Activity လုပ်တာ ဖြစ်ပါတယ်။

## Where to find them

Official Next.js docs က YouTube ပေါ်က fundamentals နဲ့ deep dives တွေ ပါဝင်တဲ့ curated videos တွေကို link လုပ်ထားပါတယ် ("Next.js Learn" / official channel ကို ရှာပါ)။ စစ်ဆေးပြီးသား official series တွေကတော့ **App Router Explained**, **Data Fetching with RSC**, **Cache Components**, **Security**, **Deployment** တွေ ပါဝင်ပါတယ်။

## Suggested watch order

| Stage                          | Topics                                   |
| ------------------------------ | ---------------------------------------- |
| Foundations                    | What is full-stack, App Router basics    |
| Data & caching                 | Server Components, `use cache`, ISR      |
| Advanced                        | Streaming, auth, edge, security         |
| Production / platform          | Deployment, CI caching, analytics       |

## While you watch

- စမ်းသပ်ခုနယ် `create-next-app` တစ်ခုထဲမှာ video နဲ့အတူ code along လုပ်ပါ
- Reveal မလုပ်ခင် pause လုပ်ပြီး "next.ts build" ရဲ့ result ကို ကြို ခန့်မှန်းပါ
- ဒီ course နဲ့ မတူတဲ့ API name တွေ ရှိရင် မှတ်ထားပါ — ဒီနေရာမှာ ပါသမျှ အားလုံး Next 16 နဲ့ ကိုက်ညီတာပဲ

## Keep learning loop

1. Video ကြည့်ပြီး demo ကို build လုပ်ပါ
2. ဒီ course ထဲက ဆက်စပ်တဲ့ docs pages တွေကို ဖတ်ပါ
3. Lesson တစ်ခုစီရဲ့ အဆုံးမှာ Activity လုပ်ပါ

## Activity

Video တစ်ခုကို ရွေးပါ (ဥပမာ "Server Components deep dive"), သူ့ရဲ့ နောက်ဆုံး code ကို submit လုပ်ပြီး ဒီ course ရဲ့ mini project ထဲမှာ `npm run build` ကို run ပါ။ Video ရဲ့ concepts တွေကို သင့် route report နဲ့ ချိတ်ဆက်ကြည့်ပါ။
