Terminology — လို စရာ — model, feature, label — ရှင်း။

## အဓိက terms

| Term | အကြောင်း |
|---|---|
| Dataset | ဒေတာ စု |
| Feature | input အချက် |
| Label | answer |
| Model | လေ့လာ ပြီး |
| Training | လေ့ကျင့် |
| Prediction | ခန့်မှန်း |

## ဥပမာ

```js
const house = {
  features: [50, 3, 1], // area, rooms, garage
  label: 20000, // price
};
```

## အဆင့်

- Fit — အံ ကိုက်
- Loss — လွဲ
- Accuracy — အဆင်

## အဓိက အချက်များ

- Feature — input
- Label — answer
- Model — ရလဒ်
