Deep learning — neural network အလွှာ — data မှ features။

## အလွှာ

- Input — features

```js
const model = tf.sequential();
model.add(tf.layers.dense({ units: 64, activation: "relu", inputShape: [784] }));
model.add(tf.layers.dense({ units: 10, activation: "softmax" }));
```
