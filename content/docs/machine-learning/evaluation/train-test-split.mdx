Train/test split — ဒေတာ ခွဲ — အမှန် စစ်။

## Why

- အတူ တာ — memorize
- သစ် တာ — generalize
- စစ် — ခွဲ

## Split

```js
const split = (data, ratio = 0.8) => {
  const i = Math.floor(data.length * ratio);
  return [data.slice(0, i), data.slice(i)];
};
const [train, test] = split(dataset);
```
