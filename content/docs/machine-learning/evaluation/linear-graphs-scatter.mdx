## Scatter — ပုံ

- x — feature
- y — label
- ပုံစံ — trend

```js
const house = [[30, 12], [50, 20], [70, 28], [40, 16]];
```

## Linear မြင်

- Points — လိုင်း ပေါ်
- စောင်း — relation
- ပြန့် — noise

## Chart.js သုံး

```js
new Chart(ctx, {
  type: "scatter",
  data: { datasets: [{ data: house.map(([x, y]) => ({ x, y })) }] },
});
```
