Linear function — straight line — ML အခြေ ဆုံး။

## Formula

```js
// y = wx + b
// w = weight (slope)
// b = bias (intercept)
const y = (w, x, b) => w * x + b;
```

## ဥပမာ

| x | y = 2x + 1 |
|---|---|
| 0 | 1 |
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |

## Slope & intercept

- Slope w — စောင်း
- Intercept b — စတင်
- Line — အံ ကိုက်

```js
// predict house price
const price = (area) => 200 * area + 10000;
console.log(price(50)); // 20000
```

## အဓိက အချက်များ

- y = wx + b
- Line — prediction
- Error — လျှော့
