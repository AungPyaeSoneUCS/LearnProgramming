## Number systems

| System | ပုံစံ | သုံး |
|---|---|---|
| Decimal | 0-9 | လူ |
| Binary | 0/1 | computer |
| Hex | 0-F | နည်းပညာ |
| Float | 3.14 | data |

## Computer တွက်

```js
// Decimal → Binary
console.log((10).toString(2)); // "1010"
console.log(parseInt("1010", 2)); // 10
```

- Vectors — အခြေ
