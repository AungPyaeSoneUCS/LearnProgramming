Machine intelligence — လူ ဉာဏ် လိုပဲ တွေးဖို့ — ရှေးဦး အကြံ သုံး။

## ဉာဏ်ရည် ဆိုတာ

- Learn — သင်ယူ
- Reason — ဆင်ခြင်
- Adapt — လိုက်လျော
- Solve — ဖြေရှင်း

## သမိုင်း ခြုံ

| Era | အကြောင်း |
|---|---|
| ရှေးခေတ် | Aristotle — logic |
| 1800s | Boolean — algebra |
| 1950s | Turing — တွေးစက် |
| 2000s | Deep learning ထွက် |

## AI နှင့် intelligence

```js
// ဥပမာ — ဉာဏ်ရည် တိုင်း
const intelligence = (learn, solve) => learn + solve;
console.log(intelligence("data", "answer"));
```
