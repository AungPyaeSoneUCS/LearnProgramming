**Machine Learning** — အလိုအလျောက် လေ့လာသော program — data မှ pattern သင်ယူ။

## ML ဆိုတာ

- ပုံမှန် code — rule ပေး
- ML — data + answer ပေး — model က rule ကိုယ်တိုင် ရှာ

```
Traditional:  Rules  ->  Data     -> Answers
ML:           Data   + Answers    -> Rules
```

JavaScript သိသူများ — ဒီ ML သင်တန်း — စတင်နိုင်။
