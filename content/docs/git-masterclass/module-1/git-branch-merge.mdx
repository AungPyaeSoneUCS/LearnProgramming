## Branch ဆိုသည်မှာ အဘယ်နည်း

Branch သည် commit history ၏ သီးခြားပိုင်း (separate line of development) ဖြစ်ပါသည်။ Main branch ကို မထိခိုက်စေဘဲ new feature, bug fix များကို သီးခြား branch တွင် တီထွင်နိုင်ပါသည်။

Branch စာရင်း ကြည့်ရှုခြင်း-

```
git branch
```

```
* main
```

`*` သည် လက်ရှိ ရောက်နေသော branch ကို ညွှန်ပြပါသည်။

## Branch အသစ် ဖန်တီးခြင်း

```
git branch feature/login
git branch
```

```
* main
  feature/login
```

## Branch များအကြား ပြောင်းလဲခြင်း

```
git switch feature/login
git branch
```

```
  main
* feature/login
```

Branch ကို ဖန်တီးပြီး တစ်ပြိုင်နက် ပြောင်းလိုပါက `git switch -c` ကို အသုံးပြုပါသည်။

```
git switch -c feature/navbar
```

## Branch တွင် အလုပ်လုပ်ခြင်း

Feature branch တွင် commit အသစ်တစ်ခုကို ဆောင်ရွက်ပါ။

```
echo "login page" > login.html
git add login.html
git commit -m "Add login page"
git log --oneline
```

Feature branch သည် main မှ ရှေ့သို့ ခြားထွက်သွားပါသည်။

## Merge ပြုလုပ်ခြင်း

Feature ၏ အလုပ်ပြီးသွားပါက main branch သို့ ပြန်လည် ပေါင်းစည်းပါသည်။

```
git switch main
git merge feature/login
```

Main branch တွင် feature branch ကဲ့သို့ commit များ မရှိသေးပါက fast-forward merge ဖြစ်ပြီး branch pointer သည်သာ ရှေ့သို့ ရွေ့သွားပါသည်။

```
Updating 9f8a2d1..c3d4e5f
Fast-forward
 login.html | 10 ++++++++++
 1 file changed, 10 insertions(+)
```

## Branch ဖျက်ခြင်း

Feature အလုပ်ပြီးသွားပါက branch ကို ဖျက်နိုင်ပါသည်။

```
git branch -d feature/login
```

Main သို့ merge မလုပ်ရသေးသော branch ကို အတင်းဖျက်ရန် `-D` ကို သုံးရပါမည်။ Branch သည် ပေါ့ပါးသော object ဖြစ်သောကြောင့် ဖန်တီးခြင်း ဖျက်ခြင်းကို လွတ်လပ်စွာ လုပ်နိုင်ပါသည်။
