Git သည် developer တိုင်း ကျွမ်းကျင်ရန် လိုအပ်သည့် version control system တစ်ခု ဖြစ်ပါသည်။ ဤသင်တန်းတွင် local computer ပေါ်တွင် code ၏ သမိုင်းကြောင်းကို ခြေရာခံခြင်းမှစပြီး GitHub တွင် team နှင့်အတူ တွဲဖက်လုပ်ဆောင်ခြင်း၊ server deployment နှင့် CI/CD pipeline များတွင် အသုံးပြုသည့် advanced workflow များအထိ တစ်ဆင့်ချင်း လေ့လာရပါမည်။

သင်တန်းကို သီတင်းပတ် 4 ခု အဖြစ် ဖွဲ့စည်းထားပြီး တစ်ပတ်စီတွင် သဘောတရား ရှင်းလင်းချက်၊ terminal command အပြည့်အစုံနှင့် လက်တွေ့ ဥပမာများ ပါဝင်ပါသည်။

## သင်တန်း အကြောင်းအရာ မြေပုံ

- **Module 1 - Core Fundamentals**: Git installation, commit cycle, branching နှင့် state management တို့ကို local computer ပေါ်တွင် လေ့လာမည် ဖြစ်ပါသည်။
- **Module 2 - Remote Repositories & GitHub**: SSH authentication, remote repository, push/pull နှင့် GitHub Flow တို့ကို သင်ယူမည် ဖြစ်ပါသည်။
- **Module 3 - Undoing Mistakes & Open Source**: amend, revert, reset, rebase, reflog တို့ဖြင့် အမှားပြင်ဆင်နည်း နှင့် fork, clone, pull request လုပ်နည်း တို့ ပါဝင်ပါသည်။
- **Module 4 - Advanced Git & DevOps**: .gitignore, LFS, submodules, merge conflict, GPG signing, git hooks နှင့် GitHub Actions CI/CD တို့ကို လေ့လာမည် ဖြစ်ပါသည်။
- **Validation & Assessment**: လက်တွေ့ exercises နှင့် quiz ဖြင့် မိမိ၏ အရည်အချင်းကို စစ်ဆေးမည် ဖြစ်ပါသည်။

## ကြိုတင်လိုအပ်ချက်များ

- Basic Terminal (Command Prompt, PowerShell သို့မဟုတ် Linux Shell) အသုံးပြုနည်းကို သိထားရပါမည်။
- မည်သည့် programming language မဆို အနည်းငယ် လေ့လာထားလျှင် ပိုမို အဆင်ပြေပါသည်။
- Git ကို install မလုပ်ထားသေးပါက Module 1 ရှိ Git Install & Config ဆောင်းပါးကို ဦးစွာ ဖတ်ပါ။

သင်တန်းကို စတင်လေ့လာရန် အောက်ပါ ဆောင်းပါးများကို အစဉ်လိုက် ဖတ်ပါ။
