## GitHub ဆိုသည်မှာ အဘယ်နည်း

GitHub သည် Git repository များကို cloud ပေါ်တွင် သိမ်းဆည်းပြီး team များ ပူးပေါင်း လုပ်ဆောင်နိုင်သည့် ပလက်ဖောင်း ဖြစ်ပါသည်။ Issue tracking, pull request, code review နှင့် CI/CD ကဲ့သို့သော စွမ်းရည်များကိုလည်း ပံ့ပိုးပေးပါသည်။

## Account ဖန်တီးခြင်း

1. https://github.com သို့ သွားပါ။
2. Sign up ကိုနှိပ်ပြီး username, email နှင့် password တို့ကို ထည့်သွင်းပါ။
3. Email verification ပြုလုပ်ပြီးနောက် account သည် အသုံးပြုရန် အဆင်သင့် ဖြစ်ပါသည်။

## Repository အသစ် ဖန်တီးခြင်း

1. အပေါ်ညာဘက်ရှိ + ခလုတ်ကိုနှိပ်၍ `New repository` ကို ရွေးပါ။
2. Repository name ကို `my-web-app` ဟု ထည့်ပါ။
3. Public သို့မဟုတ် Private ကို ရွေးပါ။
4. `Add a README file` checkbox ကို အမှတ်ခြစ်ပြီး `Create repository` ကိုနှိပ်ပါ။

## Repository URL ရယူခြင်း

Repository စာမျက်နှာ၏ Code tab တွင် URL များကို တွေ့ရပါမည်။

HTTPS URL-

```
https://github.com/mgmg/my-web-app.git
```

SSH URL-

```
git@github.com:mgmg/my-web-app.git
```

## README File ဆိုသည်မှာ အဘယ်နည်း

`README.md` သည် project ၏ နိဒါန်း ဖြစ်ပြီး install နည်း, အသုံးပြုနည်း နှင့် အခြားသူများ သိရန် လိုအပ်သည့် အချက်အလက်များကို ရေးသားထားပါသည်။ GitHub သည် README.md ကို repository စာမျက်နှာတွင် display ပြုလုပ်ပါသည်။

## GitHub တွင် File တည်းဖြတ်ခြင်း

Repository စာမျက်နှာတွင် file ကိုနှိပ်၍ edit option ကို ရွေးပြီး `Commit changes` button ဖြင့် commit ပြုလုပ်နိုင်ပါသည်။ ဤနည်းသည် browser မှ တိုက်ရိုက် တည်းဖြတ်သည့် နည်း ဖြစ်ပြီး local repo နှင့် ချိတ်ဆက်ထားလျှင် push/pull ဖြင့် ညှိနှိုင်းရပါမည်။
