MySQL သည် ကမ္ဘာပေါ်တွင် အသုံးအများဆုံး **relational database management system (RDBMS)** တစ်ခုဖြစ်ပါတယ်။ Data တွေကို ဇယား (tables) ပုံစံဖြင့် သိမ်းဆည်းပြီး လိုသလို ထုတ်ယူနိုင်ပါတယ်။

## ဘာ့ကြောင့် MySQL သုံးလဲ

- Open-source ဖြစ်ပြီး အခမဲ့သုံးနိုင်
- မြန်ဆန်၍ စိတ်ချရသော performance
- Web applications များတွင် အသုံးအများဆုံး
- PHP, Node.js, Python စသည့် ဘာသာစကားများနှင့် ချိတ်ဆက်လွယ်

## Database ဆိုတာ

Database ဆိုတာ data များကို စနစ်တကျ သိမ်းဆည်းထားသော နေရာဖြစ်ပါတယ်။ ဥပမာ — online shop တစ်ခုရဲ့ customers, products, orders ဇယားများ။

## ပထမဆုံး query

```sql
SELECT name, email FROM customers WHERE city = 'Yangon';
```

`customers` ဇယားထဲက `city` သည် 'Yangon' ဖြစ်သူများ၏ name နဲ့ email ကို ပြပါတယ်။

## ဒီသင်တန်းမှာ သင်ယူရမယ့် အကြောင်းအရာများ

- SQL query များ — SELECT, INSERT, UPDATE, DELETE
- Filter နှင့် sorting — WHERE, ORDER BY, LIMIT
- Aggregate — COUNT, SUM, AVG, MIN, MAX
- ဇယားများ ချိတ်ဆက်ခြင်း — JOIN, UNION
- Database ဒီဇိုင်း — constraints, keys, indexes

## MySQL ကို ဘယ်မှာ ရနိုင်လဲ

- **MySQL Community Server** — open source edition
- **XAMPP / WAMP** — local development အတွက် လွယ်ကူသော package
- Cloud services — AWS RDS, DigitalOcean စသည်

## အဓိက အချက်များ
- MySQL သည် popular RDBMS တစ်ခု
- Data ကို tables/rows ဖြင့် သိမ်းဆည်း
- SQL ဖြင့် query လုပ်သည်ဆိုတာ မှတ်သားပါ
