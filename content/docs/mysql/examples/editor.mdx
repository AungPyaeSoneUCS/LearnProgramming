MySQL ကုဒ်များကို စာမျက်နှာပေါ်တွင် တိုက်ရိုက်စမ်းသပ်နိုင်ပါတယ် — ကိုယ်ပိုင် environment တစ်ခု ပြင်စရာမလိုဘဲ သင်ယူနိုင်ရန်။

## အသုံးပြုပုံ
- Editor ထဲ SQL queries ရေးပါ
- **Run** ခလုတ် နှိပ်၍ ရလဒ် ကြည့်ပါ
- ဥပမာများကို ပြန် modify လုပ်ကြည့်

## ပဏာမ စမ်း

```sql
SELECT 'Hello MySQL' AS greeting;
```

Run လုပ်လျှင် `Hello MySQL` ပြန်ရမည်။

## ဇယားဆောက်၍ စမ်းနည်း

```sql
CREATE TABLE demo (id INT, name VARCHAR(50));
INSERT INTO demo VALUES (1, 'MySQL');
SELECT * FROM demo;
```

Statements အကြားတွင် semicolon (`;`) ခွဲရေးပါ။

## အကြံပြုချက်
- Syntax သိချင်လျှင် အရင်စမ်းပါ
- Tutorial ဥပမာများကို ပြန်စမ်း

## အဓိက အချက်များ
- Editor တွင်ရေး → Run
- Statements semicolon ပိတ်
- ကိုယ်တိုင် ပြောင်းလုပ်ကြည့်
