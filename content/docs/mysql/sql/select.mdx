`SELECT` statement သည် ဇယားထဲက data များကို ထုတ်ယူရန် အသုံးပြုပါတယ်။

## Syntax

```sql
SELECT column1, column2, ...
FROM table_name;
```

## All columns — SELECT *

```sql
SELECT * FROM customers;
```

`*` သည် column အားလုံးကို ဆိုလိုသည်။

## Column ရွေးထုတ်ယူ

```sql
SELECT first_name, last_name FROM employees;
```

## Expression — calculated column

```sql
SELECT product_name, price * quantity AS total_price
FROM order_items;
```

`price * quantity` ကို `total_price` အမည်ဖြင့် ပြသည် (AS alias)။

## Concatenate

```sql
SELECT CONCAT(first_name, ' ', last_name) AS full_name
FROM employees;
```

## မှတ်သားရန် အချက်များ
- `SELECT *` — အားလုံး (သို့သော်) column များကိုခွဲရွေးသည် ပိုကောင်း
- `AS` — output column နာမည်ပြောင်းရန်
- Query ကို semicolon ဖြင့်အဆုံးသတ်
