**JOIN** သည် ‌ဇယား‌နှစ်ခု‌ပေါင်းကို related column အပေါ် ‌မူတည်၍ ‌ပေါင်း‌စပ် ‌ထုတ်ယူရန် ‌သုံးပါတယ်။

## ‌ဥပမာ ‌ဇယား‌နှစ်ခု

```
orders                     customers
+----+-----------+-------+  +----+----------+
| id | customer_id | amt |  | id | name     |
+----+-----------+-------+  +----+----------+
| 1  | 1          | 300  |  | 1  | Aung     |
| 2  | 3          | 200  |  | 2  | Su       |
+----+-----------+-------+  +----+----------+
```

## ‌အခြေခံ JOIN (INNER)

```sql
SELECT o.id, c.name, o.amount
FROM orders AS o
JOIN customers AS c ON o.customer_id = c.id;
```

`orders.customer_id = customers.id` ‌ကိုက်ညီသော rows ‌တွဲ ‌ပြသည်။

## JOIN အမျိုးအစားများ ခြုံငုံ

| Type | ‌ဖော်ပြချက် |
| --- | --- |
| INNER JOIN | ‌နှစ်‌ဖက်လုံး ‌ကိုက်ညီ |
| LEFT JOIN | ‌ဘယ်ဘက် ‌အားလုံး + ‌ကိုက်ညီသူ |
| RIGHT JOIN | ‌ညာဘက် ‌အားလုံး + ‌ကိုက်ညီသူ |
| CROSS JOIN | ‌ပေါင်းစပ် (every combination) |
| SELF JOIN | ‌ဇယားကိုယ်၌ ‌နှင့် |

## ‌ဘယ်လို ‌ရွေးမလဲ
- ‌နှစ်‌ဖက်မှ ‌ကိုက်ညီမှသာ → INNER
- ‌ဘယ်ဘက်အားလုံးလို → LEFT
- ‌စုံတွဲ ပေါင်းစပ်မှု အားလုံး → CROSS

## ‌အဓိက အချက်များ
- JOIN = ‌ဇယားများ ‌ချိတ်
- ON ‌ဖြင့် ‌တွဲ ‌ချက် သတ်မှတ်
- ‌ရွေးရန် အမျိုးအစား မှန်‌အောင် သိရှိ
