`LIMIT` clause သည် query ‌ရလဒ်ထဲ ပြမည့် **rows အရေအတွက်ကို ကန့်** ပါတယ် — ‌ဒေတာ‌ကြီးတွေမှာ ‌အသုံးဝင်သည်။

## Syntax

```sql
SELECT column1
FROM table_name
LIMIT number;
```

## ဥပမာ — ‌ပထမ 3 rows

```sql
SELECT * FROM customers
LIMIT 3;
```

## ORDER BY ‌နှင့် တွဲ — top N

```sql
SELECT * FROM products
ORDER BY price DESC
LIMIT 5;
```

price ‌အကြီးဆုံး 5 ခု။

## OFFSET — ‌ကျော်ပြီး ထုတ်

```sql
SELECT * FROM products
ORDER BY price DESC
LIMIT 5 OFFSET 10;
```

row 10 ကျော်ပြီး 5 ခု ‌ပြ — pagination ၏ page 3 ‌ပုံစံ။

## Pagination ‌ဥပမာ

```sql
-- Page 1
SELECT * FROM products LIMIT 10 OFFSET 0;
-- Page 2
SELECT * FROM products LIMIT 10 OFFSET 10;
```

## ‌အဓိက အချက်များ
- LIMIT n — n rows ‌ပြ
- ORDER BY + LIMIT — top N
- OFFSET — skip rows (pagination)
