**Buffer** — raw binary data ‌များကို representation — Node.js ‌မှာ streams/network/crypto ‌တွင် ‌အသုံးများ။

## ‌ကြီး

```js
const buf = Buffer.alloc(5);         // 5 bytes ‌အ‌ပြည့် ‌အ‌ဟာ
const buf2 = Buffer.from("hello");   // from string
const buf3 = Buffer.from([1, 2, 3]); // from array
```

## Decode

```js
const data = Buffer.from("မင်္ဂလာပါ", "utf8");
console.log(data.toString("utf8")); // ‌ပြန် ‌ဖတ်
```

Buffers are **array-like** — index ‌ဖြင့် bytes ‌ကြည့်:

```js
console.log(buf2[0]);        // 104 ('h')
console.log(buf2.length);    // 5
```

## Slice (‌အ‌ချောင် — copy ‌မဟုတ်)

```js
const sub = buf2.subarray(1, 3);
```

## ‌အသုံးပြုမှု — file chunk

```js
const chunk = fs.readFileSync("img.png"); // Buffer
console.log(chunk.length, chunk[0]);
```

## ‌အဓိက အချက်များ
- Buffer.from / alloc / toString
- Index + length
- Binary/network ‌တွင် ‌အသုံးများ
