`node:http` — ကိုယ်ပိုင် HTTP server ဖန်တီး၍ requests လက်ခံစေရန်။

## ပထမဆုံး server

```js
const http = require("node:http");

const server = http.createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "text/plain" });
  res.end("Hello from HTTP server");
});

server.listen(3000, () => console.log("Listening on :3000"));
```

## ရလဒ်

Browser `http://localhost:3000` → `Hello from HTTP server`။

## Route checking

```js
const server = http.createServer((req, res) => {
  if (req.url === "/") {
    res.end("Home");
  } else if (req.url === "/about") {
    res.end("About");
  } else {
    res.writeHead(404);
    res.end("Not found");
  }
});
```

## req object များ
| အရာ | ဖော်ပြချက် |
| --- | --- |
| `req.url` | path e.g. `/about?a=1` |
| `req.method` | GET/POST/... |
| `req.headers` | headers object |

```js
console.log(req.method, req.url);
```
