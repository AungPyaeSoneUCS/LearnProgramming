LEDs ‌အများ ‌ဆက် ‌လင်းစေ — flowing/knight-rider ‌ပုံစံ။

## Wiring
LEDs → GPIO pins 17, 18, 27, 22, 23 (resistors) → GND ‌တူ။

## Code

```js
const Gpio = require("onoff").Gpio;

const pins = [17, 18, 27, 22, 23];
const leds = pins.map((p, i) => ({ pin: p, gpio: new Gpio(p, "out") }));

let i = 0;
setInterval(() => {
  leds.forEach((l, idx) => l.gpio.writeSync(idx === i ? 1 : 0));
  i = (i + 1) % leds.length;
}, 200);

process.on("SIGINT", () => {
  leds.forEach((l) => {
    l.gpio.writeSync(0);
    l.gpio.unexport();
  });
  process.exit();
});
```

## Back-and-forth

```js
let dir = 1;
setInterval(() => {
  leds.forEach((l, idx) => l.gpio.writeSync(idx === i ? 1 : 0));
  i += dir;
  if (i === leds.length - 1 || i === 0) dir *= -1;
}, 150);
```
