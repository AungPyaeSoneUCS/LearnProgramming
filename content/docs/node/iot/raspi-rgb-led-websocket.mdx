RGB LED — 3 colors (red/green/blue) — PWM ‌ဖြင့် ‌ပေါင်း colors — websocket ‌ထိန်း။

## Wiring
- R → GPIO17, G → GPIO18, B → GPIO27 (PWM-capable)
- Common cathode → GND

## Code

```js
const http = require("node:http");
const { WebSocketServer } = require("ws");
const Gpio = require("onoff").Gpio;

const leds = {
  r: new Gpio(17, "out"),
  g: new Gpio(18, "out"),
  b: new Gpio(27, "out"),
};

function setColor(color) {
  leds.r.writeSync(color === "red" || color === "white" ? 1 : 0);
  leds.g.writeSync(color === "green" || color === "white" ? 1 : 0);
  leds.b.writeSync(color === "blue" || color === "white" ? 1 : 0);
}

const wss = new WebSocketServer({ port: 8080, host: "0.0.0.0" });

wss.on("connection", (ws) => {
  ws.on("message", (msg) => setColor(msg.toString()));
});
```
