## Variables & arrow

```js
const port = 3000;
let count = 0;
const double = (n) => n * 2;
```

## Destructuring & spread

```js
const [a, b] = [1, 2];
const obj = { user: { name: "Su" } };
const { name } = obj.user;
const merged = { id: 1, ...obj };
```

## Template & optional chaining

```js
const msg = `Port: ${port}`;
const city = obj.user?.address?.city ?? "Unknown";
```

## Maps / Sets / Array helpers

```js
const m = new Map([["a", 1]]);
const s = new Set([1, 2, 2]);
[3, 1, 2].sort((x, y) => x - y);
```
