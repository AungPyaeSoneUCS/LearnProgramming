`node:crypto` **HMAC** — hashed message authentication code — secret key ‌ဖြင့် digest — integrity + authenticity။

## createHmac

```js
const crypto = require("node:crypto");

const secret = "my-secret";
const hmac = crypto.createHmac("sha256", secret);

hmac.update("message to sign");
console.log(hmac.digest("hex"));
```

## verify

```js
function sign(data, secret) {
  return crypto.createHmac("sha256", secret).update(data).digest("hex");
}

const expected = sign("payload", secret);
const actual = sign("payload", secret);

console.log(crypto.timingSafeEqual(Buffer.from(expected, "hex"), Buffer.from(actual, "hex")));
```

`timingSafeEqual` — timing attack ‌ကာကွယ်။

## Use cases
- API signatures
- JWT-like tokens
