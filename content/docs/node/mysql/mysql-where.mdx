Filter rows — Node.js ‌မှ WHERE ပုံစံ ‌မျိုးစုံ။

## Basic

```js
const [rows] = await db.query(
  "SELECT * FROM users WHERE age >= ?",
  [18]
);
```

## AND / OR

```js
await db.query("SELECT * FROM users WHERE city = ? AND age > ?", [
  "Yangon",
  25,
]);
```

## LIKE — pattern

```js
const [rows] = await db.query(
  "SELECT * FROM users WHERE name LIKE ?",
  ["A%"]
);
```

## IN

```js
const ids = [1, 3, 5];
const placeholders = ids.map(() => "?").join(", ");
const [rows] = await db.query(
  `SELECT * FROM users WHERE id IN (${placeholders})`,
  ids
);
```

Dynamic IN — `?` placeholders ‌ဖြင့် ‌အ‌ပေါ် build — safe။
