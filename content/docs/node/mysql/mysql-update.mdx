Existing rows ‌ပြန် ‌ပြင်နည်း — WHERE မပါရင် ‌အားလုံး ‌ပြောင်း။

## Update

```js
const [result] = await db.query(
  "UPDATE users SET name = ?, city = ? WHERE id = ?",
  ["Phyu", "Yangon", userId]
);
```

## affectedRows

```js
console.log(result.affectedRows); // ‌ပြောင်း ‌ရသော rows
```

## Multiple sets

```js
await db.query(
  "UPDATE orders SET status = ?, paid_at = NOW() WHERE id = ?",
  ["paid", orderId]
);
```
