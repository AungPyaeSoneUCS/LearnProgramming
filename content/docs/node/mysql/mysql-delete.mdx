Rows ‌ဖျက်နည်း — **WHERE ‌အမြဲ** — ‌မပါလျှင် ‌အားလုံး ‌ဖျက်။

## Delete

```js
const [result] = await db.query(
  "DELETE FROM users WHERE id = ?",
  [userId]
);
console.log(result.affectedRows); // 1
```

## Check result

```js
if (result.affectedRows === 0) {
  console.log("User not found");
}
```

## With condition

```js
await db.query(
  "DELETE FROM orders WHERE status = ? AND dated < ?",
  ["expired", pastDate]
);
```
