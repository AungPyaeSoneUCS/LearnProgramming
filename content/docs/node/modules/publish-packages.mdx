ကိုယ်ပိုင် package ကို npm registry သို့ publish လုပ်နည်း — ‌အခြားသူ ‌သုံး‌စေရန်။

## Step 1 — package.json ‌ပြင်ဆင်

```json
{
  "name": "my-awesome-lib",
  "version": "1.0.0",
  "main": "index.js",
  "files": ["index.js", "README.md"],
  "license": "MIT",
  "keywords": ["helper", "utils"]
}
```

`name` — npm ‌ပေါ်တွင် unique ‌ဖြစ်ရမည်။

## Step 2 — Login

```bash
npm login
```

## Step 3 — Publish

```bash
npm publish
```

## Version ‌မြှင့်၍ republish

```bash
npm version patch   # 1.0.0 → 1.0.1
npm version minor   # 1.0.1 → 1.1.0
npm version major   # 1.1.0 → 2.0.0
npm publish
```

`npm version` — version ၏ parse/compare — git tag ‌လဲ ‌လုပ်သည်။

## Unpublish (‌သတိထား)

```bash
npm unpublish my-awesome-lib@1.0.0
```

Unpublish ‌တွင် ‌ကန့်သတ် — 24h window ‌အ‌တွင်း။

## ‌အဓိက အချက်များ
- npm login → npm publish
- version patch/minor/major
- name unique ‌လိုအပ်
