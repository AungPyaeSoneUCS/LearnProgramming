**Node.js** သည် JavaScript ကို **server / computer တွင် run** စေသော runtime ဖြစ်သည် — Chrome ၏ V8 engine ပေါ်တွင် အခြေခံသည်။

## Node.js ဆိုတာ
- JavaScript runtime (browser အပြင်)
- Built on V8 engine
- Async, event-driven, non-blocking

## ပထမဆုံး Node.js program

`app.js` ဟု ဖိုင်တစ်ခု ဖန်တီး၍:

```js
console.log("Hello from Node.js!");
```

Terminal တွင်:

```bash
node app.js
```

ရလဒ် — `Hello from Node.js!` ပြန် output ထွက်သည်။

## Node.js က ဘာတွေ လုပ်နိုင်လဲ
- Web server ဆောက်
- File system / command line tools
- Database နဲ့ ဆက်သွယ်
- Real-time apps (Socket.IO)
- IoT / hardware control (Raspberry Pi)

## Why Node.js
- JavaScript တစ်မျိုးတည်း — frontend + backend
- NPM — package သန်းပေါင်းများစွာ
- Fast for I/O intensive apps

## အဓိက အချက်များ
- Node.js = Server-side JS runtime
- `node file.js` ဖြင့် run
- V8 + Async event-driven
