**Socket.IO** — real-time, bidirectional, event-based ‌ချိတ်ဆက် — WebSocket ‌အပေါ် ‌တည်‌ဆောက် + fallback။

## Install

```bash
npm install socket.io express
```

## Server

```js
const express = require("express");
const http = require("node:http");
const { Server } = require("socket.io");

const app = express();
const server = http.createServer(app);
const io = new Server(server);

io.on("connection", (socket) => {
  console.log("User connected:", socket.id);

  socket.on("chat message", (msg) => {
    io.emit("chat message", msg);   // broadcast ‌အားလုံး
  });

  socket.on("disconnect", () => console.log("bye"));
});

server.listen(3000);
```

## Client (browser)

```js
const socket = io();

socket.on("connect", () => socket.emit("chat message", "Hello"));

socket.on("chat message", (msg) => {
  const el = document.createElement("li");
  el.textContent = msg;
  document.body.appendChild(el);
});
```

## Rooms — ‌အုပ်‌စု ‌ပေး

```js
socket.join("room-a");
io.to("room-a").emit("update", data); // room members သာ
```
