Documents ‌ဖျက်နည်း။

## Delete one

```js
const result = await users.deleteOne({ name: "Aung" });
console.log(result.deletedCount); // 1 ‌သို့ 0
```

## Delete many

```js
const result = await users.deleteMany({ age: { $lt: 18 } });
console.log(result.deletedCount);
```

## Delete everything (သတိ)

```js
const result = await users.deleteMany({});
```

## Check before delete

```js
const found = await users.findOne({ _id: new ObjectId(id) });
if (found) {
  await users.deleteOne({ _id: found._id });
} else {
  console.log("not found");
}
```
