**Worker threads** — CPU-intensive ‌လုပ်‌ဆောင်မှုများကို parallel — event loop ‌မပိတ်ဘဲ။

## Main

```js
const { Worker } = require("node:worker_threads");

const worker = new Worker("./compute.js", {
  workerData: { n: 1_000_000_000 },
});

worker.on("message", (result) => console.log("result:", result));
worker.on("error", console.error);
worker.on("exit", (code) => console.log("worker exit", code));
```

## Worker — compute.js

```js
const { parentPort, workerData } = require("node:worker_threads");

let sum = 0;
for (let i = 0; i < workerData.n; i++) sum += i;

parentPort.postMessage(sum);
```

## Run

```bash
node main.js
```

Result — main thread ‌မပိတ်ဘဲ heavy loop ။

- Image/video processing
