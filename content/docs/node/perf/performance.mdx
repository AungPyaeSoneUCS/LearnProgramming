Node apps မြန်စေရန် — အခြေခံ techniques။

## Avoid blocking the event loop

```js
// ❌ sync on server
const data = await fs.readFileSync("big.txt");

// ✓ async
const data = await fs.promises.readFile("big.txt");
```

## CPU-heavy → delegate

```js
// ‌ကြီးသော computation — worker thread ‌သို့
const { Worker } = require("node:worker_threads");
```

## Buffer / stream ‌ကြီး files

```js
fs.createReadStream("big.mp4").pipe(res); // ‌အပိုင်း memory
```

## Caching

```js
const cache = new Map();

function getExpensive(id) {
  if (cache.has(id)) return cache.get(id);
  const value = compute(id);
  cache.set(id, value);
  return value;
}
```
