`node:zlib` — data ‌ချုံ့ (gzip, deflate) — ‌ပို့ ‌အရွယ် ‌ပေါ့ချက် — HTTP responses, files။

## gzip a file

```js
const zlib = require("node:zlib");
const fs = require("node:fs");

const read = fs.createReadStream("big.txt");
const write = fs.createWriteStream("big.txt.gz");

read.pipe(zlib.createGzip()).pipe(write);
```

## Unzip

```js
fs.createReadStream("big.txt.gz")
  .pipe(zlib.createGunzip())
  .pipe(fs.createWriteStream("big2.txt"));
```

## Sync compress

```js
const data = fs.readFileSync("big.txt");
const gz = zlib.gzipSync(data);
console.log(`before ${data.length} → after ${gz.length}`);
```
